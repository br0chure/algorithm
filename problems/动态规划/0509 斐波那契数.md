# 斐波那契数

## 题面

斐波那契数列：`F(0)=0`、`F(1)=1`，此后每项是前两项之和 `F(n)=F(n-1)+F(n-2)`。给定 `n`，求 `F(n)`。

约束：`0 ≤ n ≤ 30`。

## 思路

**Pattern：斐波那契型** → [dp_intro](../../patterns/动态规划/dp_intro.md)

跟 [0070 爬楼梯](0070%20爬楼梯.md) **完全同构**，转移方程一样 `dp[i]=dp[i-1]+dp[i-2]`，**唯一差异是 base case**：

| | base case |
|---|---|
| 爬楼梯 | `dp[1]=1`、`dp[2]=2` |
| 斐波那契 | `dp[0]=0`、`dp[1]=1` |

### 直接进阶到 O(1) 空间

爬楼梯归档的是 O(n) 数组版；斐波那契这里承载**空间优化**这个新点。

观察转移方程 `dp[i]=dp[i-1]+dp[i-2]`：算 `dp[i]` 只用到**前两个**值，更早的格子全是死重量。所以不必开整个数组——**两个变量 `prev`、`curr` 往前滚**就够。

## 完整代码（O(1) 滚动变量）

```go
func fib(n int) int {
    if n < 2 {
        return n
    }
    prev, curr := 0, 1               // prev=F(0), curr=F(1)
    for i := 2; i <= n; i++ {
        prev, curr = curr, prev+curr // 整体往前滚一格
    }
    return curr
}
```

> `prev, curr = curr, prev+curr`：Go 的多重赋值，右边先整体算完再赋回，天然不用临时变量。一轮滚完，`curr` 就是新的 `F(i)`。

## 复杂度

- **时间：O(n)**——一层 for 从 2 到 n，每步 O(1)。
- **空间：O(1)**——只用 `prev`、`curr` 两个变量，不随 n 增长（对比爬楼梯的 O(n) 数组版，省掉了整个数组）。
