# 分割等和子集

## 题面

给一个只含正整数的非空数组 `nums`，判断能否分割成两个子集，使两子集元素和相等。

样例：
- `[1,5,11,5]` → `true`（`{1,5,5}` 和 `{11}`，各 11）
- `[1,2,3,5]` → `false`

约束：`1 ≤ n ≤ 200`，`1 ≤ nums[i] ≤ 100`。

## 思路

**Pattern：0-1 背包（伪装题）** → [knapsack_01](../../patterns/动态规划/knapsack_01.md)

### 揭开伪装：这是背包

"分成两个等和子集" → 每个子集的和 = `sum/2` → 问题变成：**能否从数组挑若干数、和恰好为 `sum/2`**？

这就是 0-1 背包（每个数只能用一次）：

| 背包概念 | 本题 |
|---|---|
| 物品 | 数组每个数 |
| 重量 `w[i]` | `nums[i]`（数值本身）|
| 容量 `W` | `sum / 2` |
| dp 装什么 | **能否恰好凑出（bool）** |

> 前置特判：`sum` 是奇数 → 直接 `false`（分不出两个相等的整数和）。

### 状态 & 转移

- **状态**：`dp[i][j]` = 前 `i` 个数能否恰好凑出和 `j`
- **转移**：`dp[i][j] = dp[i-1][j] || (j >= nums[i-1] && dp[i-1][j-nums[i-1]])`
  - 不选第 i 个数：`dp[i-1][j]`
  - 选第 i 个数（需 `j >= nums[i-1]`）：`dp[i-1][j-nums[i-1]]`
  - "取更优"是 bool → 用 `||`（有一条路能凑出就行）
- **base case**：`dp[i][0] = true`（容量 0，啥都不选就凑出）；`dp[0][j>0] = false`（默认）
- **答案**：`dp[n][sum/2]`

### 两个坑（啃过的）

- **第 `i` 行对应 `nums[i-1]`**（数组从 0 起）；写成 `nums[i]` 会在 `i=n` 时越界 panic。
- **守卫用 `j >= nums[i-1]`，不是 `>`**：`j` 正好等于这个数时，"单用它就能填满容量 j"，是合法解，`>` 会漏掉（反例 `[2,2]`）。

## 完整代码

```go
func canPartition(nums []int) bool {
    sum := 0
    for _, x := range nums {
        sum += x
    }
    if sum%2 != 0 {
        return false
    }
    target := sum / 2
    dp := make([][]bool, len(nums)+1)
    for i := range dp {
        dp[i] = make([]bool, target+1)
        dp[i][0] = true // 容量 0：啥都不选就凑出
    }
    for i := 1; i <= len(nums); i++ {
        for j := 1; j <= target; j++ {
            dp[i][j] = dp[i-1][j] || (j >= nums[i-1] && dp[i-1][j-nums[i-1]])
        }
    }
    return dp[len(nums)][target]
}
```

## 复杂度

- **时间：O(n × target)**（`target = sum/2`）——dp 表 `(n+1)×(target+1)` 个格子，每个 O(1) 填一次，即"数格子"。
- **空间：O(n × target)**——二维表；一维滚动 + `j` 倒序可降到 **O(target)**。

> **伪多项式**：复杂度带着 `target`（数值），不是纯看元素个数 `n`。所以背包题总限制 sum / 容量不大——**"和 / 容量有明确上界"是背包的一个信号**。
