# 打家劫舍 III

## 题面

房子排成一棵**二叉树**，直接相连（父子）的两间不能同时偷。求能偷到的最大金额。

样例：`[3,2,3,null,3,null,1]` → `7`（偷根 3 + 两个孙子 3 和 1 = `3+3+1`）

约束：节点数 `[1, 10⁴]`，`0 ≤ Node.val ≤ 10⁴`。

## 思路

**Pattern：house_robber（树形变体）** → [house_robber](../../patterns/动态规划/house_robber.md)

### 起手五步的 ③：要决定父节点偷不偷，得知道孩子的什么？

- **偷父** → 孩子必须不偷 → 需要孩子**"不偷时"**的值
- **不偷父** → 孩子随意 → 需要孩子**"偷 / 不偷里更大"**的值

两种都用到孩子的"偷"和"不偷"两个值 → **每个节点必须向上返回一对 `(不偷, 偷)`**（甩不掉的二维状态机）。

### 转移（后序：先算孩子，再拼父亲）

```
不偷 node = max(左那对) + max(右那对)
偷   node = node.Val + 左"不偷" + 右"不偷"
```

答案 = `max(根那对)`。

### dp 表在哪？——递归返回值

树的节点没有整数下标，**不用数组**。每个节点的 `[2]int` 返回值就是它的 dp；**"存" = return 给父亲，"用" = 父亲接住来算自己**。

> ⚠️ 坑：必须用局部变量 `left := dfs(node.Left)` **接住、只算一次**。若写成 `dfs(node.Left)[0]`、`dfs(node.Left)[1]` 反复调，同一棵子树被重算，链状树 3ⁿ 爆炸 TLE——就是"没记账"的重复计算。

## 完整代码

```go
func rob(root *TreeNode) int {
    var dfs func(*TreeNode) [2]int
    dfs = func(node *TreeNode) [2]int {
        if node == nil {
            return [2]int{0, 0}
        }
        left := dfs(node.Left)   // 接住，只算一次
        right := dfs(node.Right)
        norob := max(left[0], left[1]) + max(right[0], right[1]) // [0] = 不偷 node
        rob := node.Val + left[0] + right[0]                     // [1] = 偷 node
        return [2]int{norob, rob}
    }
    return max(dfs(root)[0], dfs(root)[1])
}
```

## 复杂度

- **时间：O(n)**——每个节点被父亲调用**恰好 1 次**（接住返回值的功劳），n 个节点各 O(1)。
- **空间：O(h)**——递归栈深 = 树高 h（最坏链状 O(n)，平衡 O(log n)）；返回值 `[2]int` 常数大小，无额外数组。
