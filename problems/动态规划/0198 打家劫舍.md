# 打家劫舍

## 题面

一排房子，第 `i` 间藏 `nums[i]` 现金。**相邻两间不能同时偷**（会触发报警）。求今晚能偷到的最大金额。

样例：
- `[1,2,3,1]` → `4`（偷 0、2 号房：`1+3`）
- `[2,7,9,3,1]` → `12`（偷 0、2、4 号房：`2+9+1`）

约束：`1 ≤ n ≤ 100`，`0 ≤ nums[i] ≤ 400`。

## 思路

**Pattern：带决策的一维 DP**（斐波那契型的进阶——转移里第一次出现"选 / 不选"）→ [dp_intro](../../patterns/动态规划/dp_intro.md)

### 状态定义

`dp[i]` = 在前 `i+1` 间房（下标 `0..i`）里随便偷，能偷到的最大金额。

> ⚠️ 关键：**`dp[i]` 不锁定"第 i 间偷没偷"**。它只承诺"`0..i` 这段的最优值"，偷没偷 i 是 `max` 选出来的**副产品**。

### 转移方程

站在第 `i` 间前，二选一：

```
dp[i] = max( dp[i-1],          // 不偷 i：原地继承到 i-1 的最优
             dp[i-2]+nums[i] ) // 偷 i：必须跳过 i-1，从 i-2 接 + nums[i]
```

**口诀：偷 → 跳一格接 `dp[i-2]`；不偷 → 原地接 `dp[i-1]`。** 决策被 `max` 吸收掉了，所以一维就够。

### 初始化 & 遍历

- `dp[0] = nums[0]`（只有一间，偷它）
- `dp[1] = max(nums[0], nums[1])`（两间取大的那间）
- `i` 从 2 到 n-1 顺着填。

### 为什么不用二维？

很自然会想开 `dp[i][0/1]`（偷 i / 不偷 i）——这个"状态机"思路**完全正确**，只是对这题冗余。令 `f[i] = max(dp[i][0], dp[i][1])`，推导会发现"偷 i"要用的"i-1 不偷的值"恰好 `= f[i-2]`，于是二维塌成上面的一维方程。

> 二维状态机不是白想——到**买卖股票**那组，"持有 / 不持有"是甩不掉的状态，`dp[i][0/1]` 会成主力。
> **判据：当"处于哪种状态"会限制下一步能做什么时，才需要多开一维记状态。**

## 完整代码

```go
func rob(nums []int) int {
    if len(nums) == 1 {
        return nums[0]
    }
    dp := make([]int, len(nums))
    dp[0] = nums[0]
    dp[1] = max(nums[0], nums[1])
    for i := 2; i < len(nums); i++ {
        dp[i] = max(dp[i-1], dp[i-2]+nums[i])
    }
    return dp[len(nums)-1]
}
```

> Go 1.21+ 内置 `max`，可省去自定义。

## 复杂度

- **时间：O(n)**——一层 for 扫一遍，每步 O(1)。
- **空间：O(n)**——`dp` 数组。因 `dp[i]` 只依赖前两个值，可用滚动变量优化到 **O(1)**（待补）。
