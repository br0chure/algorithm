# 组合

## 题面

给定两个整数 `n` 和 `k`，返回 `[1, n]` 中所有 `k` 个数的组合，可按任意顺序返回。

- 示例：`n=4, k=2` → `[[1,2],[1,3],[1,4],[2,3],[2,4],[3,4]]`

## 思路

组合**不计顺序**（`{1,2}` 与 `{2,1}` 是同一个），所以用 **`start` 只往后选** 去重，不需要 `used`。

- 参数 `i` = 上一个选过的数字；每层 for 从 `i+1` 开始，保证只选更大的数 → 同一组只生成升序那一份，逆序分支根本不存在，重复从源头消失。
- 递归传 `j`（刚选的数），下一层从它之后继续。
- base case：`len(path) == k`。

## 完整代码

```go
func combine(n int, k int) [][]int {
    result := [][]int{}
    path := make([]int, 0, k)

    var backtrack func(int)
    backtrack = func(i int) {
        if len(path) == k {
            tmp := make([]int, k)
            copy(tmp, path)
            result = append(result, tmp)
            return
        }
        for j := i + 1; j <= n; j++ {
            path = append(path, j) // 选择
            backtrack(j)           // 下一层从 j 之后选
            path = path[:len(path)-1] // 撤销
        }
    }

    backtrack(0)
    return result
}
```

## 细节 / 易错点

- **为什么不用 `used`**：组合不计顺序，靠"只往后选"就能去重；`used` 是排列（计顺序、要回头选）才需要。判断尺——**结果在不在意顺序**。
- **递归传 `j` 还是 `j+1`**：取决于参数语义。这里 `i` 表示"上一个选的数"，所以传 `j`（下一层从 `j` 之后选）；若把参数定义成"起点 `start`"，则 for 从 `start` 开始、递归传 `j+1`。两种等价，别混。
- **深拷贝**收集，老规矩（切片共享底层数组）。
- 进阶：可加**剪枝**——剩余数字不足以凑满 `k` 个时提前停。把循环上界改成 `j <= n-(k-len(path))+1`，能砍掉大量无效分支。

## 复杂度

- 时间：**O(k × C(n,k))**。组合共 `C(n,k)` 个（叶子），每个深拷贝 `O(k)`；内部节点遍历开销同阶，被叶子主导。
- 空间：**O(k)**（不计输出）。递归最深 `k` 层，每帧 `O(1)`；`path` 占 `O(k)`。输出 `result` 不计入额外空间。
