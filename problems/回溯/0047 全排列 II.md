# 全排列 II

## 题面

给一个**可能含重复数字**的序列 `nums`，按任意顺序返回所有**不重复**的全排列。

- 示例：`[1,1,2]` → `[[1,1,2],[1,2,1],[2,1,1]]`

## 思路

0046 全排列（`used`）+ 输入去重。排列**用 `used` 不用 `start`**，所以同层去重的判断和组合不同：

- 排序 + `if i > 0 && nums[i]==nums[i-1] && !used[i-1] { continue }`。
- 看前一个相同值的状态：**前一个「用了」（`used[i-1]==true`）= 跨层**（在 path 里、上层选的）→ 留；**前一个「没用」（`used[i-1]==false`）= 同层**（本层刚试完撤销了）→ 跳。

## 完整代码

```go
import "sort"

func permuteUnique(nums []int) [][]int {
    result := [][]int{}
    path := make([]int, 0, len(nums))
    used := make([]bool, len(nums))
    sort.Ints(nums)

    var backtrack func()
    backtrack = func() {
        if len(path) == len(nums) {
            tmp := make([]int, len(path))
            copy(tmp, path)
            result = append(result, tmp)
            return
        }
        for i := 0; i < len(nums); i++ {
            if used[i] {
                continue // 已在 path 里，跳过
            }
            if i > 0 && nums[i] == nums[i-1] && !used[i-1] {
                continue // 同层去重：前一个相同值刚撤销（同层）
            }
            path = append(path, nums[i])
            used[i] = true
            backtrack()
            path = path[:len(path)-1]
            used[i] = false
        }
    }

    backtrack()
    return result
}
```

## 细节 / 易错点

- **两个 `continue` 各管一件事**，别混：
  - `if used[i]` → 跳过"已经在当前 path 里的"（排列本来就有的）。
  - `if ... && !used[i-1]` → 跳过"同层重复值"（去重新增的）。
- **`!used[i-1]` 的口诀**：前一个「用了」是跨层（留），「没用」是同层（跳）。
- 必须先**排序**，去重靠相同值相邻。
- 深拷贝收集。

## 复杂度

- 时间：**O(n × n!)** 上界（去重剪枝后实际更少）。最多 `n!` 个排列，每个深拷贝 `O(n)`。
- 空间：**O(n)**（不计输出）。递归最深 `n` 层，`path`、`used` 各 `O(n)`。
