# 子集 II

## 题面

给一个**可能含重复元素**的数组 `nums`，返回所有可能的子集（幂集），解集不含重复子集。

- 示例：`[1,2,2]` → `[[],[1],[1,2],[1,2,2],[2],[2,2]]`

## 思路

**0078 子集 + 0040 去重** 的合体，没有新机制：

- 子集（每个节点都是答案）→ **入口收集**（含空集），传 `j+1`。
- 输入有重复 → **排序 + 同层去重** `if j > i && nums[j]==nums[j-1] { continue }`。

两件事位置不冲突：收集放函数入口（子集那套），去重判断放 for 里（去重那套）。

## 完整代码

```go
import "sort"

func subsetsWithDup(nums []int) [][]int {
    result := [][]int{}
    path := []int{}
    sort.Ints(nums)

    var backtrack func(int)
    backtrack = func(i int) {
        tmp := make([]int, len(path))
        copy(tmp, path)
        result = append(result, tmp) // 入口收集（含空集）

        for j := i; j < len(nums); j++ {
            if j > i && nums[j] == nums[j-1] {
                continue // 同层去重
            }
            path = append(path, nums[j])
            backtrack(j + 1)
            path = path[:len(path)-1]
        }
    }

    backtrack(0)
    return result
}
```

## 细节 / 易错点

- **收集 `append` 的是 `tmp` 不是 `path`**：深拷贝坑的变量版——`tmp` 拷好了别忘了用它。深层原因见切片扩容：浅拷贝时不同长度的快照落在不同底层数组上，部分被后续 `append` 原地覆写，结果是一片混乱（不是"全一样"）。
- **必须先排序**，去重靠相同值相邻。
- 收集位置（入口） vs 去重位置（for 里）各管各的，别混。

## 复杂度

- 时间：**O(2ⁿ × n)** 量级。最坏 `2ⁿ` 个子集，去重剪掉一部分；每个解深拷贝 `O(n)`。
- 空间：**O(n)**（不计输出）。递归最深 `n` 层，`path` 占 `O(n)`。
