# 组合总和

## 题面

给一个**无重复元素**的数组 `candidates` 和目标 `target`，返回所有和为 `target` 的组合。**同一个数字可无限次重复选取**。

- 示例：`candidates=[2,3,6,7], target=7` → `[[2,2,3],[7]]`

## 思路

组合骨架（`start` 防组合重复）+ 两处变化：

- **可重复选** → 递归传 `j`（不是 `j+1`），下一层还能再选中 `j` 自己。
- **终止看和**，不看长度：`sum == target` 收集；`sum > target` 剪枝 `return`。

`for` 从 `j=i` 开始保证组合不重复（`[2,3]` 不会再出 `[3,2]`）；递归传 `j` 允许同一个数重复（`[2,2,3]`）——两件事互不冲突。

## 完整代码

```go
func combinationSum(candidates []int, target int) [][]int {
    result := [][]int{}
    path := []int{}
    var sum int

    var backtrack func(int)
    backtrack = func(i int) {
        if sum > target {
            return // 剪枝：超了，这条路废了
        }
        if sum == target {
            tmp := make([]int, len(path))
            copy(tmp, path)
            result = append(result, tmp)
            return
        }
        for j := i; j < len(candidates); j++ {
            path = append(path, candidates[j])
            sum += candidates[j]
            backtrack(j) // 传 j：同一个数可重复选
            path = path[:len(path)-1]
            sum -= candidates[j]
        }
    }

    backtrack(0)
    return result
}
```

## 细节 / 易错点

- **传 `j` 还是 `j+1`** 是"可不可重复选"的开关：传 `j` 可重复（本题），传 `j+1` 每个数用一次（0077）。
- **`sum` 与 `path` 成对加减**：撤销时两个都要回退（`path` 弹出、`sum` 减回去）。
- **剪枝**：`sum > target` 直接 `return`。进阶可先给 `candidates` 排序，循环里 `if sum+candidates[j] > target { break }`——升序后一旦超就能断掉整个 for（比 `continue` 更狠）。

## 复杂度

- 时间：**指数级，约 O(N^(target/m))**。`N` 个候选、最小值 `m` → 递归最深约 `target/m` 层，每层最多 `N` 个分支。剪枝（`sum>target`）实际砍掉大量分支，但最坏仍是指数。
- 空间：**O(target/m)**（不计输出）。递归深度最深 `target/m`，`path` 同量级。
