# 组合总和 III

## 题面

找出所有相加之和为 `n` 的 `k` 个数的组合，只能用数字 **1-9**，每个数字最多用一次，解集不含重复组合。

- 示例：`k=3, n=9` → `[[1,2,6],[1,3,5],[2,3,4]]`

## 思路

就是 **0077（k 个数，传 `j+1`）+ 0039（和约束 + 剪枝）** 的合体，没有新质：

- 候选固定 1-9 → for 从 `start` 到 `9`。
- 每个数最多一次 → 传 `j+1`。
- **双重终止**：必须 `len(path)==k` **且** `sum==n` 才收集。
- 剪枝：`sum > n` 提前 `return`。

## 完整代码

```go
func combinationSum3(k int, n int) [][]int {
    result := [][]int{}
    path := make([]int, 0, k)
    sum := 0

    var backtrack func(int)
    backtrack = func(i int) {
        if sum > n {
            return // 剪枝：和超了
        }
        if len(path) == k {
            if sum == n {
                tmp := make([]int, k)
                copy(tmp, path)
                result = append(result, tmp)
            }
            return // 凑够 k 个就到头，收没收都不能再往下
        }
        for j := i; j <= 9; j++ {
            path = append(path, j)
            sum += j
            backtrack(j + 1) // 每个数用一次
            path = path[:len(path)-1]
            sum -= j
        }
    }

    backtrack(1)
    return result
}
```

## 细节 / 易错点

- **`len(path)==k` 后一定要 `return`**：无论 `sum` 对不对，凑够 k 个就到头了，不能再往下选。漏写 `return` 不会错（更深的分支 `len≠k` 不收集、`sum>n` 会剪），但会让 for **空跑几次**——呼应「return 的剪枝作用」。
- **双约束缺一不可**：只判 `len==k` 会收进和不对的；只判 `sum==n` 会收进个数不对的。
- `sum` 与 `path` 成对加减。

## 复杂度

- 时间：**O(C(9,k) × k)**。从 9 个数里选 k 个的组合数为 `C(9,k)`，每个解深拷贝 `O(k)`；剪枝进一步收窄。
- 空间：**O(k)**（不计输出）。递归最深 `k` 层，`path` 占 `O(k)`。
