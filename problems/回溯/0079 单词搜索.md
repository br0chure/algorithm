# 单词搜索

## 题面

`m×n` 字符网格 `board` 和单词 `word`，判断 `word` 是否存在于网格中（相邻格水平/垂直连接，同一格不能重复用）。

- 示例：`word="ABCCED"` 在对应网格中 → `true`

## 思路

**二维网格 DFS + 回溯**：

- 每个格子都可能是起点 → 双重 for 遍历起点。
- `backtrack(r, c, k)`：从 `(r,c)` 匹配 `word[k]`。
  - 越界 / 字符不匹配 / 已访问 → `return`。
  - `k == len(word)-1`（匹配到最后一个字符）→ 找到。
  - 标记已访问 → 四方向递归 `word[k+1]` → 撤销标记。

## 完整代码

```go
func exist(board [][]byte, word string) bool {
    var result bool
    row, col := len(board), len(board[0])
    used := make([][]int, row)
    for i := 0; i < row; i++ {
        used[i] = make([]int, col)
    }

    var backtrack func(int, int, int)
    backtrack = func(m, n, k int) {
        if m < 0 || m == row || n < 0 || n == col {
            return // 越界
        }
        if board[m][n] != word[k] || used[m][n] == 1 {
            return // 字符不匹配 或 已访问
        }
        if k == len(word)-1 {
            result = true
            return // 匹配到最后一个字符
        }
        used[m][n] = 1 // 标记
        backtrack(m-1, n, k+1)
        backtrack(m+1, n, k+1)
        backtrack(m, n-1, k+1)
        backtrack(m, n+1, k+1)
        used[m][n] = 0 // 撤销
    }

    for i := 0; i < row; i++ {
        for j := 0; j < col; j++ {
            backtrack(i, j, 0)
        }
    }
    return result
}
```

## 细节 / 易错点

- **visited 两种方式（等价）**：
  - `used` 矩阵（本解）：清晰，额外 `O(m×n)` 空间。
  - **原地改标记**（`board[r][c]='#'`，回溯改回）：省 visited 空间到 `O(1)`，代价是临时改动输入。
- 标记进、撤销出（`used=1` → 四方向 → `used=0`），和 `path` 的 append/撤销一个道理。
- 小优化：`result=true` 后，各层加 `if result { return }` 提前终止，避免空搜。

## 复杂度

- 时间：**O(m×n×4ᴸ)**，`L=len(word)`。每个起点最多 `O(4ᴸ)`（每步 4 方向、深度 L）。
- 空间：**O(m×n)**（`used` 矩阵）+ `O(L)` 递归栈。原地改标记可省去 `used` 那块。
