# N 皇后

## 题面

`n×n` 棋盘放 `n` 个皇后，互不攻击（同行 / 同列 / 对角线）。返回所有摆法（`'Q'` 皇后，`'.'` 空位）。

- 示例：`n=4` → 2 种方案。

## 思路

**逐行放皇后**（A 类：本层 for 枚举候选列）：

- `backtrack(row)`：第 `row` 行放哪列。`for col` 遍历列，不冲突就放、递归 `row+1`、撤销。
- base case：`row == n`（放满）→ 收集。
- **冲突检测 O(1)**，三个标记数组：
  - `cols[col]`（列）
  - `diag1[row+col]`（副对角线，同一条 `row+col` 相同）
  - `diag2[n+row-col]`（主对角线，同一条 `row-col` 相同，`+n` 防负下标）
- 不查同行——一行只放一个，天然不冲突。

## 完整代码

```go
func solveNQueens(n int) [][]string {
    result := [][]string{}
    path := []string{}
    diag1 := make([]int, 2*n) // 副对角线 row+col
    diag2 := make([]int, 2*n) // 主对角线 row-col+n
    cols := make([]int, n)

    var backtrack func(int)
    backtrack = func(row int) {
        if row == n {
            tmp := make([]string, n)
            copy(tmp, path)
            result = append(result, tmp)
            return
        }
        for col := 0; col < n; col++ {
            if diag1[row+col] == 1 || diag2[n+row-col] == 1 || cols[col] == 1 {
                continue // 冲突，试下一列
            }
            path = append(path, toString(col, n))
            diag1[row+col], diag2[n+row-col], cols[col] = 1, 1, 1
            backtrack(row + 1)
            path = path[:len(path)-1]
            diag1[row+col], diag2[n+row-col], cols[col] = 0, 0, 0
        }
    }

    backtrack(0)
    return result
}

func toString(loc, n int) string {
    c := make([]byte, n)
    for i := 0; i < n; i++ {
        if i == loc {
            c[i] = 'Q'
        } else {
            c[i] = '.'
        }
    }
    return string(c)
}
```

## 细节 / 易错点

- **对角线规律**：主对角线（↘）`row-col` 相同、副对角线（↙）`row+col` 相同；`row-col` 会负，用 `+n` 偏移成正下标。
- **三个标记同进同退**：放皇后时 `cols/diag1/diag2` 一起置 1，撤销时一起置 0——像 `used`，只是三个联动。
- `col` 是 `for` 枚举的候选，不传参（A 类）；冲突判断是「候选验证」，for 里 `continue`。

## 复杂度

- 时间：**O(n!)**。第 1 行 `n` 种选法，第 2 行受列/对角线约束最多 `n-1`……总路径数约 `n!`；每找到一个解构造棋盘字符串 `O(n²)`。总体 `O(n! · n²)`，由 `n!` 主导。
- 空间：**O(n)**（不计输出）。递归深度 `n`；`cols`、`diag1`、`diag2` 各 `O(n)`；`path` 存 `n` 行。
