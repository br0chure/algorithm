# 子集

## 题面

给一个**互不相同**的整数数组 `nums`，返回它**所有可能的子集**（幂集），解集不含重复子集。

- 示例：`[1,2,3]` → `[[],[1],[2],[1,2],[3],[1,3],[2,3],[1,2,3]]`（共 2³ = 8 个，含空集）

## 思路

子集和组合的关键差别：**每个节点都是一个答案**（不只叶子）——`[]`、`[1]`、`[1,2]`…… 全都要。

- **收集位置在函数入口**：一进 `backtrack` 就收当前 `path`。根节点（`path` 还空着）顺带把**空集**收进来。
- **start 去重**：和组合一样只往后选，避免 `[1,2]`/`[2,1]` 重复。
- **不需要 base case**：`for i := start; i < len(nums)` 在 `start` 到末尾时自然不执行、函数自然返回——递归终止由 for 边界兜底。

## 完整代码

```go
func subsets(nums []int) [][]int {
    result := [][]int{}
    path := []int{}

    var backtrack func(int)
    backtrack = func(start int) {
        tmp := make([]int, len(path))
        copy(tmp, path)
        result = append(result, tmp) // 每个节点都是一个子集（含空集）

        for i := start; i < len(nums); i++ {
            path = append(path, nums[i]) // 选择
            backtrack(i + 1)             // 只往后选
            path = path[:len(path)-1]     // 撤销
        }
    }

    backtrack(0)
    return result
}
```

## 细节 / 易错点

- **收集放入口、不放 base case**：组合/排列"满了才收集"，所以写在 base case 里；子集每个节点都要，所以挪到函数入口。放对位置，空集 `[]` 自然被根节点收进来。
- **base case 可以不写**：若写 `if start == len(nums) { return }` 放在收集**之前**，会拦掉"选满"那个子集（漏 `[1,2,3]`）——因为收集在它之后。最干净的是不写：for 边界 `i < len(nums)` 已保证 `start` 到末尾时不再递归。
- **深拷贝**收集，老规矩。

## 复杂度

- 时间：**O(n × 2ⁿ)**。子集共 `2ⁿ` 个（每个元素选/不选），解空间树约 `2ⁿ` 个节点，每节点深拷贝当前 `path`（最长 `n`），故 `O(n × 2ⁿ)`。
- 空间：**O(n)**（不计输出）。递归最深 `n` 层，`path` 占 `O(n)`。输出 `result` 占 `O(n × 2ⁿ)`，不计入额外空间。
