# 电话号码的字母组合

## 题面

给一个仅含数字 `2-9` 的字符串，返回所有它能表示的字母组合（电话按键映射）。

- 示例：`"23"` → `["ad","ae","af","bd","be","bf"]`
- `digits==""` → `[]`

## 思路

回溯的**第三类**：候选**逐层独立**（不是同一个 nums）。

- 第 `index` 层的候选 = `digits[index]` 这个数字对应的字母串。
- 用 `index` 当递归参数逐层推进，每层遍历**本层自己的**字母。
- **不需要 `start`、不需要去重**：每个位置的候选独立、位置被 `digits` 顺序锁死，`ad` 和 `da` 不会同时出现。
- base case：`index == len(digits)`（每个数字都配了字母）。

## 完整代码

```go
func letterCombinations(digits string) []string {
    result := []string{}
    if len(digits) == 0 {
        return result // 空输入返回 []，不是 [""]
    }
    phone := map[byte]string{
        '2': "abc", '3': "def", '4': "ghi", '5': "jkl",
        '6': "mno", '7': "pqrs", '8': "tuv", '9': "wxyz",
    }
    path := make([]byte, 0, len(digits))

    var backtrack func(int)
    backtrack = func(index int) {
        if len(path) == len(digits) {
            result = append(result, string(path)) // string() 转换自带拷贝，无需 tmp
            return
        }
        letters := phone[digits[index]] // 先存，别在 for 里反复查 map
        for i := 0; i < len(letters); i++ {
            path = append(path, letters[i])
            backtrack(index + 1)
            path = path[:len(path)-1]
        }
    }

    backtrack(0)
    return result
}
```

## 细节 / 易错点

- **空输入**：`digits==""` 要返回 `[]`，否则会收进一个 `""` → `[""]`，错。
- **收集免手动深拷贝**：`string(path)` 转换本身就复制底层字节（字符串不可变），直接 `append(result, string(path))` 即可——和 `[]int` 必须 make+copy 不同。
- **map key 用 `byte`**：`digits[index]` 返回 byte，key 同类型免转换；用 int 得 `phone[int(...)]`。
- **不需要 start/去重**：见思路——逐层独立候选，位置锁死。

## 复杂度

- 时间：**O(4ⁿ × n)**，`n=len(digits)`。每个数字最多 4 个字母 → 最多 `4ⁿ` 个组合，每个 `string(path)` 拷贝 `O(n)`。
- 空间：**O(n)**（不计输出）。递归最深 `n` 层，`path` 占 `O(n)`。
