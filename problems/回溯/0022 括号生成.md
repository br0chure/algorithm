# 括号生成

## 题面

`n` 对括号，生成所有**合法**组合。

- 示例：`n=3` → `["((()))","(()())","(())()","()(())","()()()"]`

## 思路

不是"从候选里选"，而是**每一位填 `(` 或 `)`**，用约束保证合法：

- 填 `(` 的条件：`left < n`（左括号没用完）
- 填 `)` 的条件：`right < left`（右括号不能超过左）
- base case：`len(path) == 2n`（填满）→ 收集。

**两个 if = 拆开的 for**：当前层就两个候选（`(`/`)`），约束不同，各自 `append → 递归 → 撤销`。

## 完整代码

```go
func generateParenthesis(n int) []string {
    result := []string{}
    path := make([]byte, 0, 2*n)
    left, right := 0, 0

    var backtrack func()
    backtrack = func() {
        if len(path) == 2*n {
            result = append(result, string(path))
            return
        }
        if left < n { // 还能放左括号
            path = append(path, '(')
            left++
            backtrack()
            path = path[:len(path)-1]
            left--
        }
        if right < left { // 右括号不超过左，才能放
            path = append(path, ')')
            right++
            backtrack()
            path = path[:len(path)-1]
            right--
        }
    }

    backtrack()
    return result
}
```

## 细节 / 易错点

- **append 必须在递归之前**（选了才能往下走，回溯铁律）；**判满在 append 之后**（放完才知满没满）——顺序反了就收集不到。
- **两个 if 各 `append/撤销` 一次**：当前层两个候选各选各的。区别于二叉树（当前层值定 `node.Val`，只 append 一次）——这就是「值选 vs 值定」。
- `left/right` 全局变量要**成对 `++/--`**（或改用参数传，值传递自动回溯，省手动撤销）。

## 复杂度

- 时间：**O(4ⁿ / √n)**（卡特兰数级）。合法组合数是第 `n` 个卡特兰数 ≈ `4ⁿ/(n√n)`，每个 `O(n)` 拼接。
- 空间：**O(n)**（不计输出）。递归最深 `2n`，`path` 占 `O(n)`。
