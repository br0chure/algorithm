# 组合总和 II

## 题面

给一个**可能含重复元素**的数组 `candidates` 和 `target`，找所有和为 `target` 的组合。**每个数字在每个组合里只能用一次**，解集不含重复组合。

- 示例：`candidates=[10,1,2,7,6,1,5], target=8` → `[[1,1,6],[1,2,5],[1,7],[2,6]]`

## 思路

0039 的"输入去重"版，两处关键：

- **每个数用一次** → 递归传 `j+1`（不是 0039 的 `j`）。
- **输入有重复** → **排序 + 同层去重**：`if j > i && candidates[j]==candidates[j-1] { continue }`。

同层去重的核心（`j > i` 而非 `j > 0`）：排序后相同值相邻；`j > i` 锁定"**本层** for 已经选过相同值"（同层重复，跳过）；`j == i`（本层第一个）的相同值来自上一层（跨层，如 `[1,1]`），必须保留。

## 完整代码

```go
import "sort"

func combinationSum2(candidates []int, target int) [][]int {
    sort.Ints(candidates) // 排序，让相同值相邻（去重前提）
    result := [][]int{}
    path := []int{}
    sum := 0

    var backtrack func(int)
    backtrack = func(i int) {
        if sum > target {
            return
        }
        if sum == target {
            tmp := make([]int, len(path))
            copy(tmp, path)
            result = append(result, tmp)
            return // 和达标，再加只会更大，剪枝
        }
        for j := i; j < len(candidates); j++ {
            if j > i && candidates[j] == candidates[j-1] {
                continue // 同层去重：本层已选过相同值
            }
            path = append(path, candidates[j])
            sum += candidates[j]
            backtrack(j + 1) // 每个数用一次
            path = path[:len(path)-1]
            sum -= candidates[j]
        }
    }

    backtrack(0)
    return result
}
```

## 细节 / 易错点

- **`j > i` 不是 `j > 0`**：`i` 是本层 for 起点，它把"同层"和"跨层"切开。同层重复要跳，跨层相同（`[1,1]`）要留。
- **必须先排序**：去重靠"相同值相邻"，不排序整个判断失效。
- **`sum==target` 后 `return`**：排序后都是正数，再加必然超，剪掉无用分支（同 0216 的习惯）。

## 复杂度

- 时间：**O(2ⁿ × n)** 量级。最坏每个数选/不选共 `2ⁿ` 个分支，去重 + `sum` 剪枝实际远小于此；每个解深拷贝 `O(n)`。
- 空间：**O(n)**（不计输出）。递归最深 `n` 层，`path` 占 `O(n)`。
