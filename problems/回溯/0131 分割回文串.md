# 分割回文串

## 题面

把字符串 `s` 分割成若干子串，使**每个子串都是回文**。返回所有分割方案。

- 示例：`s="aab"` → `[["a","a","b"],["aa","b"]]`

## 思路

**切分型回溯 = 子集的「选一段」版**。骨架和子集完全一样（`for j:=start` + `backtrack(j+1)`），只是：

- `start` = 当前段**开头**、`j` = 当前段**结尾**、`s[start:j+1]` = 这一段。
- 只有这段**回文**才选、才递归 `backtrack(j+1)`（切剩下的串）。
- **base case `start==len(s)`**：整串切完、每段都已回文 → 收集。

和子集**唯一的实质区别**：必须切到**整串结束**才算一个答案（子集是每个节点都收）。**不用去重**——按位置切，顺序锁死。

## 完整代码

```go
func partition(s string) [][]string {
    result := [][]string{}
    path := []string{}

    var backtrack func(int)
    backtrack = func(start int) {
        if start == len(s) { // 整串切完 = 一个完整方案
            tmp := make([]string, len(path))
            copy(tmp, path)
            result = append(result, tmp)
            return
        }
        for j := start; j < len(s); j++ {
            sub := s[start : j+1] // 当前段 [start, j]
            if !isPalindrome(sub) {
                continue // 不回文，这种切法作废
            }
            path = append(path, sub)
            backtrack(j + 1) // 切剩下的
            path = path[:len(path)-1]
        }
    }

    backtrack(0)
    return result
}

func isPalindrome(s string) bool {
    for l, r := 0, len(s)-1; l < r; l, r = l+1, r-1 {
        if s[l] != s[r] {
            return false
        }
    }
    return true
}
```

## 细节 / 易错点

- **`start` 段头、`j` 段尾、`s[start:j+1]` 这一段**；`backtrack(j+1)` 切剩下的（下一段头 = 上一段尾 +1）。
- **base case 是 `start==len(s)`**：分割必须整串切完才是答案，和子集「每节点都收」不同——这是切分 vs 子集的分界。
- **不用去重**：按位置切、顺序锁死，天然不重复。
- 回文判断双指针 `l/r` 往中间收。

## 复杂度

- 时间：**O(n × 2ⁿ)**。长度 `n` 的串有 `n-1` 个缝隙，每缝切/不切 → 最多 `2ⁿ⁻¹` 种分割；每种回文校验 + 深拷贝 `O(n)`。
- 空间：**O(n)**（不计输出）。递归最深 `n` 层，`path` 占 `O(n)`。
