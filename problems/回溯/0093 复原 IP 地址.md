# 复原 IP 地址

## 题面

给一个只含数字的字符串 `s`，插入 3 个点分成 **4 段**，每段是合法 IP（`0-255`，无前导 0）。返回所有可能的合法 IP 地址。

- 示例：`"25525511135"` → `["255.255.11.135","255.255.111.35"]`

## 思路

**0131 切分型的双胞胎**，三处变化：

- **段数固定 4**：`len(path)==4` 就到头（`len(path)` 天然记段数，不用额外变量）。
- **过滤条件**换成"合法 IP 段"（`isValid`）。
- **base case 双约束**：`len(path)==4 && start==len(s)` 才收集——4 段且字符用完。
- 剪枝：每段最多 3 位（`i < start+3`）。

## 完整代码

```go
func restoreIpAddresses(s string) []string {
    result := []string{}
    path := []string{}

    var backtrack func(int)
    backtrack = func(start int) {
        if len(path) == 4 { // 够 4 段就到头
            if start == len(s) { // 且字符用完 → 合法
                result = append(result, strings.Join(path, "."))
            }
            return
        }
        for i := start; i < len(s) && i < start+3; i++ { // 每段最多 3 位
            sub := s[start : i+1]
            if !isValid(sub) {
                continue
            }
            path = append(path, sub)
            backtrack(i + 1)
            path = path[:len(path)-1]
        }
    }

    backtrack(0)
    return result
}

func isValid(s string) bool {
    if len(s) > 3 {
        return false
    }
    if n, _ := strconv.Atoi(s); n > 255 {
        return false
    }
    if len(s) > 1 && s[0] == '0' { // 单个 "0" 合法，前导 0 才非法
        return false
    }
    return true
}
```

## 细节 / 易错点

- **段数用 `len(path)` 记，别再加变量**：`path` 存了每段，`len(path)` 就是段数——同一个信息别记两遍（cutSum 冗余）。
- **前导 0**：单个 `"0"` 合法（`0.0.0.0`）；只有 `len>1 && s[0]=='0'` 才非法。这是最常踩的坑。
- **base case 双约束**：`len(path)==4` 且 `start==len(s)`。"字符用完但不够 4 段"由 for 边界自然兜底，不用单独写。
- base case 里 `len(path)==4` 就 `return`（无论字符用没用完），是 return 的剪枝。

## 复杂度

- 时间：**O(1)**（常数级）。段数固定 4、每段最多 3 位 → 搜索空间 ≤ `3⁴` 是常数，与串长无关。
- 空间：**O(1)**。`path` 最多 4 段，递归最深 4 层。
