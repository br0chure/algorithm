# 二叉树的后序遍历

## 题面

给你二叉树的根节点 `root`，返回它节点值的**后序遍历**（左 → 右 → 根）。

样例：
- `root = [1,null,2,3]` → `[3, 2, 1]`
- `root = []` → `[]`

约束：节点数 `0 ≤ n ≤ 100`。

## 主解：取巧法（伪前序 + 反转）

直接迭代后序很难——需要标记节点是否已访问，因为根要在子树都处理完之后才能访问。

**取巧**：

```
真后序: 左 → 右 → 根
反过来:
        根 → 右 → 左   ← 这是一种"伪前序"（左右互换）

伪前序得到的序列 reverse 后 = 真后序
```

所以**只要写一个"先入左、后入右"的迭代前序**，最后整体反转即可。

### 与 144 前序的对比

| 操作 | 144 前序 | 145 取巧后序 |
|---|---|---|
| 入栈顺序 | 先右后左（让左先弹） | **先左后右**（让右先弹） |
| 最后 | 直接返回 | **整体反转 result** |

### 代码

```go
func postorderTraversal(root *TreeNode) []int {
    if root == nil {
        return []int{}
    }
    result := make([]int, 0)
    stack := []*TreeNode{root}
    for len(stack) > 0 {
        node := stack[len(stack)-1]
        stack = stack[:len(stack)-1]
        result = append(result, node.Val)
        if node.Left != nil {
            stack = append(stack, node.Left)    // 先左
        }
        if node.Right != nil {
            stack = append(stack, node.Right)   // 后右 → 栈顶 → 下次先弹
        }
    }
    // 整体反转
    for i, j := 0, len(result)-1; i < len(result)/2; i, j = i+1, j-1 {
        result[i], result[j] = result[j], result[i]
    }
    return result
}
```

### 跟踪样例 `[1, null, 2, 3]`

```
    1
     \
      2
     /
    3
```

| 步骤 | stack | result |
|---|---|---|
| 初始 | [1] | [] |
| 弹 1，加 result，推右（2） | [2] | [1] |
| 弹 2，加 result，推左（3） | [3] | [1,2] |
| 弹 3，加 result | [] | [1,2,3] |
| 反转 | | **[3,2,1]** ✓ |

## 备用解：递归版（Type A 自递归合并）

```go
func postorderTraversal(root *TreeNode) []int {
    if root == nil {
        return nil
    }
    result := postorderTraversal(root.Left)
    result = append(result, postorderTraversal(root.Right)...)
    result = append(result, root.Val)
    return result
}
```

只需把 `root.Val` 放到最后追加——和 144 同模板，三序差别就在 `root.Val` 的位置。

## 复杂度

### 主解（迭代取巧）

- **时间：O(n)**——每个节点入栈/出栈各 1 次（O(n)），反转 O(n/2)，总 O(n)。
- **空间：O(h)**——栈深度等于路径长度。
