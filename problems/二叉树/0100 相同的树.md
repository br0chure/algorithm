# 相同的树

## 题面

给你两棵二叉树的根节点 `p` 和 `q`，编写一个函数来检验两棵树是否相同。**结构相同 + 节点值相同**才算相同。

样例：
- `p = [1,2,3]`、`q = [1,2,3]` → `true`
- `p = [1,2]`、`q = [1,null,2]` → `false`（结构不同）
- `p = [1,2,1]`、`q = [1,1,2]` → `false`（值不同）

约束：节点数 `0 ≤ n ≤ 100`，`-10^4 ≤ Node.val ≤ 10^4`。

## 思路

**Pattern：tree_subtree · 双树同步递归 · 同向配对**（详见 `patterns/二叉树/tree_subtree.md`）。

### 三问（双树版本）

| 问题 | 答案 |
|---|---|
| 1. 「两棵树相同」的递归定义 | 根值相等 + 两棵树的左子树相同 + 两棵树的右子树相同 |
| 2. base case | 两棵都 nil 相同；一 nil 一非 nil 不同；两棵都非 nil 比 Val |
| 3. 配对怎么进 | **同向配对**：`(p.Left, q.Left)` + `(p.Right, q.Right)` |

> 关键标志：函数签名带两个 node 参数，且**两个参数都在推进**——这就是双树同步递归。

## 完整代码

```go
func isSameTree(p *TreeNode, q *TreeNode) bool {
    if p == nil && q == nil {
        return true
    }
    if p == nil || q == nil {
        return false
    }
    if p.Val != q.Val {
        return false
    }
    left := isSameTree(p.Left, q.Left)
    right := isSameTree(p.Right, q.Right)
    return left && right
}
```

## 与 101 对称二叉树对比

100 是 `tree_subtree` pattern 最干净的入门题，101 是 100 的「镜像变体」：

| | 100 相同的树 | 101 对称二叉树 |
|---|---|---|
| 配对方式 | **同向**：`(p.Left, q.Left)` + `(p.Right, q.Right)` | **交叉**：`(p.Left, q.Right)` + `(p.Right, q.Left)` |
| 入口 | 用户给两棵树 `p`、`q` | 用户给一棵树 `root`，把它的左右子树看成两棵 |
| Helper 必需吗？ | 否（LC 入口就是 `(p, q)` 双参） | 是（LC 入口是单参 `root`，需要桥接） |

100 → 101 的本质差别只在第 3 问：「配对方向」从同向变成交叉。**双树同步递归的骨架完全一样**。

## 复杂度

- **时间：O(n)**——n 是较小一棵树的节点数。任何一对配对发现不同就 return false，不会展开更深。最坏情况两棵树完全相同，所有节点都遍历一次。
- **空间：O(h)**——递归栈，h 为树高（最坏链状 O(n)、平衡 O(log n)）。

  栈帧只装 `p`、`q` 两个指针 + 元信息，O(1)；函数体没有动态分配。
