# 二叉树的右视图

## 题面

给定一棵二叉树的根 `root`，想象自己站在它的右侧，按从顶到底的顺序，返回从右侧所能看到的节点值。

样例：
- 输入 `root = [1,2,3,null,5,null,4]` → 输出 `[1, 3, 4]`
- 输入 `root = [1,null,3]` → 输出 `[1, 3]`
- 输入 `root = []` → 输出 `[]`

⚠️ 注意：右视图 ≠ 每层右子节点。若某层右子树为空，左子树节点会"露出来"。

约束：节点数 `0 ≤ n ≤ 100`，`-100 ≤ Node.val ≤ 100`。

## 思路

**Pattern：树的 BFS（102 的小变体）**。

模板与 102 完全一致，唯一差别在每层只取**最后一个出队节点**的 Val：

1. 队列 BFS，外层每轮先 `levelSize := len(queue)` 锁定本层节点数。
2. 内层循环里——**每个**出队节点都要把左右孩子入队（不分最后一个与否）。
3. 当 `i == levelSize-1` 时，当前 `node` 就是本层最右节点，记录其 `Val`。
4. 一层结束把记录值追加进 `result`。

### 易错点（首次写时踩过的坑）

- ❌ 入队时写成 `root.Left / root.Right` —— 永远在重复塞根的孩子，**死循环**。
- ❌ 把入队动作放在内层循环外（按"层"入队，且只塞 root 的孩子）—— 双重错误。

> 💡 **心法**：BFS 中"弹出节点 + 把它的左右孩子入队"是每个节点的标配动作，和"它是不是本层最后一个"完全无关。`levelSize` 只用来分层，不影响节点级动作。

## 完整代码

```go
func rightSideView(root *TreeNode) []int {
    result := make([]int, 0)
    if root == nil {
        return result
    }
    queue := []*TreeNode{root}
    var rightVal int
    for len(queue) > 0 {
        levelSize := len(queue)
        for i := 0; i < levelSize; i++ {
            node := queue[0]
            queue = queue[1:]
            if node.Left != nil {
                queue = append(queue, node.Left)
            }
            if node.Right != nil {
                queue = append(queue, node.Right)
            }
            if i == levelSize-1 {
                rightVal = node.Val
            }
        }
        result = append(result, rightVal)
    }
    return result
}
```

## 复杂度

- 时间：O(n)，每个节点恰好出入队列一次。
- 空间：O(n)，队列最坏需存约半层节点。
