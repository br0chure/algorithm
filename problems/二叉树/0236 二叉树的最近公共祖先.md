# 二叉树的最近公共祖先

## 题面

给定一个二叉树，找到该树中两个指定节点 `p` 和 `q` 的**最近公共祖先**（LCA）。

> LCA = 树中**深度最深**的节点 x，满足 x **同时是 p 和 q 的祖先**。
> **一个节点也可以是它自己的祖先**——p 是 q 的祖先时，LCA = p。

约束：节点数 `2 ≤ n ≤ 10^5`，所有节点值唯一，**p 和 q 都保证存在于树中**。

## 思路

**Pattern：tree_dfs · Type B**（返回值是子树"信号"，全局变量记答案）。

### 三问

| 问题 | 答案 |
|---|---|
| 1. 递归返回什么？ | `bool`：以 node 为根的子树**是否包含 p 或 q** |
| 2. base case？ | `node == nil` → false |
| 3. 当前节点做什么？ | 看左、右、自己三个"信号"，判断当前 node 是不是 LCA |

### 关键判断：什么时候 node 是 LCA？

设 `left = dfs(node.Left)`、`right = dfs(node.Right)`、`self = (node == p 或 node == q)`，**两种情况让 node 成为 LCA**：

| 情况 | left | right | self | 说明 |
|---|---|---|---|---|
| A | ✓ | ✓ | - | 左右子树各包含一个 → node 是它俩的最深共同祖先 |
| B | (任一为 ✓) | (任一为 ✓) | ✓ | node **自己就是 p/q**，另一个在子树里 → 自己是自己的祖先 → node 是 LCA |

发现 node 是 LCA 时**记到全局变量** `ans`。

### 返回值：把"是否包含 p/q"的信号传上去

```go
return left || right || self
```

含义：「以我为根的子树**是否包含 p 或 q**」——左子树有 OR 右子树有 OR 我自己就是。

## 完整代码

```go
func lowestCommonAncestor(root, p, q *TreeNode) *TreeNode {
    var ans *TreeNode
    var dfs func(*TreeNode) bool
    dfs = func(node *TreeNode) bool {
        if node == nil {
            return false
        }
        left := dfs(node.Left)
        right := dfs(node.Right)
        self := node == p || node == q

        if left && right {           // 情况 A：左右各一个
            ans = node
        }
        if (left || right) && self { // 情况 B：自己是一个 + 子树里有另一个
            ans = node
        }

        return left || right || self
    }
    dfs(root)
    return ans
}
```

## 备用解：压缩版（返回 *TreeNode）

LC 题解里常见的"信号 + 身份合一"写法——同一个 `*TreeNode` 返回值同时承载"找到的信号"和"节点身份"：

```go
func lowestCommonAncestor(root, p, q *TreeNode) *TreeNode {
    if root == nil { return nil }
    if root == p || root == q { return root }
    left := lowestCommonAncestor(root.Left, p, q)
    right := lowestCommonAncestor(root.Right, p, q)
    if left != nil && right != nil {
        return root
    }
    if left != nil {
        return left
    }
    return right
}
```

更短（10 行 vs 13 行），但**含义不统一**——返回值可能是 p、q、LCA、或 nil。**信号和身份压在同一个 `*TreeNode` 里**。

`base case` 找到 p / q 就立刻返回（不继续探索）——靠题目保证「p、q 一定存在」让算法自然涌现正确答案。

## 两种写法对比

| | 主解（Type B） | 备用解（Type A 压缩版） |
|---|---|---|
| 返回值含义 | 单一：是否包含 p/q（bool） | 多重：p / q / LCA / nil |
| 全局变量 | 需要 `ans` | 不需要 |
| 代码长度 | 13 行 | 10 行 |
| 思路清晰 | ⭐⭐⭐⭐（信号和答案分离） | ⭐⭐（"压缩"含义） |
| LC 流行度 | 教科书风格 | 更常见 |

熟练后可以用备用解（更精炼）。初学用主解（思路清晰）。

## 复杂度

- **时间：O(n)**——每个节点访问 1 次。
- **空间：O(h)**——递归栈深度 = 树高。`ans` 是单指针，O(1)。

## 关于 236 的"独特感"
