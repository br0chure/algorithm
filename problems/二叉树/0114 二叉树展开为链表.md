# 二叉树展开为链表

## 题面

给你二叉树的根节点 `root`，请你将它**展开为一个单链表**：

- 用同一个 `TreeNode` 结构
- `Right` 指向链表下一个节点
- `Left` 始终为 `nil`
- 节点顺序 = 二叉树**前序遍历**顺序

要求**原地修改**。

样例：
```
原树:         展开后:
   1              1
  / \              \
 2   5              2
/ \   \              \
3 4    6              3
                       \
                        4
                         \
                          5
                           \
                            6
```

约束：节点数 `0 ≤ n ≤ 2000`，`-100 ≤ Node.val ≤ 100`。

## 主解：递归前序收集 + 后串（思路 A）

最直观分两步：

1. **前序 DFS 收集**所有节点到 list
2. **遍历 list** 把每个节点的 `Right` 设成下一个、`Left` 设成 nil

### 代码

```go
func flatten(root *TreeNode) {
    if root == nil { return }
    var list []*TreeNode

    var dfs func(*TreeNode)
    dfs = func(node *TreeNode) {
        if node == nil { return }
        list = append(list, node)
        dfs(node.Left)
        dfs(node.Right)
    }

    var toList func(*TreeNode, []*TreeNode)
    toList = func(root *TreeNode, list []*TreeNode) {
        if root == nil { return }
        for _, t := range list {
            root.Left = nil
            root.Right = t
            root = root.Right
        }
    }

    dfs(root)
    toList(root, list[1:])    // list[0] 是 root 本身，从 list[1:] 开始串
}
```

为什么 `list[1:]`：避免 root 自己挂到自己（自环）。从第二个节点开始挂到 root 后面。

**复杂度**：O(n) 时间，O(n) 空间（list）。

## 变体 1：递归 + prev 指针（边走边串）

省掉显式 list，用一个**链尾指针 prev** 边遍历边挂。`dummy` 节点避免"第一个节点"特判。

### 代码

```go
func flatten(root *TreeNode) {
    if root == nil { return }
    dummy := &TreeNode{}
    prev := dummy

    var dfs func(*TreeNode)
    dfs = func(node *TreeNode) {
        if node == nil { return }
        // ⚠️ 先存左右孩子（下面要改 node，避免"先改后读"bug）
        left, right := node.Left, node.Right

        node.Left = nil
        prev.Right = node
        prev = node

        dfs(left)
        dfs(right)
    }
    dfs(root)
}
```

### 关键 1：`dummy` 哨兵节点

`dummy` 是临时占位，让 prev 一开始就有值，避免每次循环检查 `if prev == nil`。第一次 `prev.Right = node` 会把 `dummy.Right` 设成 root（无害——dummy 反正要扔）。

**这是链表题里的经典 trick**——链表合并、反转、删除都常用。

### 关键 2：先存 left/right 再改 node

```go
left, right := node.Left, node.Right    // 先存
node.Left = nil                          // 再改
prev.Right = node
prev = node
dfs(left)                                // 用存的副本递归
dfs(right)
```

如果不存副本，递归 `dfs(node.Right)` 会跳到新串上而不是原右子树——**死循环 / 乱序**。**心法**：边遍历边改时，**先存"我要读的指针副本"，再改 node**。

**复杂度**：O(n) 时间，O(h) 空间（递归栈）。比主解省 O(n) 的 list。

## 变体 2：左子树最右节点（O(1) 额外空间）

LC 经典 trick，纯迭代，**O(1) 空间**。

### 思路

前序展开 = `根 → 左子树前序 → 右子树前序` 串成一条线。

在节点 `cur` 处，要把**左子树整体塞到 cur 和原右子树之间**。
关键操作：**找左子树的最右节点 rightmost，把 cur 的原右子树挂到 rightmost.Right**——这样左子树整体就能替换 cur.Right。

### 一步操作分解

```
原:                  操作后:
  cur                  cur
  /  \                   \
 L    R                   L
                          ...（左子树原结构不变）
                           ↘
                            R   ← R 接到 L 的最右下方
```

代码：

```go
func flatten(root *TreeNode) {
    cur := root
    for cur != nil {
        if cur.Left != nil {
            // 找左子树的最右节点
            rightmost := cur.Left
            for rightmost.Right != nil {
                rightmost = rightmost.Right
            }
            rightmost.Right = cur.Right    // 原右子树挂到 rightmost
            cur.Right = cur.Left            // 左子树整体替换右
            cur.Left = nil                  // 清左
        }
        cur = cur.Right                     // 前进到下一个
    }
}
```

### 跟踪样例

```
   1
  / \
 2   5
/ \   \
3 4    6
```

| cur | 左子树 | rightmost | 操作后 |
|---|---|---|---|
| 1 | 2 | 4（2→4 走右到底）| `1→2→3→4→5→6`（链条但有左 Left=3）|
| 2 | 3 | 3 | `1→2→3→4→5→6`（链条更纯）|
| 3, 4, 5, 6 | 无 | - | 只 `cur = cur.Right` 前进 |

最终：`1 → 2 → 3 → 4 → 5 → 6` ✓

### 为什么 O(n) 时间

每条边只被访问常数次——cur 走过一次，rightmost 找最右路径上每个节点也只走过常数次（摊销分析）。

**复杂度**：O(n) 时间，O(1) 额外空间（cur、rightmost 两个指针）。

## 三种解法对比

| 解法 | 时间 | 空间 | 实现复杂度 |
|---|---|---|---|
| 主解：递归收集 + 后串 | O(n) | O(n)（list） | ⭐ 最简 |
| 变体 1：prev 指针 + 边走边串 | O(n) | O(h)（递归栈） | ⭐⭐ 中等 |
| 变体 2：左子树最右节点 | O(n) | **O(1)** | ⭐⭐⭐ 最巧 |

## 踩坑笔记

### 坑 1：找最右节点的 for 条件

```go
// ❌ 错的（会走过头到 nil）
for rightmost != nil {
    rightmost = rightmost.Right
}
// 出循环时 rightmost == nil

// ✅ 对的（停在最后一个非 nil）
for rightmost.Right != nil {
    rightmost = rightmost.Right
}
// 出循环时 rightmost 是最右节点
```

**记忆抓手**：想拿"最后一个非 nil"，**条件查"下一个"**——`for x.Next != nil { x = x.Next }`。

这条以后刷链表题（找尾节点、反转、合并）会**反复用到**。

### 坑 2：先改后读

`prev.Right = node` 之后再 `dfs(node.Right)`——`node.Right` 已被改！要在改之前**保存 right 副本**：

```go
left, right := node.Left, node.Right    // 先存
// ...改 node...
dfs(left); dfs(right)                    // 用副本
```

**心法**：边遍历边改时，**先存"我要读的指针副本"**。

### 坑 3：BFS 不能解（顺序错）

BFS 是层序，得到 `1, 2, 5, 3, 4, 6`。展开要的是前序 `1, 2, 3, 4, 5, 6`。**用 BFS 一定错**——必须用前序 DFS。
