# 二叉搜索树中第 K 小的元素

## 题面

给定一棵二叉搜索树的根节点 `root` 和一个整数 `k`，返回其中第 `k` 小的元素（**1-indexed**）。

样例：
- `root = [3,1,4,null,2]`、`k = 1` → `1`
- `root = [5,3,6,2,4,null,null,1]`、`k = 3` → `3`

约束：`1 ≤ k ≤ n ≤ 10^4`，`0 ≤ Node.val ≤ 10^4`。

## 思路

**Pattern：bst · 中序遍历**——BST 的中序遍历是**严格升序**序列，所以「第 k 小」就是「中序遍历的第 k 个节点」。

不需要把整个序列收集出来——**边遍历边计数**，到第 k 个就停。

### 三问

| 问题 | 答案 |
|---|---|
| 1. 递归返回什么？ | 不返回（用闭包共享 `count` 和 `result`） |
| 2. base case？ | `node == nil` 或 `count >= k`（真正的全局短路） |
| 3. 当前节点做什么？ | 中序顺序：递归左 → `count++`，命中就记录 `result` 并 return → 递归右 |

## 完整代码（主解）

```go
func kthSmallest(root *TreeNode, k int) int {
    count, result := 0, 0
    var dfs func(*TreeNode)
    dfs = func(node *TreeNode) {
        if node == nil || count >= k {
            return
        }
        dfs(node.Left)
        count++
        if count == k {
            result = node.Val
            return
        }
        dfs(node.Right)
    }
    dfs(root)
    return result
}
```

### 关键：真正的全局短路

```go
if node == nil || count >= k { return }
```

`count >= k` 这个检查放在**每次递归入口**——一旦命中第 k 个，**所有层级**的后续 dfs 调用都会立刻返回。整个 DFS 真的停下来。

## 备用解：先收集中序、再取下标

```go
func kthSmallest(root *TreeNode, k int) int {
    midOrder := make([]int, 0)
    var i int
    var bst func(*TreeNode)
    bst = func(node *TreeNode) {
        if node == nil { return }
        bst(node.Left)
        midOrder = append(midOrder, node.Val)
        if i++; i == k { return }
        bst(node.Right)
    }
    bst(root)
    return midOrder[k-1]
}
```

**能 AC，但有两个改进空间**：

1. **没有真正短路**：`if i++; i == k { return }` 只跳过**当前节点的 bst(right)**——父节点的 bst(right) 还会继续跑。所以达到 k 之后，midOrder 还会被 append 更多 Val（只是你不读它们）。极端情况下（k=1，10000 节点）几乎遍历完整棵树。
2. **midOrder 切片是多余的**：题目只要第 k 个值，没必要收集全部中序。多用了 O(n) 空间。

主解用 `count` + `result` + 全局短路检查，把空间从 O(n) 降到 O(h)，时间从「最坏遍历完整棵树」降到「访问到第 k 个节点就停」。

## 与 98 验证 BST · 方法 2 的对比

两题都是「中序遍历 + 闭包共享状态」，骨架完全一样：

| | 98 验证 BST | 230 第 k 小 |
|---|---|---|
| 共享状态 | `prev` 指针 | `count` + `result` |
| 短路条件 | `prev.Val >= node.Val` | `count >= k` |
| 短路位置 | 比较失败时 return false | 入口检查 + 命中时记录 |

> **BST 中序题的通用骨架**：「**闭包 + 共享状态变量 + 入口短路**」。状态变量用什么取决于题目要什么——验证就用 prev，找第 k 个就用 count，求最小绝对差也用 prev。

## 复杂度

### 主解

- **时间：O(h + k)**——递归先沉到最左叶子（O(h)），然后中序访问 k 个节点就停。最坏情况（k = n + 链状树）退化成 O(n)。
- **空间：O(h)**——递归栈，h 为树高。

### 备用解（先收集再取）

- **时间：O(n)**——总是遍历完整棵树（不真正短路）。
- **空间：O(n)**——`midOrder` 切片。
