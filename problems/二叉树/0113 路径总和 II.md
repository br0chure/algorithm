# 路径总和 II

## 题面

给你二叉树的根节点 `root` 和一个整数 `targetSum`，**找出所有**从根节点到叶子节点路径总和等于 targetSum 的路径。

返回所有合法路径，每条路径是节点值的列表。

样例：
- `root = [5,4,8,11,null,13,4,7,2,null,null,5,1]`、`targetSum = 22` → `[[5,4,11,2], [5,8,4,5]]`
- `root = [1,2,3]`、`targetSum = 5` → `[]`

约束：节点数 `0 ≤ n ≤ 5000`，`-1000 ≤ Node.val, targetSum ≤ 1000`。

## 思路

**Pattern：tree_path · DFS + 回溯** —— 是 **257（收集所有路径）+ 112（和的判断）** 的合体。

答案是路径**集合**（`[][]int`） → 必须用回溯收集 path。
顺便维护累加 `sum`，到叶子时判断 `sum == targetSum`。

### 三问

| 问题 | 答案 |
|---|---|
| 1. 递归返回什么？ | `void`（答案是集合，用外部 `result` 收集） |
| 2. base case？ | `node == nil` 直接 return |
| 3. 当前节点做什么？ | 进入：path 加入 Val、sum += Val；叶子时判断收集；离开：path 弹出、sum -= Val（**两个都回溯**） |

## 完整代码

```go
func pathSum(root *TreeNode, targetSum int) [][]int {
    result := [][]int{}
    path := []int{}
    sum := 0
    var dfs func(*TreeNode)
    dfs = func(node *TreeNode) {
        if node == nil {
            return
        }
        path = append(path, node.Val)             // 进入：path 加入
        sum += node.Val                            // 进入：sum 累加

        if node.Left == nil && node.Right == nil {
            if sum == targetSum {
                result = append(result, append([]int{}, path...))   // ⚠️ 深拷贝
            }
        } else {
            dfs(node.Left)
            dfs(node.Right)
        }

        path = path[:len(path)-1]                  // 离开：path 弹出
        sum -= node.Val                            // 离开：sum 减回
    }
    dfs(root)
    return result
}
```

## 关键点：深拷贝 path

```go
result = append(result, append([]int{}, path...))
```

`append([]int{}, path...)` 创建**新切片 + 新底层数组**，把 path 的内容复制进去。后续 `path = path[:len(path)-1]` 改的是原 path，不影响已存入 result 的拷贝。

**如果直接 `result = append(result, path)`**——`path` 的 header 被存进 result，但底层数组共享。后续回溯修改底层数组时，已收集的路径**会被污染**。

> 这条规律：**回溯收集 `[]int`（引用类型）必须深拷贝；收集 `string` 不需要（Go 字符串不可变）**。

## 复杂度

- **时间：O(n²)**——每个节点访问 1 次；找到合法路径时深拷贝 O(h)；最坏所有叶子都合法 + 满二叉树 → O(n × h) = O(n log n)；链状最坏 O(n²)。
- **空间：O(h + L·h)**——递归栈 + path 栈是 O(h)；result 存所有合法路径，最坏 L 条 × 每条 h 长 = O(L·h)。result 通常按惯例不计入辅助空间。
