# 删除二叉搜索树中的节点

## 题面

给定 BST 的根节点 `root` 和一个值 `key`，**删除 BST 中值等于 key 的节点**。返回删除后的 BST 根节点。

删除后的树**仍必须是合法 BST**。如果 key 不存在，返回原树。

约束：节点数 `0 ≤ n ≤ 10^4`，`-10^5 ≤ Node.val, key ≤ 10^5`，节点值唯一。

## 思路

**Pattern：bst · 左小右大递归 + 返回值修剪树指针**——和 701 插入是镜像题，但 case D 需要"重新拼接子树"。

### 整体结构

```
1. 定位目标：用 BST 性质走到 key 位置（和 701 完全一样）
2. 找到目标后，根据「左/右孩子的有无」分 4 个 case 处理
```

### 三问

| 问题 | 答案 |
|---|---|
| 1. 递归返回什么？ | `*TreeNode`，「删除后子树的新根」 |
| 2. base case？ | `root == nil` → `nil`（key 不存在或空树） |
| 3. 当前节点做什么？ | 比较 key 与 root.Val 决定方向；找到后按 4 个 case 删除 |

### 删除阶段的 4 个 case

| root.Left | root.Right | 返回什么 | 说明 |
|---|---|---|---|
| nil | nil | `nil` | 叶子节点直接删 |
| nil | 非 nil | `root.Right` | 用右子树继位 |
| 非 nil | nil | `root.Left` | 用左子树继位 |
| 非 nil | 非 nil | 见下 | 需要合并左右子树 |

### case D 的关键：右子树继位 + 左子树挂到右子树最左下方

```
原:                  删除 root 后:
    root
   /    \                右子树最左节点
  L      R               /     \
        / \            (原 L)   ...
       ...
       (最左节点)
```

**为什么这样合法？** 右子树所有节点 > root.Val > 左子树所有节点。把左子树整棵挂到右子树的最左下方节点的 Left 位置 → 左子树仍然 < 那个最左节点（满足 BST 性质）。

## 完整代码

```go
func deleteNode(root *TreeNode, key int) *TreeNode {
    if root == nil {
        return nil
    }
    if key < root.Val {
        root.Left = deleteNode(root.Left, key)
        return root
    }
    if key > root.Val {
        root.Right = deleteNode(root.Right, key)
        return root
    }
    // 找到目标节点，分 4 个 case
    if root.Left == nil && root.Right == nil {
        root = nil
    } else if root.Left == nil {
        root = root.Right
    } else if root.Right == nil {
        root = root.Left
    } else {
        getMin(root.Right).Left = root.Left   // 左子树挂到右子树最左下方
        root = root.Right                     // 右子树继位
    }
    return root
}

// 找子树最左下方节点（迭代）
func getMin(node *TreeNode) *TreeNode {
    for node.Left != nil {
        node = node.Left
    }
    return node
}
```

## 简化版：把 case A + B 合并

case A（叶子）和 case B（只有右子树）可以合并——叶子时 `root.Right` 也是 nil，返回 nil 正确：

```go
if root.Left == nil { return root.Right }      // 同时覆盖叶子和"只有右"
if root.Right == nil { return root.Left }      // 只有左
// case D
getMin(root.Right).Left = root.Left
return root.Right
```

主解保留 4 case 显式版本（更可读、调试友好）。简化版**完全等价**。

## 关于 getMin

「找子树最左下方节点」是单向沿 `.Left` 走到底的操作——**迭代写法最自然**：

```go
for node.Left != nil {
    node = node.Left
}
return node
```

> **小思考**：当任务是"沿一条路径走到尽头"（无分叉、无聚合），**迭代往往比递归更直接**。递归适合"分叉 + 合并"或"自底向上聚合"。下次写之前先问：「我是要分叉还是单向走？」单向走优先选迭代。

## case D 的另一种策略（镜像）

把"左子树挂到右子树最左"反过来：**右子树挂到左子树最右**：

```go
getMax(root.Left).Right = root.Right
return root.Left
```

两者**完全对称**，都合法 BST，都 AC。选哪个看个人偏好——「右继位」更常见。

## 复杂度

- **时间：O(h)**
  - 定位 key：从根走到目标，最多 h 步
  - case D 的 getMin：从右子树根走到最左，最多 h 步
  - 总 O(h)，平衡 BST O(log n)，最坏链状 O(n)
- **空间：O(h)**——递归栈深度。getMin 是迭代，不增加栈空间。
