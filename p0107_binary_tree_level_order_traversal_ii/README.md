# 二叉树的层序遍历 II

## 题面

给你二叉树的根节点 `root`，返回其节点值**自底向上**的层序遍历（按从叶子到根的层序逐层遍历，每层从左到右）。

样例：
- 输入 `root = [3,9,20,null,null,15,7]` → 输出 `[[15,7], [9,20], [3]]`
- 输入 `root = [1]` → 输出 `[[1]]`
- 输入 `root = []` → 输出 `[]`

约束：节点数 `0 ≤ n ≤ 2000`，`-1000 ≤ Node.val ≤ 1000`。

## 思路

**Pattern：BFS 自顶向下 + 整体 reverse**（102 + 一个 O(n) 后处理）。

### 关键拆解：「已知模板的输出 + 小操作」

1. 自顶向下 BFS 收每层 → `[[3], [9,20], [15,7]]`
2. 双指针 reverse → `[[15,7], [9,20], [3]]`

### 思维要点

题面"**自底向上**"是结果方向，不是解法方向。BFS 的天然方向是 FIFO 从根开始；强行实现"自底向上 BFS"要用栈或反向 DFS，更复杂。**用熟模板 + 后处理** 永远比改造模板简单。

### 为什么不在头部 insert

```go
result = append([][]int{level}, result...)  // ❌ 头部插入：O(n²)
```

每次插入要把已有元素全部拷贝一遍，n 层 → n(n-1)/2 = O(n²)。  
**尾部 append（摊销 O(1)）+ 最后 reverse（O(n)）= 总 O(n)**。

## 复杂度

- 时间：O(n)
- 空间：O(n)
