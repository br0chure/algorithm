# 回溯

## 1. 理论基础

回溯算法是一种通过探索所有可能的解决方案来解决问题的算法技术，尤其适用于组合优化、决策树等问题。其核心思想是利用递归的方式逐步尝试可能的选择，并在发现当前选择不可行时及时“回溯”到之前的决策点，从而避免无效路径的深入。

回溯算法通常可以解决如下类型问题：

- 组合问题：`N`个数里面按一定规则找出`k`个数的集合。
- 子集问题：一个`N`个数的集合里有多少符合条件的子集。
- 排列问题：`N`个数按一定规则全排列，有几种排列方式。
- 棋盘问题：`N`皇后，解数独等等。

### 1.1. 回溯算法理解

回溯法解决的问题都可以抽象为**树形结构**，因为回溯法解决的都是在集合中递归查找子集，集合的大小就构成了树的宽度，递归的深度就构成了树的深度。

### 1.2. 回溯算法模板

确定递归三要素：

- 返回值及参数：回溯算法中函数返回值一般为`void`；回溯算法的参数不像二叉树递归的时候那么容易一次性确定下来，所以一般是先写逻辑，然后需要什么参数，就填什么参数。
- 回溯函数终止条件。
- 回溯搜索的遍历过程：`for`循环可以理解是横向遍历，`backtracking`就是纵向遍历，这样就把这棵树全遍历完了。

```java
// 回溯算法主入口
void backtracking(参数列表) {
    // 递归终止条件
    if (满足结束条件) {
        保存当前解;
        return;
    }

    // 遍历选择列表
    for (选择 : 当前所有可能的选择) {
        if (不满足约束条件) {
            continue; // 剪枝
        }

        // 做出选择
        更新状态(选择);

        // 递归进入下一层
        backtrack(更新后的参数);

        // 回溯
        恢复状态(选择);
    }
}

```

## 2. 组合问题

### 2.1. 经典问题

#### 2.1.1. 组合

**题目 $77$ 组合**：给定两个整数`n`和`k`，返回范围`[1, n]`中所有可能的`k`个数的组合。你可以按任何顺序返回答案。

```markdown
# 注意点：
- 剪枝逻辑。
```

```java
class Solution {
    List<List<Integer>> res = new ArrayList<>();
    public List<List<Integer>> combine(int n, int k) {
        List<Integer> list = new ArrayList<>();
        backtracking(n, k, 1, list);
        return res;
    }

    public void backtracking(int n, int k, int start, List<Integer> list) {
        // 递归结束条件
        if (list.size() == k) {
            res.add(new ArrayList<>(list));
            return;
        }

        for (int i = start; i <= n; i++) {
            // 剪枝：当前层剩余元素个数小于所需元素个数
            if (n - i + 1 < k - list.size()) continue;
            list.add(i);
            // 递归
            backtracking(n, k, i + 1, list);
            // 回溯
            list.remove(list.size() - 1);
        }
    }
}
```

#### 2.1.2. 组合总和Ⅲ

**题目 $216$​ 组合总和Ⅲ**：找出所有相加之和为`n`的`k`个数的组合，且满足下列条件：只使用数字`1`到`9`；每个数字 最多使用一次。返回所有可能的有效组合的列表。该列表不能包含相同的组合两次，组合可以以任何顺序返回。

```markdown
# 注意点：
- 剪枝逻辑。
```

```java
class Solution {
    List<List<Integer>> res = new ArrayList<>();
    public List<List<Integer>> combinationSum3(int k, int n) {
        List<Integer> list = new ArrayList<>();
        backtracking(k, n, 1, list);
        return res;
    }

    public void backtracking(int k, int n, int start, List<Integer> list) {
        // 递归结束条件
        if (n < 0) return;
        if (list.size() == k) {
            if (n == 0) res.add(new ArrayList<>(list));
            return;
        }

        for (int i = start; i <= 9; i++) {
            // 剪枝
            if (9 - i + 1 < k - list.size()) continue;
            n -= i;
            list.add(i);
            // 递归
            backtracking(k, n, i + 1, list);
            // 回溯
            n += i;
            list.remove(list.size() - 1);
        }
    }
}
```

#### 2.1.3. 组合总和（hot100）

**题目 $39$ 组合总和**：给你一个无重复元素的整数数组`candidates`和一个目标整数`target`，找出`candidates`中可以使数字和为目标数`target`的所有不同组合，并以列表形式返回。你可以按任意顺序返回这些组合。`candidates`中的同一个数字可以无限制重复被选取。如果至少一个数字的被选数量不同，则两种组合是不同的。 对于给定的输入，保证和为`target`的不同组合数少于`150`个。

```java
// 时间复杂度 O(n^(T/m))；空间复杂度 O(S*T/M) + O(T/M)
// n - 数组长度；T - target；m - 数组中最小值；S - 解的个数
class Solution {
    List<List<Integer>> res = new ArrayList<>();
    public List<List<Integer>> combinationSum(int[] candidates, int target) {
        List<Integer> list = new ArrayList<>();
        backtracking(candidates, target, 0, list);
        return res;
    }

    public void backtracking(
        int[] candidates, int target, int startIdx, List<Integer> list) {
        // 递归结束条件
        if (target < 0) return;
        if (target == 0) {
            res.add(new ArrayList<>(list));
            return;
        }

        for (int i = startIdx; i < candidates.length; i++) {
            target -= candidates[i];
            list.add(candidates[i]);
            // 递归
            backtracking(candidates, target, i, list);
            // 回溯
            target += candidates[i];
            list.remove(list.size() - 1);
        }
    }
}
```

### 2.2. 去重问题

去重问题发生场景：集合中存在重复元素，且要求结果不重复。

>**树层去重（Level-based Deduplication）**：指在回溯过程中，对于同一层级的节点进行去重，即在每一层递归中，处理重复的元素时通过某些条件进行剪枝，确保每个元素只被考虑一次。通常通过**排序 + 跳过重复元素**来实现。

#### 2.2.1. 组合总和Ⅱ

**题目 $40$ 组合总和Ⅱ**：给定一个候选人编号的集合`candidates`和一个目标数`target`，找出`candidates`中所有可以使数字和为`target`的组合。`candidates`中的每个数字在每个组合中只能使用一次。注意：解集不能包含重复的组合。 

```markdown
# 注意点：
- 树层去重的逻辑，类似题目“三数之和”。
```

```java
class Solution {
    List<List<Integer>> res = new ArrayList<>();
    public List<List<Integer>> combinationSum2(int[] candidates, int target) {
        // 排序
        Arrays.sort(candidates);
        List<Integer> list = new ArrayList<>();
        backtracking(candidates, target, 0, list);
        return res;
    }

    public void backtracking(int[] candidates, int target, int startIdx, List<Integer> list) {
        // 递归结束条件
        if (target < 0) return;
        if (target == 0) {
            res.add(new ArrayList<>(list));
            return;
        }

        for (int i = startIdx; i < candidates.length; i++) {
            // 树层去重
            if (i > startIdx && candidates[i] == candidates[i - 1]) continue;
            list.add(candidates[i]);
            target -= candidates[i];
            // 递归
            backtracking(candidates, target, i + 1, list);
            // 回溯
            list.remove(list.size() - 1);
            target += candidates[i];
        }
    }
}
```

```java
class Solution {
    String[] array = new String[]{
        "", "", "abc", "def", "ghi", "jkl", "mno", "pqrs", "tuv", "wxyz"};
    List<String> res = new ArrayList<>();
    public List<String> letterCombinations(String digits) {
        // 直接返回特殊情况
        if (digits.length() == 0) return res;
        StringBuilder s = new StringBuilder();
        backtracking(digits, 0, s);
        return res;
    }

    public void backtracking(String digits, int startIdx, StringBuilder s) {
        // 递归结束条件
        if (s.length() == digits.length()) {
            res.add(new String(s));
            return;

            s.append(ss.charAt(i));
            // 递归
            backtracking(digits, startIdx + 1, s);
            // 回溯
            s.deleteCharAt(s.length() - 1);
        }
    }
}
```

#### 2.3.2. 分割回文串（hot100）

**题目 $131$ 分割回文串**：给你一个字符串`s`，请你将`s`分割成一些子串，使每个子串都是回文串。返回`s`所有可能的分割方案。

```markdown
# 注意点：
- 对于“aaa”，["a","aa"] 和 ["aa", "a"] 是两种不同的分割方案。
```

```java
class Solution {
    List<List<String>> res = new ArrayList<>();
    public List<List<String>> partition(String s) {
        List<String> list = new ArrayList<>();
        backtracking(s, 0, list);
        return res;
    }

    public void backtracking(String s, int startIdx, List<String> list) {
        // 递归结束条件
        if (startIdx > s.length() - 1) {
            res.add(new ArrayList<>(list));
            return;
        }

        for (int i = startIdx; i < s.length(); i++) {
            // 剪枝
            if (!isHuiwen(s, startIdx, i)) continue;
            list.add(s.substring(startIdx, i + 1));
            // 递归
            backtracking(s, i + 1, list);
            // 回溯
            list.remove(list.size() - 1);
        }
    }

    public boolean isHuiwen(String s, int left, int right) {  // 左闭右闭区间
        while (left < right) {
            if (s.charAt(left) != s.charAt(right)) return false;
            left++; right--;
        }
        return true;
    }
}
```

#### 2.3.3. 复原 IP 地址（2）

有效 IP 地址正好由四个整数（每个整数位于`0`到`255`之间组成，且不能含有前导`0`），整数之间用`'.'`分隔。例如`"0.1.2.201"`和`"192.168.1.1"`是有效 IP 地址，但是`"0.011.255.245", "192.168.1.312", "192.168@1.1"`是无效 IP 地址。给定一个只包含数字的字符串`s`，用以表示一个 IP 地址，返回所有可能的有效 IP 地址，这些地址可以通过在`s`中插入`'.'`来形成。你可以按任何顺序返回答案。

```markdown
# 注意点：
- 剪枝的情况。
- String.join() 方法的使用。
```

```java
class Solution {
    List<String> res = new ArrayList<>();
    public List<String> restoreIpAddresses(String s) {
        List<String> list = new ArrayList<>();
        backtracking(s, list, 0);
        return res;
    }

    public void backtracking(String s, List<String> list, int startIdx) {
        // 递归结束条件
        if (list.size() == 4) {
            if (startIdx == s.length()) {
                res.add(String.join(".", list));
            }
            return;
        }

        for (int i = startIdx; i < s.length(); i++) {
            String cur = s.substring(startIdx, i + 1);
            // 剪枝
            if (i - startIdx > 2) continue;  // 情况一：超过三位数
            if (cur.length() > 1 && cur.charAt(0) == '0') continue;  // 情况二：0 开头
            if (cur.charAt(0) != '0' && Integer.parseInt(cur) > 255) continue;  // 情况三：超过 255
            // 递归
            list.add(cur);
            backtracking(s, list, i + 1);
            // 回溯
            list.remove(list.size() - 1);
        }
    }
}
```

### 4.1. 经典问题

#### 4.1.1. 全排列（hot100, 1）

**题目 $46$ 全排列**：给定一个不含重复数字的数组`nums`，返回其所有可能的全排列。你可以按任意顺序返回答案。


```java
class Solution {
    List<List<Integer>> res = new ArrayList<>();
    public List<List<Integer>> permute(int[] nums) {
        List<Integer> list = new ArrayList<>();
        int[] used = new int[nums.length];
        backtracking(nums, used, list);
        return res;
    }

    public void backtracking(int[] nums, int[] used, List<Integer> list) {
        // 递归结束条件
        if (list.size() == nums.length) {
            res.add(new ArrayList<>(list));
            return;
        }

        for (int i = 0; i < nums.length; i++) {
            // 剪枝
            if (used[i] == 1) continue;
            list.add(nums[i]);
            used[i] = 1;
            // 递归
            backtracking(nums, used, list);
            // 回溯
            used[i] = 0;
            list.remove(list.size() - 1);
        }
    }
}
```

#### 4.2.1. 全排列Ⅱ

```java
class Solution {
    List<List<Integer>> res = new ArrayList<>();
    public List<List<Integer>> permuteUnique(int[] nums) {
        List<Integer> list = new ArrayList<>();
        int[] used = new int[nums.length];
        Arrays.sort(nums);
        backtracking(nums, used, list);
        return res;
    }

    public void backtracking(int[] nums, int[] used, List<Integer> list) {
        // 递归结束条件
        if (list.size() == nums.length) {
            res.add(new ArrayList<>(list));
            return;
        }

        for (int i = 0; i < nums.length; i++) {
            // 剪枝
            if (used[i] == 1) continue;

            if (i > 0 && nums[i] == nums[i - 1] && used[i - 1] == 0) continue;

            used[i] = 1;
            // 递归
            backtracking(nums, used, list);
            // 回溯
            list.remove(list.size() - 1);
            used[i] = 0;
        }
    }
}
```

### 5.1. 括号生成（hot100, 3）

**题目 $22$ 括号生成**：数字`n`代表生成括号的对数，请你设计一个函数，用于能够生成所有可能的并且有效的括号组合。

```markdown
# 注意点：
- 每一层递归逐个添加括号。
- 左括号的数量必须大于等于右括号。
```

```java
class Solution {
    List<String> res = new ArrayList<>();
    public List<String> generateParenthesis(int n) {
        StringBuilder sb = new StringBuilder();
        backtracking(n, 0, 0, sb);
        return res;
    }

    public void backtracking(int n, int left, int right, StringBuilder sb) {
        // 递归结束条件：
        if (sb.length() == n * 2) {
            res.add(new String(sb));
            return;
        }

        // 如果左括号数量不足，则直接添加
        if (left < n) {
            sb.append('(');
            backtracking(n, left + 1, right, sb);
            sb.deleteCharAt(sb.length() - 1);
        }
        // 如果左括号数量大于右括号，则可以添加右括号
        if (right < left) {
            sb.append(')');
            backtracking(n, left, right + 1, sb);
            sb.deleteCharAt(sb.length() - 1);
        }
    }
}
```

### 5.2. 单词搜索（hot100）

**题目 $79$ 单词搜索**：给定一个`m x n`二维字符网格`board`和一个字符串单词`word`。如果`word`存在于网格中，返回`true`；否则，返回`false`。单词必须按照字母顺序，通过相邻的单元格内的字母构成，其中“相邻”单元格是那些水平相邻或垂直相邻的单元格。同一个单元格内的字母不允许被重复使用。

```markdown
# 注意点：
- 本题思路不难想，但细节较多，需要熟练。
```

```java
class Solution {
    int[][] directions = new int[][]{{-1, 0}, {0, 1}, {1, 0}, {0, -1}};
    boolean res = false;
    public boolean exist(char[][] board, String word) {
        int[][] used = new int[board.length][board[0].length];
        for (int i = 0; i < board.length; i++) {
            for (int j = 0; j < board[0].length; j++) {
                if (word.charAt(0) == board[i][j]) {
                    // 递归
                    used[i][j] = 1;
                    backtracking(board, used, word, 1, i, j);
                    // 回溯
                    used[i][j] = 0;
                }
            }
        }
        return res;
    }

    public void backtracking(char[][] board, int[][] used, String word, int startIdx, int row, int col) {
        // 递归结束条件
        if (startIdx == word.length()) {
            res = true;
            return;
        }

        for (int[] dir : directions) {
            int newRow = dir[0] + row;
            int newCol = dir[1] + col;
            if (newCol < 0 || newCol >= board[0].length) continue;  // 超限
            if (newRow < 0 || newRow >= board.length) continue;  // 超限
            if (board[newRow][newCol] != word.charAt(startIdx)) continue;  // 非目标单词
            if (used[newRow][newCol] == 1) continue;  // 字符已被使用
            // 递归
            used[newRow][newCol] = 1;
            backtracking(board, used, word, startIdx + 1, newRow, newCol);
            // 回溯
            used[newRow][newCol] = 0;
        }
    }
}
```

### 5.3. N 皇后（hot100）

**题目 $51$ N 皇后**：按照国际象棋的规则，皇后可以攻击与之处在同一行或同一列或同一斜线上的棋子。N 皇后问题研究的是如何将`n`个皇后放置在`n×n`的棋盘上，并且使皇后彼此之间不能相互攻击。给你一个整数`n`，返回所有不同的 N 皇后问题的解决方案。每一种解法包含一个不同的 N 皇后问题的棋子放置方案，该方案中`Q`和`.`分别代表了皇后和空位。

```java
class Solution {
    List<List<String>> res = new ArrayList<>();
    public List<List<String>> solveNQueens(int n) {
        char[][] board = new char[n][n];
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                board[i][j] = '.';
            }
        }
        backtracking(board, 0);
        return res;
    }

    public void backtracking(char[][] board, int row) {
        // 递归结束条件
        if (row == board.length) {
            res.add(arrayToList(board));
            return;
        }

        for (int i = 0; i < board.length; i++) {
            if (isValid(board, row, i)) {
                // 递归
                board[row][i] = 'Q';
                backtracking(board, row + 1);
                // 回溯
                board[row][i] = '.';
            }
        }
    }

    // 结果格式转换
    public List arrayToList(char[][] board) {
        List<String> list = new ArrayList<>();
        for (char[] chars : board) {
            StringBuilder sb = new StringBuilder();
            for (char c : chars) {
                sb.append(c);
            }
            list.add(sb.toString());
        }
        return list;
    }

    // 判断在当前位置放置皇后是否合法
    public boolean isValid(char[][] board, int row, int col) {
        // 检查列
        for (int i = 0; i < row; i++) {
            if (board[i][col] == 'Q') return false;
        }
        // 检查行
        for (int j = 0; j < col; j++) {
            if (board[row][j] == 'Q') return false;
        }
        // 检查 45 度对角线
        for (int i = row - 1, j = col + 1; i >= 0 && j < board.length; i--, j++) {
            if (board[i][j] == 'Q') return false;
        }
        // 检查 135 度对角线
        for (int i = row - 1, j = col - 1; i >= 0 && j >= 0; i--, j--) {
            if (board[i][j] == 'Q') return false;
        }
        return true;
    }
}
```

提供另一个版本的解答，个人感觉更容易想到：

```java
class Solution {
    private List<List<String>> res = new ArrayList<>();
    public List<List<String>> solveNQueens(int n) {
        int[][] used = new int[n][n];
        List<String> list = new ArrayList<>();
        backtracking(used, list, 0);
        return res;
    }

    public void backtracking(int[][] used, List<String> list, int row) {
        if (list.size() == used.length) {
            res.add(new ArrayList<>(list));
            return;
        }

        for (int i = 0; i < used[0].length; i++) {
            if (isVaild(used, row, i)) {
                StringBuilder sb = new StringBuilder();
                for (int tmp = 0; tmp < used.length; tmp++) {
                    sb.append('.');
                }
                sb.setCharAt(i, 'Q');
                // 递归
                used[row][i] = 1;
                list.add(sb.toString());
                backtracking(used, list, row + 1);
                // 回溯
                used[row][i] = 0;
                list.remove(list.size() - 1);
            }
        }
    }

    public Boolean isVaild(int[][] used, int row, int col) {
        // 检查行
        for (int j = 0; j < col; j++) {
            if (used[row][j] == 1) {
                return false;
            }
        }
        // 检查列
        for (int i = 0; i < row; i++) {
            if (used[i][col] == 1) {
                return false;
            }
        }
        // 检查 45 度对角线
        for (int i = row - 1, j = col + 1; i >= 0 && j < used[0].length; i--, j++) {
            if (used[i][j] == 1) {
                return false;
            }
        }
        // 检查 135 度对角线
        for (int i = row - 1, j = col - 1; i >= 0 && j >= 0; i--, j--) {
            if (used[i][j] == 1) {
                return false;
            }
        }
        return true;
    }
}
```
