# 数组和字符串

本章节中包含了数组和字符串相关题目，主要涉及**二分法、双指针、滑动窗口**等常见题型。

## 1. 二分法

### 1.1. 经典二分法

> 经典二分法要求搜索数组**全局严格有序**，或查找的函数**全局严格单调**。

#### 1.1.1. 二分查找（3）

**题目 $704$ 二分查找**：给定一个`n`个元素有序的（升序）整型数组`nums`和一个目标值`target`，写一个函数搜索`nums`中的`target`，如果目标值存在返回下标，否则返回`-1`。你可以假设`nums`中的所有元素是不重复的。

```markdown
# 注意点：
- 本题有两种常见的区间定义方式，不同定义方式在“初始化、循环条件、边界更新条件”存在不同。
	- 左闭右闭区间：[left, right]
	- 左闭右开区间：[left, right)
```

```java
// 时间复杂度 O(logn)；空间复杂度 O(1)
// n - 数组长度
class Solution {
    public int search(int[] nums, int target) {
        // 区间定义：在 [left, right] 左闭右闭区间中进行搜索
        int left = 0, right = nums.length - 1;  // 注意
        while (left <= right) {  // left = right 在 [left, right] 区间定义中属于合法区间
            int mid = left + (right - left) / 2;
            if (nums[mid] > target) right = mid - 1;  // 注意
            else if (nums[mid] < target) left = mid + 1;  // 注意
            else if (nums[mid] == target) return mid;
        }
        return -1;
    }
}
```

#### 1.1.2. 有效的完全平方数

**题目 $367$ 有效的完全平方数**：给你一个正整数`num`。如果`num`是完全平方数，返回`true`；否则返回`false`。

```markdown
# 注意点：
- int 类型数值溢出问题。
```

```java
// 时间复杂度 O(logn)；空间复杂度 O(1)
// n - 正整数大小
class Solution {
    public boolean isPerfectSquare(int num) {
        // 定义区间：左闭右闭
        int left = 1, right = num;
        while (left <= right) {
            int mid = left + (right - left) / 2;
            long tmp = (long) mid * mid;
            if (tmp == num) return true;
            else if (tmp > num) right = mid - 1;
            else if (tmp < num) left = mid + 1;
        }
        return false;
    }
}
```

#### 1.1.3. 搜索插入位置（hot100）

**题目 $35$ 搜索插入位置**：给定一个排序数组和一个目标值，在数组中找到目标值，并返回其索引。如果目标值不存在于数组中，返回它将会被按顺序插入的位置。

```markdown
# 注意点：
- 在目标元素不存在时，left 指向插入的位置。
```

```java
// 时间复杂度 O(logn)；空间复杂度 O(1)
// n - 数组长度
class Solution {
    public int searchInsert(int[] nums, int target) {
        // 定义区间：[left, right]
        // 如果目标值存在，则就是标准的二分搜索
        // 如果目标值不存在，则 left 指向插入位置
        int left = 0, right = nums.length - 1;
        while (left <= right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] == target) return mid;
            else if (nums[mid] > target) right = mid - 1;
            else if (nums[mid] < target) left = mid + 1;
        }
        return left;
    }
}
```

#### 1.1.4. x 的平方根（3）

**题目 $69$ x 的平方根**：给你一个非负整数`x`，计算并返回`x`的算术平方根。由于返回类型是整数，结果只保留整数部分，小数部分将被舍去。

```markdown
# 注意点：
- int 类型数值溢出问题。
- 当 x 不是完全平方数时，right 指向 x 的平方根。
```

```java
// 时间复杂度 O(logn)；空间复杂度 O(1)
// n - 正整数大小
class Solution {
    public int mySqrt(int x) {
        // 定义区间：左闭右闭
        int left = 1, right = x;
        while (left <= right) {
            int mid = left + (right - left) / 2;
            long tmp = (long) mid * mid;  // 注意 int 类型溢出问题
            if (tmp == x) return mid;
            else if (tmp > x) right = mid - 1;
            else if (tmp < x) left = mid + 1;
        }
        return right;
    }
}
```

#### 1.1.5. 搜索二维矩阵（hot100）

**题目 $74$ 搜索二维矩阵**：给你一个满足下述两条属性的`m x n`整数矩阵：

- 每行中的整数从左到右按非严格递增顺序排列。
- 每行的第一个整数大于前一行的最后一个整数。

给你一个整数`target`，如果`target`在矩阵中，返回`true`；否则，返回`false`。

```markdown
# 注意点：
- 先对行进行二分搜索；再对列进行二分搜索。
```

```java
// 时间复杂度 O(logm + logn)；空间复杂度 O(1)
// m - 行数；n - 列数
class Solution {
    public boolean searchMatrix(int[][] matrix, int target) {
        // 先搜索对应行
        // 定义区间：[top, bottom]
        int top = 0, bottom = matrix.length - 1;
        while (top <= bottom) {
            int mid = top + (bottom - top) / 2;
            if (matrix[mid][0] == target) return true;
            else if (matrix[mid][0] > target) bottom = mid - 1;
            else if (matrix[mid][0] < target) top = mid + 1;
        }
        // 注意处理 bottom == -1 的特殊情况
        if (bottom == -1) return false;
        // 此时 bottom 指向对应行，再搜索列
        // 定义区间：[left, right]
        int left = 0, right = matrix[0].length - 1;
        while (left <= right) {
            int mid = left + (right - left) / 2;
            if (matrix[bottom][mid] == target) return true;
            else if (matrix[bottom][mid] > target) right = mid - 1;
            else if (matrix[bottom][mid] < target) left = mid + 1;
        }
        return false;
    }
}
```

### 1.2. 变种二分法

> 变种二分法是指搜索的数组可以**非严格有序**，或是**部分有序**。

#### 1.2.1. 在排序数组中查找元素的第一个和最后一个位置（hot100）

**题目 $34$ 在排序数组中查找元素的第一个和最后一个位置**：给你一个按照非递减顺序排列的整数数组`nums`，和一个目标值`target`。请你找出给定目标值在数组中的开始位置和结束位置。如果数组中不存在目标值`target`，返回`[-1, -1]`。你必须设计并实现时间复杂度为`O(log n)`的算法解决此问题。

```markdown
# 注意点：
- 在非严格有序的数组中查找重复元素的边界。
```

```java
// 时间复杂度 O(logn)；空间复杂度 O(1)
// n - 数组长度
class Solution {
    public int[] searchRange(int[] nums, int target) {
        // 查找开始位置：[left, right]
        int firstIdx = -1;
        int left = 0, right = nums.length - 1;
        while (left <= right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] == target) {
                firstIdx = mid;
                // 右边界左移
                right = mid - 1;
            } else if (nums[mid] > target) right = mid - 1;
            else if (nums[mid] < target) left = mid + 1;
        }

        // 查找结束位置：[left, right]
        int lastIdx = -1;
        left = 0;
        right = nums.length - 1;
        while (left <= right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] == target) {
                lastIdx = mid;
                // 左边界右移
                left = mid + 1;
            } else if (nums[mid] > target) right = mid - 1;
            else if (nums[mid] < target) left = mid + 1;
        }

        return new int[]{firstIdx, lastIdx};
    }
}
```

#### 1.2.2. 搜索旋转排序数组（hot100, 1）

**题目 $33$ 搜索旋转排序数组**：整数数组 `nums` 按升序排列，数组中的值 **互不相同** 。在传递给函数之前，`nums`在预先未知的某个下标`k, 0 <= k < nums.length`上进行了旋转。例如 `[0,1,2,4,5,6,7]`在下标`3`处经旋转后可能变为`[4,5,6,7,0,1,2]`。给你旋转后的数组`nums`和一个整数`target`，如果`nums`中存在这个目标值`target`，则返回它的下标，否则返回`-1`。你必须设计一个时间复杂度为`O(log n)`的算法解决此问题，且`nums`中的元素两两不相同。

```markdown
# 注意点：
- 利用 mid 分割后有序的一部分子数组进行查找。
```

```java
// 时间复杂度 O(logn)；空间复杂度 O(1)
// n - 数组长度
class Solution {
    public int search(int[] nums, int target) {
        int left = 0, right = nums.length - 1;
        while (left <= right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] == target) return mid;
            // 重点：当 nums[left] == nums[mid] 时，[left, mid] 有序还是 [mid, right] 有序？
            if (nums[left] <= nums[mid]) {
                // 此时 [left, mid] 严格有序
                if (target >= nums[left] && target < nums[mid]) {
                    right = mid - 1;
                } else {
                    left = mid + 1;
                }
            } else if (nums[left] > nums[mid]) {
                // 右区间单调 [mid, right] 严格有序
                if (target > nums[mid] && target <= nums[right]) {
                    left = mid + 1;
                } else {
                    right = mid - 1;
                }
            }
        }
        return -1;
    }
}
```

#### 1.2.3. 寻找旋转排序数组中的最小值（hot100）

**题目 $153$ 寻找旋转排序数组中的最小值**：已知一个长度为`n`的数组，预先按照升序排列，经由`1`到`n`次旋转后，得到输入数组。例如，原数组`nums = [0,1,2,4,5,6,7]`在变化后可能得到：

- 若旋转`4`次，则可以得到 `[4,5,6,7,0,1,2]`。
- 若旋转`7`次，则可以得到`[0,1,2,4,5,6,7]`。

给你一个元素值互不相同的数组`nums`，它原来是一个升序排列的数组，并按上述情形进行了多次旋转。请你找出并返回数组中的最小元素。你必须设计一个时间复杂度为`O(log n)`的算法解决此问题。

```markdown
# 注意点：
- 利用 mid 分割后有序的一部分子数组进行查找。
- 由于数组单调递增为特殊情况，本题必须与右边界进行比较。
- 本题并不完全符合左闭右闭，或左闭右开的标准形式！！！
	- 对于一定存在结果的题目，循环结束条件为 left = right
```

```java
// 时间复杂度 O(logn)；空间复杂度 O(1)
// n - 数组长度
class Solution {
    public int findMin(int[] nums) {
        int left = 0, right = nums.length - 1;
        while (left < right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] < nums[right]) {
                // 情况一：数组单调递增，收缩右边界
                // 情况二：最小值位于 [left, mid]，收缩右边界
                right = mid;
            } else if (nums[mid] > nums[right]) {
                // 情况三：最小值位于 [mid + 1, right]，收缩左边界
                left = mid + 1;
            }
        }
        // 退出循环的条件是 left = right，均指向最小值
        return nums[left];
    }
}
```

#### 1.2.4. 寻找峰值

**题目 $162$ 寻找峰值**：峰值元素是指其值严格大于左右相邻值的元素。给你一个整数数组`nums`，找到峰值元素并返回其索引。数组可能包含多个峰值，在这种情况下，返回任何一个峰值所在位置即可。你可以假设`nums[-1] = nums[n] = -∞`。你必须实现时间复杂度为`O(log n)`的算法来解决此问题。对于所有有效的`i`都有`nums[i] != nums[i + 1]`。

```markdown
# 注意点：
- 需要明确 nums[-1] = nums[n] = 负无穷 的条件下，峰值一定存在。
- mid 必须和 mid + 1 进行比较。
- 本题并不完全符合左闭右闭，或左闭右开的标准形式！！！
	- 对于一定存在结果的题目，循环结束条件为 left = right
```

```java
// 时间复杂度 O(logn)；空间复杂度 O(1)
// n - 数组长度
class Solution {
    public int findPeakElement(int[] nums) {
        int left = 0, right = nums.length - 1;
        while (left < right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] > nums[mid + 1]) {
                right = mid;  // [0, mid] 区间内一定存在峰值
            } else if (nums[mid] < nums[mid + 1]) {
                left = mid + 1;  // [mid + 1, nums.length - 1] 区间内一定存在峰值
            }
        }
        // 退出循环的条件是 left = right，均指向峰值
        return left;
    }
}
```

## 2. 双指针

### 2.1. 快慢指针

> 快慢指针是双指针中的一种，主要用于**数组中的元素移动，链表判断环、中间点查找**等场景。

#### 2.1.1. 移除元素

**题目 $27$ 移除元素**：给你一个数组`nums`和一个值`val`，你需要原地移除所有数值等于`val`的元素。元素的顺序可能发生改变。然后返回`nums`中与`val`不同的元素的数量。

```java
// 时间复杂度 O(n)；空间复杂度 O(1)
// n - 数组长度
class Solution {
    public int removeElement(int[] nums, int val) {
        if (nums.length == 0) return 0;
        // 快指针：指向不等于 val 的位置
        // 慢指针：指向当前需要被覆盖的位置
        int slow = 0;
        for (int fast = 0; fast < nums.length; fast++) {
            if (nums[fast] != val) {
                nums[slow] = nums[fast];
                slow++;
            }
        }
        return slow;
    }
}
```

#### 2.1.2. 删除有序数组中的重复项

**题目 $26$ 删除有序数组中的重复项**：给你一个非严格递增排列的数组`nums`，请你原地删除重复出现的元素，使每个元素只出现一次，返回删除后数组的新长度。元素的相对顺序应该保持一致。返回`nums`中唯一元素的个数。

```java
// 时间复杂度 O(n)；空间复杂度 O(1)
// n - 数组长度
class Solution {
    public int removeDuplicates(int[] nums) {
        int slow = 0;
        for (int fast = 0; fast < nums.length; fast++) {
            if (fast == 0 || nums[fast] != nums[fast - 1]) {
                // 快指针：指向重复出现元素的最左侧位置
        		// 慢指针：指向当前需要被覆盖的位置
                nums[slow] = nums[fast];
                slow++;
            }
        }
        return slow;
    }
}
```

#### 2.1.3. 移动零（hot100）

**题目 $283$ 移动零**：给定一个数组`nums`，编写一个函数将所有`0`移动到数组的末尾，同时保持非零元素的相对顺序。请注意，必须在不复制数组的情况下原地对数组进行操作。

```java
// 时间复杂度 O(n)；空间复杂度 O(1)
// n - 数组长度
class Solution {
    public void moveZeroes(int[] nums) {
        int slow = 0;
        for (int fast = 0; fast < nums.length; fast++) {
            // 快指针：指向不为 0 的位置
            // 慢指针：指向当前需要被覆盖的位置
            if (nums[fast] != 0) {
                nums[slow] = nums[fast];
                slow++;
            }
        }
        while (slow < nums.length) {
            nums[slow] = 0;
            slow++;
        }
    }
}
```

### 2.2. 左右指针

>左右指针是双指针中的一种，通常指向数组或字符串的**两端**，然后向中间靠拢，直到满足某种条件。

#### 2.2.1. 反转字符串

**题目 $344$ 反转字符串**：编写一个函数，其作用是将输入的字符串反转过来。输入字符串以字符数组`s`的形式给出。不要给另外的数组分配额外的空间，你必须原地修改输入数组，使用`O(1)`的额外空间解决这一问题。

```java
// 时间复杂度 O(n)；空间复杂度 O(1)
// n - 数组长度
class Solution {
    public void reverseString(char[] s) {
        // 左指针：指向下标 0
        // 右指针：指向下标 s.length - 1;
        int left = 0, right = s.length - 1;

        while (left < right) {
            char tmp = s[left];
            s[left] = s[right];
            s[right] = tmp;
            left++;
            right--;
        }
    }
}
```

#### 2.2.2. 有序数组的平方

**题目 $977$ 有序数组的平方**：给你一个按非递减顺序排序的整数数组`nums`，返回每个数字的平方组成的新数组，要求也按非递减顺序排序。

```java
// 时间复杂度 O(n)；空间复杂度 O(n)
// n - 数组长度
class Solution {
    public int[] sortedSquares(int[] nums) {
        // 左指针：指向下标 0
        // 右指针：指向下标 nums.length - 1
        int left = 0, right = nums.length - 1;
        int[] res = new int[nums.length];

        for (int i = nums.length - 1; i >= 0; i--) {
            if (nums[left] * nums[left] >= nums[right] * nums[right]) {
                res[i] = nums[left] * nums[left];
                left++;
            } else {
                res[i] = nums[right] * nums[right];
                right--;
            }
        }
        return res;
    }
}
```

#### 2.2.3. 盛水最多的容器（hot100）

**题目 $11$ 盛水最多的容器**：给定一个长度为`n`的整数数组`height`。有`n`条垂线，第`i`条线的两个端点是`(i, 0)`和`(i, height[i])`。找出其中的两条线，使得它们与`x`轴共同构成的容器可以容纳最多的水。返回容器可以储存的最大水量。

```markdown
# 注意点：
- 证明：在每一次移动（即抛弃）较小的边界值时，被抛弃的边界值一定不存在盛水更多的情况。
```

```java
// 时间复杂度 O(n)；空间复杂度 O(1)
// n - 数组长度
class Solution {
    public int maxArea(int[] height) {
        // 左指针：指向下标 0
        // 右指针：指向下标 height.length - 1
        int left = 0, right = height.length - 1;

        int maxWater = 0;
        while (left < right) {
            maxWater = Math.max(
                maxWater, Math.min(height[left], height[right]) * (right - left));
            if (height[left] >= height[right]) right--;
            else left++;
        }
        return maxWater;
    }
}
```

#### 2.2.4. 反转字符串中的单词（3）

**题目 $151$ 反转字符串中的单词**：给你一个字符串`s`，请你反转字符串中单词的顺序。单词是由非空格字符组成的字符串。`s`中使用至少一个空格将字符串中的单词分隔开。返回单词顺序颠倒且单词之间用单个空格连接的结果字符串。注意：输入字符串`s`可能会存在前导空格、尾随空格或者单词间的多个空格。返回的结果字符串中，单词间应当仅用单个空格分隔，且不包含任何额外的空格。

```markdown
# 注意点：本题不难，但步骤较多，细节繁琐，需要熟练。
- 不能使用任何内置的反转方法。
```

```java
// 时间复杂度 O(n)；空间复杂度 O(n)
// n - 字符串长度
class Solution {
    public String reverseWords(String s) {
        StringBuilder sb = new StringBuilder();
        // 1. 去除首尾，以及单词间多余的空格
        // 1.1. 去除首位空格
        int left = 0, right = s.length() - 1;
        while (s.charAt(left) == ' ') left++;
        while (s.charAt(right) == ' ') right--;
        // 1.2. 去除中间空格
        for (int i = left; i <= right; i++) {
            if (s.charAt(i) == ' ' && s.charAt(i + 1) == ' ') continue;
            sb.append(s.charAt(i));
        }

        // 2. 双指针翻转整个字符串
        reverseStringBuilder(sb, 0, sb.length() - 1);

        // 3. 双指针依次翻转每个单词
        int slow = 0;
        for (int fast = 0; fast < sb.length(); fast++) {
            if (sb.charAt(fast) == ' ') {
                reverseStringBuilder(sb, slow, fast - 1);
                slow = fast + 1;
            } else if (fast == sb.length() - 1) {
                reverseStringBuilder(sb, slow, fast);
            }
        }
        return sb.toString();
    }

    // 翻转指定区间内的字符串
    public void reverseStringBuilder(StringBuilder s, int left, int right) {
        while (left < right) {
            char tmp = s.charAt(left);
            s.setCharAt(left, s.charAt(right));
            s.setCharAt(right, tmp);
            left++;
            right--;
        }
    }
}
```

#### 2.2.5. 三数之和（hot100, 1）

**题目 $15$ 三数之和**：给你一个整数数组`nums`，判断是否存在三元组`[nums[i], nums[j], nums[k]]`满足`i != j, i != k, j != k`，同时还满足`nums[i] + nums[j] + nums[k] == 0`。请你返回所有和为`0`且不重复的三元组。

```markdown
# 注意点：
- 先对数组进行排序。因为要根据和的大小移动双指针。
- 针对每一个元素都需要进行去重：
	- 第二和第三个元素的去重操作必须在找到结果后才进行，否则会遗漏情况！！！
```

```java
// 时间复杂度 O(n^2)；空间复杂度 O(logn + k)
// n - 数组长度；k - 不重复三元组数量
class Solution {
    public List<List<Integer>> threeSum(int[] nums) {
        // 对数组进行排序，升序
        Arrays.sort(nums);

        List<List<Integer>> res = new ArrayList<>();
        for (int i = 0; i < nums.length; i++) {
            if (nums[i] > 0) return res;  // 如果第一个数大于零，则不可能和为零
            if (i > 0 && nums[i] == nums[i - 1]) continue;  // 去重（第一个数）

            // 双指针
            int left = i + 1, right = nums.length - 1;
            int target = -nums[i];
            while (left < right) {
                if (nums[left] + nums[right] == target) {
                    res.add(Arrays.asList(nums[i], nums[left], nums[right]));
                    left++; right--;
                    // 去重（第二个元素）
                    while (left < right && nums[left] == nums[left - 1]) left++;
                    // 去重（第三个元素）
                    while (left < right && nums[right] == nums[right + 1]) right--;
                } else if (nums[left] + nums[right] > target) {
                    right--;
                } else left++;
            }
        }

        return res;
    }
}
```

#### 2.2.6. 四数之和

**题目 $18$ 四数之和**：给你一个由`n`个整数组成的数组`nums`，和一个目标值`target`。请你找出并返回满足下述全部条件不重复的四元组`[nums[a], nums[b], nums[c], nums[d]]`：`0 <= a, b, c, d < n`；`a, b, c, d`互不相同；`nums[a] + nums[b] + nums[c] + nums[d] == target`。你可以按任意顺序返回答案 。

```markdown
# 注意点：
- 先对数组进行排序。因为要根据和的大小移动双指针。
- 每一个指针的去重操作十分重要。
- 剪枝操作的条件切勿出错。
- 防止 int 类型溢出！！！
```

```java
// 时间复杂度 O(n^3)；空间复杂度 O(n + k)
// n - 数组长度；k - 不重复四元组数量
class Solution {
    public List<List<Integer>> fourSum(int[] nums, int target) {
        // 对数组进行排序
        Arrays.sort(nums);
        List<List<Integer>> res = new ArrayList<>();

        // 遍历第一个元素
        for (int i = 0; i < nums.length; i++) {
            if (nums[i] > target && nums[i] >= 0) return res;  // 剪枝
            if (i > 0 && nums[i] == nums[i - 1]) continue;  // 去重
            // 遍历第二个元素
            for (int j = i + 1; j < nums.length; j++) {
                if (nums[i] + nums[j] > target && nums[j] >= 0) break;  // 剪枝
                if (j > i + 1 && nums[j] == nums[j - 1]) continue;  // 去重

                // 双指针
                int left = j + 1, right = nums.length - 1;
                long tmp = (long) target - nums[i] - nums[j];
                while (left < right) {
                    if (nums[left] + nums[right] == tmp) {
                        res.add(Arrays.asList(nums[i], nums[j], nums[left], nums[right]));
                        // 去重
                        while (left < right && nums[left] == nums[left + 1]) {
                            left++;
                        }
                        left++;
                        while (left < right && nums[right] == nums[right - 1]) {
                            right--;
                        }
                        right--;
                    } else if (nums[left] + nums[right] > tmp) right--;
                    else left++;
                }
            }
        }
        return res;
    }
}
```

### 2.3. 双序列双指针

>双序列双指针是一种双指针扩展技巧，用于同时遍历两个有序数组或字符串，时间复杂度通常为 $O(n+m)$。

#### 2.3.1. 合并两个有序数组（1）

**题目 $88$ 合并两个有序数组**：给你两个按非递减顺序排列的整数数组`nums1`和`nums2`，另有两个整数`m`和`n`，分别表示`nums1`和`nums2`中的元素数目。请你合并`nums2`到`nums1`中，使合并后的数组同样按非递减顺序排列。最终，合并后数组不应由函数返回，而是存储在数组`nums1`中。为了应对这种情况，`nums1`的初始长度为`m + n`，其中前`m`个元素表示应合并的元素，后`n`个元素为`0`，应忽略。`nums2`的长度为`n`。请用`O(m+n)`的时间复杂度，`O(1)`的空间复杂度解决该问题。

```markdown
# 注意：在空间复杂度要求下，本题有一定难度。
- 双指针逆序遍历。
```

```java
// 时间复杂度 O(m + n)；空间复杂度 O(1)
// m - nums1.length; n - nums2.length
class Solution {
    public void merge(int[] nums1, int m, int[] nums2, int n) {
        // 双指针：分别指向两个数组的末尾位置
        int p1 = m - 1, p2 = n - 1;
        // 临时指针：指向数组 nums1 中下一个覆盖的位置
        int cur = nums1.length - 1;
        while (p1 >= 0 && p2 >= 0) {
            if (nums1[p1] >= nums2[p2]) {
                nums1[cur] = nums1[p1];
                p1--;
            } else {
                nums1[cur] = nums2[p2];
                p2--;
            }
            cur--;
        }
        // 填充剩余元素
        while (p1 >= 0) {
            nums1[cur] = nums1[p1];
            p1--; cur--;
        }
        while (p2 >= 0) {
            nums1[cur] = nums2[p2];
            p2--; cur--;
        }
    }
}
```

#### 2.3.2. 字符串相加（2）

**题目 $415$ 字符串相加**：给定两个字符串形式的非负整数`num1`和`num2`，计算它们的和并同样以字符串形式返回。你不能使用任何內建的用于处理大整数的库， 也不能直接将输入的字符串转换为整数形式。

```markdown
# 注意点：
- 本题和链表中 “两数相加” 思路基本相同。
```

```java
// 时间复杂度 O(max(n1, n2))；空间复杂度 O(max(n1, n2))
// n1 - num1.length(); n2 - num2.length()
class Solution {
    public String addStrings(String num1, String num2) {
        StringBuilder res = new StringBuilder();
        // 双指针分别指向两个字符串的末尾
        int p1 = num1.length() - 1, p2 = num2.length() - 1;
        int jinwei = 0;
        while (p1 >= 0 || p2 >= 0 || jinwei != 0) {
            int n1 = (p1 >= 0) ? num1.charAt(p1) - '0' : 0;
            int n2 = (p2 >= 0) ? num2.charAt(p2) - '0' : 0;
            int sum = n1 + n2 + jinwei;
            jinwei = sum / 10;  // 当前进位
            sum = sum % 10;  // 当前位的值
            // 收集结果
            res.append(sum);
            p1--;
            p2--;
        }
        return res.reverse().toString();
    }
}
```

#### 2.3.3. 比较含退格的字符串（×）

**题目 $844$ 比较含退格的字符串**：给定`s`和`t`两个字符串，当它们分别被输入到空白的文本编辑器后，如果两者相等，返回`true`。`#`代表退格字符。请用`O(n + m)`的时间复杂度和`O(1)`的空间复杂度解决该问题。

```markdown
# 注意点：在空间复杂度要求下，本题难度较大。
- 双指针逆序遍历。
- 临时变量 skips, skipt 记录跳跃的字符数量。
```

```java
// 时间复杂度 O(n + m)；空间复杂度 O(1)
// n - s.length(); m - t.length()
class Solution {
    public boolean backspaceCompare(String s, String t) {
        // 双指针分别指向两个字符串的末尾，逆序遍历
        int ps = s.length() - 1, pt = t.length() - 1;
        int skips = 0, skipt = 0;

        // 双指针均小于 0，正常退出循环，说明两个字符串相同
        while (ps >= 0 || pt >= 0) {
            // 首先，确定两个指针最终指向的“字符”位置
            while (ps >= 0) {
                if (s.charAt(ps) == '#') {
                    skips++;
                    ps--;
                } else {
                    if (skips > 0) {
                        skips--;
                        ps--;
                    } else break;
                }
            }
            while (pt >= 0) {
                if (t.charAt(pt) == '#') {
                    skipt++;
                    pt--;
                } else {
                    if (skipt > 0) {
                        skipt--;
                        pt--;
                    } else break;
                }
            }

            // 情况一：指针均大于 0，且字符不相同
            if (ps >= 0 && pt >= 0 && s.charAt(ps) != t.charAt(pt)) return false;
            // 情况二：一个指针小于零，一个大于零，说明两个字符串长度不同
            else if (ps < 0 && pt >= 0) return false;
            else if (ps >= 0 && pt < 0) return false;
            // 情况三：指针均大于 0，且字符相同，进入下一轮比较
            ps--;
            pt--; 
        }
        return true;
    }
}
```

#### 2.3.4. 比较版本号（3）

**题目 $165$​ 比较版本号**：给你两个版本号字符串`version1`和`version2`，请你比较它们。版本号由被点`'.'`分开的修订号组成。修订号的值是它转换为整数并忽略前导零。比较版本号时，请按从左到右的顺序依次比较它们的修订号。如果其中一个版本字符串的修订号较少，则将缺失的修订号视为`0`。返回规则如下：

- 如果`version1 < version2`返回`-1`。
- 如果`version1 > version2` 返回`1`。
- 除此之外返回`0`。

```markdown

- 字符串转换为整数的方式和题目 “字符串转换整数” 相同。
```

```java
// 时间复杂度 O(n + m)；空间复杂度 O(1)

class Solution {

        // 双指针分别指向两个字符串的起始位置
        int p1 = 0, n = version1.length();
```

### 2.4. 滑动窗口

> 滑动窗口是一种特殊的双指针法，通常用于解决数组或字符串中的**子数组或子串**相关的问题。它通过维护一个可以左右扩展的窗口，来寻找满足特定条件的子数组或子串，优化了暴力搜索方法的效率。滑动窗口法可以分为两类：
>
> - 最小滑动窗口法：即求满足条件的滑动窗口的最小长度。
>
>   ```java
>   // 模板
>   int left = 0;
>   for (int right = 0; right < nums.length; right++) {
>       // 判断 [left,right] 是否满足条件
>       while (满足条件) {  // 最大程度的压缩 left，使得滑窗尽可能的小
>           // 更新结果。注意：是在 while 循环内更新
>           left++;
>       }
>   }
>   ```
>
> - 最大滑动窗口法：即求满足条件的滑动窗口的最大长度。
>
>   ```java
>   // 模板
>   int left = 0;
>   for (int right = 0; right < nums.length; right++) {
>       // 判断 [left,right] 是否满足条件
>       while (不满足条件) {
>           left++;  // 每次移动最小单位，一旦满足条件就退出循环，使滑窗尽可能的大
>       }
>       // 更新结果。注意：是在 while 循环外更新
>   }
>   ```

#### 2.4.1. 长度最小的子数组

**题目 $209$​ 长度最小的子数组**：给定一个含有`n`个正整数的数组和一个正整数`target`。找出该数组中满足其总和大于等于`target`的长度最小的子数组。`[numsl, numsl+1, ..., numsr-1, numsr]` 并返回其长度**。**如果不存在符合条件的子数组，返回`0`。

```markdown
# 注意点：
- 最小滑动窗口。
```

```java
// 时间复杂度 O(n)；空间复杂度 O(1)
// n - 数组长度
class Solution {
    public int minSubArrayLen(int target, int[] nums) {
        int len = Integer.MAX_VALUE;
        int sum = 0;

        // 最小滑动窗口
        int left = 0;
        for (int right = 0; right < nums.length; right++) {
            sum += nums[right];
            while (sum >= target) {
                len = Math.min(len, right - left + 1);
                sum -= nums[left];
                left++;
            }
        }
        return (len == Integer.MAX_VALUE) ? 0 : len;
    }
}
```

**题目 $3$ 无重复字符的最长子串**：给定一个字符串`s`，请你找出其中不含有重复字符的最长子串的长度。`s`由英文字母、数字、符号和空格组成。

```java
// 时间复杂度 O(n)；空间复杂度 O(n)
// n - 数组长度
class Solution {
    public int lengthOfLongestSubstring(String s) {
        // 采用 Set 数据结构记录滑动窗口中出现过的字符
        Set<Character> set = new HashSet<>();
        int len = 0;

        // 最大滑动窗口
        int left = 0;
        for (int right = 0; right < s.length(); right++) {
            char c = s.charAt(right);

                char tmp = s.charAt(left);
                set.remove(tmp);
                left++;
            }
            set.add(c);
            len = Math.max(len, right - left + 1);
        }
        return len;
    }
}
```

#### 2.4.3. 水果成篮

**题目 $904$ 水果成篮**：你正在探访一家农场，农场从左到右种植了一排果树。这些树用一个整数数组`fruits`表示，其中`fruits[i]`是第`i`棵树上的水果种类。你想要尽可能多地收集水果。然而，农场的主人设定了一些严格的规矩，你必须按照要求采摘水果：

- 一旦你走到某棵树前，但水果不符合篮子的水果类型，那么就必须停止采摘。

给你一个整数数组`fruits`，返回你可以收集的水果的最大数目。

```markdown
# 注意点：
- 最大滑动窗口。
- 采用 Map 结构记录出现过的水果类型，以及次数。
- 需要先将当前元素添加到窗口中，然后再收缩窗口。
```

```java
// 时间复杂度 O(n)；空间复杂度 O(1)
// n - 数组长度
class Solution {
    public int totalFruit(int[] fruits) {
        // 采用 Map 数据结构记录滑动窗口中出现的类型，以及次数
        Map<Integer, Integer> hm = new HashMap<>();
        int len = 0;

        // 最大滑动窗口
        int left = 0;
        for (int right = 0; right < fruits.length; right++) {
            if (!hm.containsKey(fruits[right])) hm.put(fruits[right], 1);
            else hm.put(fruits[right], hm.get(fruits[right]) + 1);
            while (hm.size() > 2) {
                int tmp = fruits[left];
                if (hm.get(tmp) == 1) hm.remove(tmp);  // 删除类型
                else hm.put(tmp, hm.get(tmp) - 1);
                left++;
            }
            len = Math.max(len, right - left + 1);
        }
        return len;
    }
}
```

#### 2.4.4. 最小覆盖子串（hot100, 3）

**题目 $76$ 最小覆盖子串**：给你一个字符串`s`、一个字符串`t`。返回`s`中涵盖`t`所有字符的最小子串。如果`s`中不存在涵盖`t`所有字符的子串，则返回空字符串`""`。 

```markdown
# 注意点：
- 最小滑动窗口。
- 采用 int[] 结构作为哈希表。
```

```java
// 时间复杂度 O(n+m)；空间复杂度 O(1)
// n - s.length(); m - t.length()
class Solution {
    public String minWindow(String s, String t) {
        // 采用 int[] 数据结构记录滑动窗口中每个字符比 t 中少的个数
        // 既有大写又有小写字符 ('z' 编码为 122)，数组大小只要够用就行
        int[] hash = new int[122];
        for (int i = 0; i < t.length(); i++) {
            hash[t.charAt(i) - 'A']++;
        }
        int len = Integer.MAX_VALUE;
        String res = new String();

        // 最小滑动窗口
        int left = 0;
        for (int right = 0; right < s.length(); right++) {
            hash[s.charAt(right) - 'A']--;
            while (allCover(hash)) {
                // 记录结果
                if (len > right - left + 1) {
                    res = s.substring(left, right + 1);
                    len = right - left + 1;
                }
                hash[s.charAt(left) - 'A']++;
                left++;
            }
        }
        return res;
    }

    // 判断所有字符是否均被覆盖
    public boolean allCover(int[] nums) {
        for (int i = 0; i < nums.length; i++) {
            if (nums[i] > 0) return false;
        }
        return true;
    }
}
```
