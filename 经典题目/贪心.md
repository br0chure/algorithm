# 贪心

## 1. 跳跃游戏系列

> 这一系列的贪心题目需要注意：最后一个结果处理方式的差异。

### 1.1. 跳跃游戏Ⅱ（hot100）

**题目 $45$ 跳跃游戏Ⅱ**：给定一个长度为`n`的整数数组`nums`。初始位置为`nums[0]`，每个元素`nums[i]`表示从索引`i`向前跳转的最大长度。换句话说，如果你在`nums[i]`处，你可以跳转到任意`nums[i + j]`处。返回到达`nums[n - 1]`的最小跳跃次数。生成的测试用例确保可以到达`nums[n - 1]`。

```markdown
# 注意点：
- 局部最优：每一步尽可能跳的最远，即在当前跳跃范围内，寻找下一步跳跃的最远位置。
```

```java
class Solution {
    public int jump(int[] nums) {
        int count = 0;
        int curCover = 0;  // 当前覆盖范围，最开始覆盖 0 位置
        int nextCover = 0;  // 下一步覆盖范围（可以不需要初始化）
        for (int i = 0; i < nums.length; i++) {
            nextCover = Math.max(nextCover, i + nums[i]);
            // 当前覆盖范围耗尽
            if (i == curCover) {
                // 在启动下一步的覆盖范围之前，检查：当前覆盖范围超过了重点，则直接结束循环
                if (curCover >= nums.length - 1) break;
                // 否则，往后跳一步
                count++;
                curCover = nextCover;
            }
        }
        return count;
    }
}
```

### 1.2. 划分字母区间（hot100）

**题目 $763$ 划分字母区间**：给你一个字符串`s`。我们要把这个字符串划分为尽可能多的片段，同一字母最多出现在一个片段中。划分结果需要满足：将所有划分结果按顺序连接，得到的字符串仍然是`s`。返回一个表示每个字符串片段的长度的列表。

```markdown
# 注意点：
- 局部最优：寻找子串中所有不重复字符出现的最远位置。
- 由于循环的最后一个元素一定会触发“结果收集”，因此，不需要额外处理最后一个区间。
```

```java
class Solution {
    public List<Integer> partitionLabels(String s) {
        List<Integer> res = new ArrayList<>();
        // 采用 数组 作为哈希结构，记录每个字母出现的最远位置
        int[] hash = new int[26];
        for (int i = 0; i < s.length(); i++) {
            hash[s.charAt(i) - 'a'] = i;
        }

        int curCover = 0;  // 当前子串的最远位置
        int left = 0;  // 当前子串起始位置
        for (int right = 0; right < s.length(); right++) {
            curCover = Math.max(curCover, hash[s.charAt(right) - 'a']);
            if (right == curCover) {
                // 收集结果
                res.add(right - left + 1);
                // 更新
                left = right + 1;
            }
        }
        return res;
    }
}
```

### 1.3. 用最少的箭引爆气球

**题目 $452$ 用最少数量的箭引爆气球**：有一些球形气球贴在一堵用 XY 平面表示的墙面上。墙面上的气球记录在整数数组`points`，其中`points[i] = [xstart, xend]`表示水平直径在`xstart`和`xend`之间的气球。你不知道气球的确切 y 坐标。一支弓箭可以沿着 x 轴从不同点完全垂直地射出。在坐标`x`处射出一支箭，若有一个气球的直径的开始和结束坐标为`xstart, xend`， 且满足`xstart<=x<=xend`，则该气球会被引爆。可以射出的弓箭的数量没有限制。 弓箭一旦被射出之后，可以无限地前进。给你一个数组`points`，返回引爆所有气球所必须射出的最小弓箭数。 

```markdown
# 注意点：
- 局部最优：每一支箭尽可能射爆最多的气球。
- 需要额外处理最后一个区间。
```

```java
class Solution {
    public int findMinArrowShots(int[][] points) {
        // 按照左区间升序排列
        // 采用 Integer.compare(o1[0], o2[0]) 而不是 o1 - o2，防止发生数值越界
        Arrays.sort(points, (o1, o2) -> Integer.compare(o1[0], o2[0]));

        int res = 0;
        int minCover = Integer.MAX_VALUE;
        for (int i = 0; i < points.length; i++) {
            minCover = Math.min(points[i][1], minCover);
            if (points[i][0] > minCover) {
                res++;
                minCover = points[i][1];
            }
        }
        return res + 1;
    }
}
```

### 1.4. 无重叠区间

**题目 $435$ 无重叠区间**：给定一个区间的集合`intervals`，其中`intervals[i] = [starti, endi]`。返回需要移除区间的最小数量，使剩余区间互不重叠。注意只在一点上接触的区间是不重叠的。例如`[1, 2]`和`[2, 3]`是不重叠的。

```markdown
# 注意点：
- 本题求解思路与 452 用最少的箭引爆气球 基本完全一致。
- 需要额外处理最后一个区间。
```

```java
class Solution {
    public int eraseOverlapIntervals(int[][] intervals) {
        // 对左区间进行排序
        Arrays.sort(intervals, (o1, o2) -> o1[0] - o2[0]);

        int count = 0;
        int minCover = Integer.MAX_VALUE;
        for (int i = 0; i < intervals.length; i++) {
            minCover = Math.min(minCover, intervals[i][1]);
            if (intervals[i][0] >= minCover) {
                count++;
                minCover = intervals[i][1];
            }
        }
        return intervals.length - count - 1;
    }
}
```

### 1.5. 合并区间（hot100, 2）

**题目 $56$ 合并区间**：以数组`intervals`表示若干个区间的集合，其中单个区间为`intervals[i] = [starti, endi]`。请你合并所有重叠的区间，并返回一个不重叠的区间数组，该数组需恰好覆盖输入中的所有区间。

```markdown
# 注意点：
- 本题求解思路可借鉴 452 用最少的箭引爆气球，435 无重叠区间，但存在细节上的不同，注意代码逻辑。
- 需要额外处理最后一个区间。
```

```java
// 时间复杂度 O(nlogn)；空间复杂度 O(n)
// n - 数组长度
class Solution {
    public int[][] merge(int[][] intervals) {
        // 按照左区间进行升序排列
        Arrays.sort(intervals, (o1, o2) -> o1[0] - o2[0]);

        List<int[]> res = new ArrayList<>();
        int left = intervals[0][0], right = intervals[0][1];
        for (int i = 1; i < intervals.length; i++) {
            if (intervals[i][0] > right) {
                res.add(new int[]{left, right});
                left = intervals[i][0];
                right = intervals[i][1];
            } else {
                right = Math.max(right, intervals[i][1]);
            }
        }
        res.add(new int[]{left, right});  // 注意保存最后一个区间
        return res.toArray(new int[res.size()][2]);
    }
}
```

### 2.1. 跳跃游戏（hot100）

**题目 $55$ 跳跃游戏**：给你一个非负整数数组`nums`，你最初位于数组的第一个下标。数组中的每个元素代表你在该位置可以跳跃的最大长度（但不一定要跳跃最大长度）。判断你是否能够到达最后一个下标，如果可以，返回`true`；否则，返回`false`。

```markdown
# 注意点：
- 局部最优：求每一步跳跃的最大覆盖范围。
```

```java
class Solution {
    public boolean canJump(int[] nums) {
        int cover = 0;  // 覆盖范围
        for (int i = 0; i <= cover; i++) {  // 注意循环的结束条件
            cover = Math.max(cover, nums[i] + i);
            if (cover >= nums.length - 1) return true;
        }
        return false;
    }
}
```
