# 二叉树

**二叉树（Binary Tree）**是计算机科学中一种基本的数据结构，用于存储数据并支持快速检索、插入、删除等操作。它是一种由节点（Node）组成的树形结构，其中每个节点最多有两个子节点：左子节点和右子节点。

## 1. 分类

### 1.1. 满二叉树

一棵二叉树，如果每个节点要么没有子节点，要么恰好有两个子节点，这棵树就是**满二叉树（Full Binary Tree）**。

```markdown
        1
       / \
      2   3
     / \ 
    4  5 
```

### 1.2. 完美二叉树

**完美二叉树（Perfect Binary Tree）**的每个非叶子节点都有两个子节点，且所有叶子节点在**同一层**，每一层都被完全填满，结构严格平衡。当二叉树深度为 $d$ 时，树的节点总数为 $2^{d}-1$。

```markdown
       1
      / \
     2   3
    / \  / \
   4   5 6  7
```

> 完美二叉树一定是满二叉树，满二叉树不一定是完美二叉树。

### 1.3. 完全二叉树

一棵二叉树，如果除最后一层外，所有层的节点都是满的，且最后一层的节点从左向右尽可能紧密排列（左边有节点，右边可能有空位），那么这棵树就是**完全二叉树（Complete Binary Tree）**。

完全二叉树有以下特点：

- 完全二叉树不要求每个节点都有两个子节点，但要求节点尽量向左排列。

- 完全二叉树的结构使得它特别适合用数组来存储和表示。

```markdown
       1
      / \
     2   3
    / \  / 
   4   5 6  
```

> Java 中的优先级对列，即大顶堆和小顶堆就是完全二叉树结构。

### 1.4. 平衡二叉搜索树

平衡二叉搜索树同时满足**二叉搜索树**和**平衡二叉树**的要求：

- 二叉搜索树：左子树的所有节点值小于根节点值；右子树的所有节点值大于根节点值；左右子树仍然是二叉搜索树。基本操作（查找、插入、删除）时间复杂度为 $O(\log{n})$。
- 平衡二叉树：任何节点的左子树和右子树的高度差不超过 $1$。

常见的平衡二叉搜索树有：

- **AVL 树**：严格平衡，左右子树高度差最多 $1$。
- **红黑树**：近似平衡，保证黑高度相等，允许局部失衡。

## 2. 基础

### 2.1. 深度优先遍历

二叉树的深度优先遍历包括：前序遍历、中序遍历、后序遍历。需要熟练掌握**递归法、迭代法**的代码。

#### 2.1.1. 二叉树的前序遍历

**题目 $144$ 二叉树的前序遍历**：给你二叉树的根节点`root`，返回它节点值的前序遍历。

```java
// 递归法：
// 时间复杂度 O(n)；空间复杂度 O(n)
// n - 节点数量
class Solution {
    public List<Integer> preorderTraversal(TreeNode root) {
        List<Integer> list = new ArrayList<>();
        preorder(root, list);
        return list;
    }

    public void preorder(TreeNode root, List<Integer> list) {
        // 递归结束条件
        if (root == null) return;

        list.add(root.val);
        preorder(root.left, list);
        preorder(root.right, list);
    }
}
```

```markdown
# 注意点：
- 左右孩子的入栈顺序。
```

```java
// 迭代法：
// 时间复杂度 O(n)；空间复杂度 O(n)
// n - 节点数量
class Solution {
    public List<Integer> preorderTraversal(TreeNode root) {
        // 栈模拟递归
        Deque<TreeNode> stack = new ArrayDeque<>();
        List<Integer> res = new ArrayList<>();
        if (root == null) return res;
        stack.push(root);

        while (!stack.isEmpty()) {
            TreeNode cur = stack.pop();
            res.add(cur.val);
            // 将右孩子放入栈中
            if (cur.right != null) stack.push(cur.right);
            // 将左孩子放入栈中
            if (cur.left != null) stack.push(cur.left);
        }
        return res;
    }
}
```

#### 2.1.2. 二叉树的中序遍历（hot100, 2）

**题目 $94$ 二叉树的中序遍历**：给定一个二叉树的根节点`root`，返回它的中序遍历。

```java
// 递归法：
// 时间复杂度 O(n)；空间复杂度 O(n)
// n - 节点数量
class Solution {
    public List<Integer> inorderTraversal(TreeNode root) {
        List<Integer> list = new ArrayList<>();
        inorder(root, list);
        return list;
    }

    public void inorder(TreeNode root, List<Integer> list) {
        // 递归结束条件
        if (root == null) return;

        inorder(root.left, list);
        list.add(root.val);
        inorder(root.right, list);
    }
}
```

```markdown
# 注意点：中序遍历的迭代法相对复杂，需熟练。
- 中序遍历的迭代法由于访问顺序（遍历顺序）和处理顺序（结果顺序）不同，无法采用前序、后续的模板。
- 需要通过一个额外的指针来遍历树。
```

```java
// 迭代法
// 时间复杂度 O(n)；空间复杂度 O(n)
// n - 节点数量
class Solution {
    public List<Integer> inorderTraversal(TreeNode root) {
        Deque<TreeNode> stack = new ArrayDeque<>();
        List<Integer> res = new ArrayList<>();
        if (root == null) return res;
        stack.push(root);

        TreeNode cur = root.left;  // 指针：记录当前访问的元素
        while (cur != null || !stack.isEmpty()) {  // 注意：|| 不是 &&
            if (cur != null) {
                stack.push(cur);
                cur = cur.left;
            } else {
                cur = stack.pop();
                res.add(cur.val);
                cur = cur.right;
            }
        }
        return res;
    }
}
```

#### 2.1.3. 二叉树的后序遍历

**题目 $145$ 二叉树的后序遍历**：给你一棵二叉树的根节点`root`，返回其节点值的后序遍历。

```java
// 递归法：
// 时间复杂度 O(n)；空间复杂度 O(n)
// n - 节点数量
class Solution {
    public List<Integer> postorderTraversal(TreeNode root) {
        List<Integer> list = new ArrayList<>();
        postorder(root, list);
        return list;
    }

    public void postorder(TreeNode root, List<Integer> list) {
        // 递归结束条件
        if (root == null) return;

        postorder(root.left, list);
        postorder(root.right, list);
        list.add(root.val);
    }
}
```

```markdown
# 注意点：
- 左右孩子的入栈顺序。
- 反转 list。
```

```java
// 迭代法：
// 时间复杂度 O(n)；空间复杂度 O(n)
// n - 节点数量
class Solution {
    public List<Integer> postorderTraversal(TreeNode root) {
        Deque<TreeNode> stack = new ArrayDeque<>();
        List<Integer> res = new ArrayList<>();
        if (root == null) return res;
        stack.push(root);

        while (!stack.isEmpty()) {
            TreeNode cur = stack.pop();
            res.add(cur.val);
            // 将左孩子放入栈
            if (cur.left != null) stack.push(cur.left);
            // 将右孩子放入栈
            if (cur.right != null) stack.push(cur.right);
        }
        // 反转 list
        Collections.reverse(res);
        return res;
    }
}
```

### 2.2. 广度优先遍历

广度优先遍历是逐层遍历，经典模板为**题目 $102$ 二叉树的层序遍历**，其余题目为层序遍历的应用。

#### 2.2.1. 二叉树的层序遍历（hot100, 1）

**题目 $102$ 二叉树的层序遍历**：给你二叉树的根节点`root`，返回其节点值的层序遍历，即逐层地，从左到右访问所有节点。

```java
// 时间复杂度 O(n)；空间复杂度 O(n)
// n - 节点数量
class Solution {
    public List<List<Integer>> levelOrder(TreeNode root) {
        // 普通队列
        Deque<TreeNode> queue = new ArrayDeque<>();
        List<List<Integer>> res = new ArrayList<>();
        if (root == null) return res;
        queue.offer(root);

        while (!queue.isEmpty()) {
            // 遍历每一层
            int size = queue.size();
            List<Integer> tmpList = new ArrayList<>();
            while (size > 0) {
                TreeNode cur = queue.poll();
                tmpList.add(cur.val);
                if (cur.left != null) queue.offer(cur.left);
                if (cur.right != null) queue.offer(cur.right);
                size--;
            }
            res.add(tmpList);
        }
        return res;
    }
}
```

#### 2.2.2. 二叉树的锯齿形层序遍历（1）

**题目 $103$ 二叉树的锯齿形层序遍历**：给你二叉树的根节点`root`，返回其节点值的锯齿形层序遍历，即先从左往右，再从右往左进行下一层遍历，以此类推，层与层之间交替进行。

```markdown
# 注意点：根据深度判断，是否反转当前层的结果。
```

```java
// 时间复杂度 O(n)；空间复杂度 O(n)
// n - 节点数量
class Solution {
    public List<List<Integer>> zigzagLevelOrder(TreeNode root) {
        // 普通队列
        Deque<TreeNode> queue = new ArrayDeque<>();
        List<List<Integer>> res = new ArrayList<>();
        if (root == null) return res;
        queue.offer(root);

        int depth = 0;
        while (!queue.isEmpty()) {
            depth++;
            int size = queue.size();
            List<Integer> tmpList = new ArrayList<>();
            while (size > 0) {
                TreeNode cur = queue.poll();
                tmpList.add(cur.val);
                if (cur.left != null) queue.offer(cur.left);
                if (cur.right != null) queue.offer(cur.right);
                size--;
            }
            // 如果是偶数层，则反转当前层的结果
            if (depth % 2 == 0) Collections.reverse(tmpList);
            res.add(tmpList);
        }
        return res;
    }
}
```

本题最正常的思路是采用双端队列进行求解，根据层数奇偶性，元素从队列头部进出，或从队列尾部进出。

```markdown
# 注意：同一层的元素在进队列和出队列的“口”是相同的，否则思路会非常的混乱。
```

```java
class Solution {
    public List<List<Integer>> zigzagLevelOrder(TreeNode root) {
        List<List<Integer>> res = new ArrayList<>();
        if (root == null) {
            return res;
        }
        Deque<TreeNode> deque = new ArrayDeque<>();
        deque.offerFirst(root);
        int deep = 1;

        while (!deque.isEmpty()) {
            int size = deque.size();
            List<Integer> tmp = new ArrayList<>();
            while (size > 0) {
                if (deep % 2 == 1) {
                    TreeNode cur = deque.pollFirst();
                    tmp.add(cur.val);
                    if (cur.left != null) {
                        deque.offerLast(cur.left);
                    }
                    if (cur.right != null) {
                        deque.offerLast(cur.right);
                    }
                } else {
                    TreeNode cur = deque.pollLast();
                    tmp.add(cur.val);
                    if (cur.right != null) {
                        deque.offerFirst(cur.right);
                    }
                    if (cur.left != null) {
                        deque.offerFirst(cur.left);
                    }
                }
                size--;
            }
            res.add(tmp);
            deep++;
        }
        return res;
    }
}
```

#### 2.2.3. 二叉树的右视图（hot100, 2）

**题目 $199$ 二叉树的右视图**：给定一个二叉树的根节点`root`，想象自己站在它的右侧，按照从顶部到底部的顺序，返回从右侧所能看到的节点值。

```markdown
# 注意点：记录每层最后一个出队列的元素值。
```

```java
// 时间复杂度 O(n)；空间复杂度 O(n)
// n - 节点数量
class Solution {
    public List<Integer> rightSideView(TreeNode root) {
        // 普通队列
        Deque<TreeNode> queue = new ArrayDeque<>();
        List<Integer> res = new ArrayList<>();
        if (root == null) return res;
        queue.offer(root);

        while (!queue.isEmpty()) {
            int size = queue.size();
            while (size > 0) {
                size--;
                TreeNode cur = queue.poll();
                if (cur.left != null) queue.offer(cur.left);
                if (cur.right != null) queue.offer(cur.right);
                // 记录每层最后一个出队列，即最右侧元素的值
                if (size == 0) res.add(cur.val);
            }
        }
        return res;
    }
}
```

### 2.3. 深度 & 高度

> 深度和高度的区别：
>
> - 深度（自上而下——前序遍历）：从**根节点**到该节点的路径上的节点数。
> - 高度（自下而上——后序遍历）：从该节点到**最远叶子节点**的路径上的节点数。
>

经典模板为**题目 $104$ 二叉树的最大深度**，其余题目为该模板的应用。

#### 2.3.1. 二叉树的最大深度（hot100）

**题目 $104$ 二叉树的最大深度**：给定一个二叉树`root`，返回其最大深度。二叉树的**最大深度**是指从根节点到最远叶子节点的最长路径上的节点数。

```markdown
# 注意点：
- 后序遍历。
```

```java
// 时间复杂度 O(n)；空间复杂度 O(n)
// n - 节点数量
class Solution {
    public int maxDepth(TreeNode root) {
        // 递归结束条件
        if (root == null) return 0;

        // 左 - 右
        int leftHeight = maxDepth(root.left);
        int rightHeight = maxDepth(root.right);
        // 中
        return Math.max(leftHeight, rightHeight) + 1;
    }
}
```

#### 2.3.2. 二叉树的最小深度

**题目 $111$ 二叉树的最小深度**：给定一个二叉树，找出其最小深度。最小深度是从根节点到最近叶子节点的最短路径上的节点数量。说明：叶子节点是指没有子节点的节点。

```markdown
# 注意点：
- 后序遍历。
- 最小深度的定义，需要添加判断条件。
```

```java
// 时间复杂度 O(n)；空间复杂度 O(n)
// n - 节点数量
class Solution {
    public int minDepth(TreeNode root) {
        // 递归结束条件
        if (root == null) return 0;

        // 左 - 右
        int leftHeight = minDepth(root.left);
        int rightHeight = minDepth(root.right);
        // 中
        // 左节点为 null；右节点为 null；左右节点均不为 null
        if (root.left == null) return rightHeight + 1;
        if (root.right == null) return leftHeight + 1;
        return Math.min(leftHeight, rightHeight) + 1;
    }
}
```

#### 2.3.3. 平衡二叉树

**题目 $110$ 平衡二叉树**：给定一个二叉树，判断它是否是平衡二叉树。平衡二叉树是指该树所有节点的左右子树的高度相差不超过`1`。 

```markdown
# 注意点：
- 后序遍历。
- 采用 -1 作为标记位，标记是否为平衡二叉树。
```

```java
// 时间复杂度 O(n)；空间复杂度 O(n)
// n - 节点数量
class Solution {
    public boolean isBalanced(TreeNode root) {
        // 约定：如果返回 -1 说明不是平衡二叉树
        return postorder(root) != -1;
    }

    public int postorder(TreeNode root) {
        // 递归结束条件
        if (root == null) return 0;

        // 左 - 右
        int leftHeight = postorder(root.left);
        if (leftHeight == -1) return -1;
        int rightHeight = postorder(root.right);
        if (rightHeight == -1) return -1;
        // 中
        if (Math.abs(leftHeight - rightHeight) > 1) return -1;
        return Math.max(leftHeight, rightHeight) + 1;
    }
}
```

#### 2.3.4. 二叉树的直径（hot100）

**题目 $543$ 二叉树的直径**：给你一棵二叉树的根节点，返回该树的直径。二叉树的直径是指树中任意两个节点之间最长路径的长度。这条路径可能经过也可能不经过根节点`root`。两节点之间路径的长度由它们之间边数表示。

```markdown
# 注意点：
- 后序遍历。
- 以任意节点为转折的 直径 = 左子树高度 + 右子树高度。
```

```java
// 时间复杂度 O(n)；空间复杂度 O(n)
// n - 节点数量
class Solution {
    int res = 0;
    public int diameterOfBinaryTree(TreeNode root) {
        postorder(root);
        return res;
    }

    public int postorder(TreeNode root) {
        // 递归结束条件
        if (root == null) return 0;

        // 左 - 右
        int leftHeight = postorder(root.left);
        int rightHeight = postorder(root.right);
        // 中
        if (leftHeight + rightHeight > res) res = leftHeight + rightHeight;
        return Math.max(leftHeight, rightHeight) + 1;
    }
}
```

#### 2.3.5. 二叉树中的最大路径和（hot100, 2）

**题目 $124$ 二叉树中的最大路径和**：二叉树中的路径被定义为一条节点序列，序列中每对相邻节点之间都存在一条边。同一个节点在一条路径序列中至多出现一次。该路径至少包含一个节点，且不一定经过根节点。路径和是路径中各节点值的总和。给你一个二叉树的根节点`root`，返回其最大路径和。

```markdown
# 注意点：
- 后序遍历。
- 思考：“结果”和“返回值”的不同。
```

```java
// 时间复杂度 O(n)；空间复杂度 O(n)
// n - 节点数量
class Solution {
    int res = Integer.MIN_VALUE;
    public int maxPathSum(TreeNode root) {
        postorder(root);
        return res;
    }

    // 递归返回：当前节点路径的最大值
    public int postorder(TreeNode root) {
        // 递归结束条件
        if (root == null) return 0;

        // 左 - 右
        int leftSum = postorder(root.left);
        int rightSum = postorder(root.right);
        // 中：
        // 返回值：只取当前节点；当前节点 + 左子树；当前节点 + 右子树
        int returnVal = Math.max(root.val, Math.max(root.val + leftSum, root.val + rightSum));
        // 结果：只取当前节点；当前节点 + 左子树；当前节点 + 右子树；当前节点 + 左、右子树
        res = Math.max(res, Math.max(returnVal, root.val + leftSum + rightSum));
        return returnVal;
    }
}
```

## 3. 构造二叉树系列

### 3.1. 从中序与后序遍历序列构造二叉树

**题目 $106$ 从中序与后序遍历序列构造二叉树**：给定两个整数数组`inorder`和`postorder`，其中`inorder`是二叉树的中序遍历，`postorder`是同一棵树的后序遍历，请你构造并返回这颗二叉树。`inorder`和`postorder`都由不同的值组成。

```markdown
# 注意点：
- 后序数组用于确定根节点。
- 切分中序序列、后序序列时，索引不要出错。
```

```java
// 时间复杂度 O(n^2)；空间复杂度 O(n)
// n - 序列长度
class Solution {
    public TreeNode buildTree(int[] inorder, int[] postorder) {
        return traversal(inorder, 0, inorder.length - 1, postorder, 0, postorder.length - 1);
    }

    public TreeNode traversal(int[] inorder, int inbegin, int inend, int[] postorder, int postbegin, int postend) {  // 左闭右闭
    // 递归结束条件
    if (inbegin > inend || postbegin > postend) return null;

    // 当前根节点
    int rootVal = postorder[postend];
    TreeNode root = new TreeNode(rootVal);

    // 切分中序序列
    int idx = inbegin;
    while (inorder[idx] != rootVal) idx++;
    int inbeginLeft = inbegin;
    int inendLeft = idx - 1;
    int inbeginRight = idx + 1;
    int inendRight = inend;

    // 切分后序序列
    int postbeginLeft = postbegin;
    int postendLeft = postbeginLeft + (idx - inbegin - 1);
    int postbeginRight = postendLeft + 1;
    int postendRight = postend - 1;

    // 递归处理左、右子树
    root.left = traversal(
        inorder, inbeginLeft, inendLeft, postorder, postbeginLeft, postendLeft);
    root.right = traversal(
        inorder, inbeginRight, inendRight, postorder, postbeginRight, postendRight);
    return root;
    }
}
```

### 3.2. 从前序与中序遍历序列构造二叉树（hot100, 3）

**题目 $105$ 从前序与中序遍历序列构造二叉树**：给定两个整数数组`preorder`和`inorder`，其中`preorder`是二叉树的先序遍历，`inorder`是同一棵树的中序遍历，请构造二叉树并返回其根节点。`preorder`和`inorder`均无重复元素。

```java
// 时间复杂度 O(nlogn)~O(n^2)；空间复杂度 O(logn)~O(n)
// n - 序列长度
class Solution {
    public TreeNode buildTree(int[] preorder, int[] inorder) {
        return traversal(preorder, 0, preorder.length - 1, inorder, 0, inorder.length - 1);
    }

    public TreeNode traversal(int[] preorder, int prebegin, int preend, int[] inorder, int inbegin, int inend) {  // 左闭右闭
        // 递归结束条件
        if (prebegin > preend || inbegin > inend) return null;

        // 当前根节点
        int rootVal = preorder[prebegin];
        TreeNode root = new TreeNode(rootVal);
        // 寻找 rootVal 在前序序列中的索引位置
        int idx = inbegin;
        while (inorder[idx] != rootVal) idx++;
        
        // 切分中序序列
        int inbeginLeft = inbegin;
        int inendLeft = idx - 1;
        int inbeginRight = idx + 1;
        int inendRight = inend;
        // 切分前序序列
        int prebeginLeft = prebegin + 1;
        int preendLeft = prebeginLeft + (idx - inbegin - 1);
        int prebeginRight = preendLeft + 1;
        int preendRight = preend;

        // 递归处理左、右子树
        root.left = traversal(
            preorder, prebeginLeft, preendLeft, inorder, inbeginLeft, inendLeft);
        root.right = traversal(
            preorder, prebeginRight, preendRight, inorder, inbeginRight, inendRight);
        return root;
    }
}
```

### 5.3. 路径总和Ⅱ

**题目 $113$ 路径总和Ⅱ**：给你二叉树的根节点`root`和一个整数目标和`targetSum`，找出所有从根节点到叶子节点路径总和等于给定目标和的路径。叶子节点是指没有子节点的节点。

```markdown
# 注意点：
- 前序遍历。
- 由于只在叶子节点收集结果，因此，递归结束条件有两个。
- 回溯逻辑：当前层添加元素 & 当前层删除。
- 收获结果时 List 需要新创建。
```

```java
// 时间复杂度 O(n)；空间复杂度 O(n)
// n - 节点数量
class Solution {
    List<List<Integer>> res = new ArrayList<>();
    public List<List<Integer>> pathSum(TreeNode root, int targetSum) {
        List<Integer> path = new ArrayList<>();
        postorder(root, targetSum, path);
        return res;
    }

    public void postorder(TreeNode root, int targetSum, List<Integer> path) {
        // 递归结束条件
        if (root == null) return;
        if (root.left == null && root.right == null) {
            if (targetSum == root.val) {
                path.add(root.val);
                res.add(new ArrayList<>(path));
                // 回溯
                path.remove(path.size() - 1);
            }
            return;
        }

        // 中
        targetSum -= root.val;
        path.add(root.val);
        // 左 - 右
        postorder(root.left, targetSum, path);
        postorder(root.right, targetSum, path);
        // 回溯
        path.remove(path.size() - 1);
    }
}
```

### 5.4. 路径总和Ⅲ（hot100）

**题目 $437$ 路径总和Ⅲ**：给定一个二叉树的根节点`root`和一个整数`targetSum`，求该二叉树里节点值之和等于`targetSum`的路径的数目。路径不需要从根节点开始，也不需要在叶子节点结束，但是路径方向必须是向下的（只能从父节点到子节点）。

```markdown
# 注意点：
- 前缀和求解思路；“虚拟前缀和”。
- int 类型溢出问题。
```

```java
// 时间复杂度 O(n)；空间复杂度 O(n)
// n - 节点数量
class Solution {
    // Map 保存 <前缀和, 出现次数>
    private Map<Long, Integer> hash = new HashMap<>();
    private int res = 0;
    public int pathSum(TreeNode root, int targetSum) {
        // 添加“虚拟前缀和”
        hash.put(0L, 1);
        traversal(root, 0, targetSum);
        return res;
    }

    public void traversal(TreeNode root, long pref, int targetSum) {
        if (root == null) return;

        pref += root.val;
        // 判断是否存在路径
        if (hash.containsKey(pref - targetSum)) {
            res += hash.get(pref - targetSum);
        }

        // 更新 Map
        if (hash.containsKey(pref)) {
            hash.put(pref, hash.get(pref) + 1);
        } else {
            hash.put(pref, 1);
        }
        // 递归
        traversal(root.left, pref, targetSum);
        traversal(root.right, pref, targetSum);
        // 回溯
        if (hash.get(pref) > 1) {
            hash.put(pref, hash.get(pref) - 1);
        } else {
            hash.remove(pref);
        }
    }
}
```

### 6.4. 删除二叉搜索树中的节点

**题目 $450$ 删除二叉搜索树中的节点**：给定一个二叉搜索树的根节点`root`和一个值`key`，删除二叉搜索树中的`key`对应的节点，并保证二叉搜索树的性质不变。返回二叉搜索树（有可能被更新）的根节点的引用。一般来说，删除节点可分为两个步骤：首先找到需要删除的节点；如果找到了，删除它。

```markdown
# 注意点：本题较复杂，要考虑的情况很多，需要熟练。
- 情况一：没有找到要删除的节点。
- 情况二：删除的节点为叶子节点。
- 情况三：删除的节点左子树为空，右子树不为空。
- 情况四：删除的节点左子树不为空，右子树为空。
- 情况五（这种情况最复杂）：左子树、右子树均不为空。
```

```java
// 时间复杂度 O(logn)；空间复杂度 O(logn)
// n - 节点数量
class Solution {
    public TreeNode deleteNode(TreeNode root, int key) {
        // 递归结束条件
        // 1. 没有搜索到值
        if (root == null) return null;
        if (root.val == key) {
            // 2. 删除节点为叶子节点
            if (root.left == null && root.right == null) return null;
            // 3. 左子树为空，右子树不为空
            if (root.left == null && root.right != null) return root.right;
            // 4. 左子树不为空，右子树为空
            if (root.left != null && root.right == null) return root.left;
            // 5. 左右子树均不为空
            if (root.left != null && root.right != null) {
                // 右子树的根节点继位，并将左子树拼接到右子树最左下角叶子节点上
                TreeNode tmp = root.right;
                while (tmp.left != null) tmp = tmp.left;
                tmp.left = root.left;
                return root.right;
            }
        }

        if (key < root.val) {
            root.left = deleteNode(root.left, key);
        } else if (key > root.val) {
            root.right = deleteNode(root.right, key);
        }
        return root;
    }
}
```

```java
// n - 节点数量
class Solution {
    List<TreeNode> list = new ArrayList<>();
    public void flatten(TreeNode root) {
        postorder(root);
        // 节点数小于等于 1
        if (list.size() <= 1) return;
        for (int i = 1; i < list.size(); i++) {
            TreeNode pre = list.get(i - 1);
            TreeNode cur = list.get(i);
            pre.left = null;
            pre.right = cur;
        }
    }

    public void postorder(TreeNode root) {
        // 递归结束条件
        if (root == null) return;

        // 中
        list.add(root);
        // 左 - 右
        postorder(root.left);
        postorder(root.right);
    }
}
```

```markdown
# 进阶要求：采用空间复杂度 O(1) 的求解算法，即不能使用递归。
- 求解思路非常巧妙：直接修改二叉树结构。
```

```java
// 时间复杂度 O(n)；空间复杂度 O(1)
// n - 节点数量
class Solution {
    public void flatten(TreeNode root) {
        TreeNode cur = root;
        while (cur != null) {
            if (cur.left != null) {
                TreeNode tmp = cur.left;
                while (tmp.right != null) tmp = tmp.right;
                tmp.right = cur.right;
                cur.right = cur.left;
                cur.left = null;
            }
            cur = cur.right;
        }
    }
}
```

### 7.4. 二叉树的最近公共祖先（hot100, 1）

**题目 $236$ 二叉树的最近公共祖先**：给定一个二叉树, 找到该树中两个指定节点的最近公共祖先。百度百科中最近公共祖先的定义为：对于有根树`T`的两个节点`p, q`，最近公共祖先表示为一个节点`x`，满足`x`是`p, q`的祖先且`x`的深度尽可能大，一个节点也可以是它自己的祖先。

```markdown
# 注意点：
- 后序遍历。
```

```java
// 时间复杂度 O(n)；空间复杂度 O(n)
// n - 节点数量
class Solution {
    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        // 递归结束条件
        if (root == null) return null;

        // 左 - 右
        TreeNode left = lowestCommonAncestor(root.left, p, q);
        TreeNode right = lowestCommonAncestor(root.right, p, q);
        // 中
        if (root == p || root == q) return root;
        else {
            if (left == null && right == null) return null;
            else if (left == null && right != null) return right;
            else if (left != null && right == null) return left;
            else return root;
        }
    }
}
```
