# 链表

## 1. 反转链表系列

### 1.1. 反转链表（hot100, 1）

**题目 $206$ 反转链表**：给你单链表的头节点`head`，请你反转链表，并返回反转后的链表。

本题一定需要熟练掌握**迭代法**——双指针：

```java
// 时间复杂度 O(n)；空间复杂度 O(1)
// n - 链表长度
class Solution {
    public ListNode reverseList(ListNode head) {
        ListNode cur = head;
        ListNode pre = null;
        while (cur != null) {
            ListNode tmp = cur.next;  // 临时节点（重点）
            cur.next = pre;  // 改变方向
            // 双指针同时向后移动一位
            pre = cur;
            cur = tmp;
        }
        return pre;
    }
}
```

在迭代法的基础上，可以进一步实现**递归法（递归法的思路和双指针完全相同）**：

```java
// 时间复杂度 O(n)；空间复杂度 O(n)
// n - 链表长度
class Solution {
    public ListNode reverseList(ListNode head) {
        return traversal(head, null);
    }

    public ListNode traversal(ListNode cur, ListNode pre) {
        // 递归结束条件
        if (cur == null) return pre;

        ListNode tmp = cur.next;  // 临时节点
        cur.next = pre;  // 改变方向
        // 双指针同时向后移动一位
        return traversal(tmp, cur);
    }
}
```

### 1.2. 回文链表（hot100）

**题目 $234$ 回文链表**：给你一个单链表的头节点`head`，请你判断该链表是否为回文链表。如果是，返回`true`；否则，返回`false`。实现空间复杂度为 $O(1)$ 的求解思路。

```markdown
# 注意点：
- 综合 “反转链表、链表的中间节点” 两道题的思路，我们可以将后半部分链表翻转后，与前半部分链表进行比较。
```

```java
// 时间复杂度 O(n)，空间复杂度 O(1)
// n - 链表长度
class Solution {
    public boolean isPalindrome(ListNode head) {
        ListNode newHead = reverseList(middleNode(head));
        ListNode cur = head;  // 原链表
        ListNode curNew = newHead;  // 后一半链表（翻转后）
        while (curNew != null) {  // 注意结束条件
            if (cur.val != curNew.val) return false;
            cur = cur.next;
            curNew = curNew.next;
        }
        return true;
    }

    // 链表的中间节点
    public ListNode middleNode(ListNode head) {
        ListNode fast = head, slow = head;
        while (fast != null && fast.next != null) {
            fast = fast.next.next;
            slow = slow.next;
        }
        return slow;
    }

    // 反转链表
    public ListNode reverseList(ListNode head) {
        ListNode cur = head;
        ListNode pre = null;
        while (cur != null) {
            ListNode tmp = cur.next;
            cur.next = pre;
            pre = cur;
            cur = tmp;
        }
        return pre;
    }
}
```

### 1.3. 重排链表（2）

**题目 $143$ 重排链表**：给定一个单链表`L`的头节点`head`，单链表`L`表示为：

```
L0 → L1 → … → Ln - 1 → Ln
```

请将其重新排列后变为：

```
L0 → Ln → L1 → Ln - 1 → L2 → Ln - 2 → …
```

不能只是单纯的改变节点内部的值，而是需要实际的进行节点交换。

```markdown
# 注意点：
- 综合 “反转链表、链表的中间节点” 两道题的思路，可以将后半部分链表反转，通过双指针重排链表。
- 注意：双指针重排链表时的结束条件
```

```java
// 时间复杂度 O(n)，空间复杂度 O(1)
// n - 链表长度
class Solution {
    public void reorderList(ListNode head) {
        // 中间节点
        ListNode mid = findMiddle(head);
        // 反转后半部分链表
        ListNode newHead = reverseList(mid);
        // 双指针重排链表
        ListNode p1 = head, p2 = newHead;
        while (p2 != mid) {
            ListNode tmp1 = p1.next;
            ListNode tmp2 = p2.next;
            p1.next = p2;
            p2.next = tmp1;
            p1 = tmp1;
            p2 = tmp2;
        }
    }
    
    // 链表的中间节点
    public ListNode findMiddle(ListNode head) {
        ListNode slow = head, fast = head;
        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;
        }
        return slow;
    }
    
    // 反转链表
    public ListNode reverseList(ListNode begin) {
        ListNode pre = null;
        ListNode cur = begin;
        while (cur != null) {
            ListNode tmp = cur.next;
            cur.next = pre;
            pre = cur;
            cur = tmp;
        }
        return pre;
    }
}
```

### 1.4. 反转链表Ⅱ（2）

**题目 $92$ 反转链表Ⅱ**：给你单链表的头指针`head`和两个整数`left`和`right`，其中`left <= right`。请你反转从位置`left`到位置`right`的链表节点，返回反转后的链表。

```markdown
# 注意点：
- 本题需要获取反转开始位置的前一个节点来进行反转后链表的组装。由于头节点并不存在前驱节点，因此考虑设置虚拟头节点。
```

```java
// 时间复杂度 O(n)，空间复杂度 O(1)
// n - 链表长度
class Solution {
    public ListNode reverseBetween(ListNode head, int left, int right) {
        // 使用虚拟头节点
        ListNode dummyHead = new ListNode(0, head);
        // leftNode 指向翻转部分的前一个结点
        // rightNode 指向翻转部分的后一个节点
        ListNode leftNode = dummyHead, rightNode = dummyHead;
        while (left > 1) {
            leftNode = leftNode.next;
            left--;
        }
        while (right >= 0) {
            rightNode = rightNode.next;
            right--;
        }
        // 翻转对应部分
        ListNode newHead = reverseList(leftNode.next, rightNode);
        leftNode.next.next = rightNode;
        leftNode.next = newHead;
        return dummyHead.next;
    }

    // 反转链表
    public ListNode reverseList(ListNode begin, ListNode end) {
        ListNode pre = null;
        ListNode cur = begin;
        while (cur != end) {
            ListNode tmp = cur.next;
            cur.next = pre;
            pre = cur;
            cur = tmp;
        }
        return pre;
    }
}
```

### 1.5. k 个一组反转链表（hot100, 1）

**题目 $25$​ k 个一组反转链表**：给你链表的头节点`head`，每`k`个节点一组进行翻转，请你返回修改后的链表。`k`是一个正整数，它的值小于或等于链表的长度。如果节点总数不是`k`的整数倍，那么请将最后剩余的节点保持原有顺序。你不能只是单纯的改变节点内部的值，而是需要实际进行节点交换。

```markdown
# 注意点：
- 与 92 反转链表Ⅱ 同样的思路，设置虚拟头节点。
```

```java
// 时间复杂度 O(n)；空间复杂度 O(1)
// n - 链表长度
class Solution {
    public ListNode reverseKGroup(ListNode head, int k) {
        ListNode dummyHead = new ListNode(0, head);
        // 计算链表长度
        ListNode tmp = head;
        int len = 0;
        while (tmp != null) {
            len++;
            tmp = tmp.next;
        }
        
        ListNode start = dummyHead;  // 始终指向翻转部分的前一个节点
        ListNode end = head;
        while (len >= k) {
            len -= k;
            // 每一次交换逻辑
            for (int i = 0; i < k; i++) end = end.next;  // 始终指向翻转部分的后一个节点
            ListNode newHead = reverseList(start.next, end);
            ListNode nextStart = start.next;  // 记录下一次翻转的前一个节点位置
            start.next.next = end;
            start.next = newHead;
            // 更新 start
            start = nextStart;
        }
        return dummyHead.next;
    }
    
    // 反转链表
    public ListNode reverseList(ListNode start, ListNode end) {
        ListNode pre = null;
        ListNode cur = start;
        while (cur != end) {
            ListNode tmp = cur.next;
            cur.next = pre;
            pre = cur;
            cur = tmp;
        }
        return pre;
    }
}
```

## 2. 环形链表系列

### 2.1. 环形链表（hot100, 2）

**题目 $141$ 环形链表**：给你一个链表的头节点`head`，判断链表中是否有环。如果链表中有某个节点，可以通过连续跟踪`next`指针再次到达，则链表中存在环。如果链表中存在环，则返回`true`；否则，返回`false`。

```java
// 时间复杂度 O(n)；空间复杂度 O(1)
// n - 链表长度
public class Solution {
    public boolean hasCycle(ListNode head) {
        /** 
        经典快慢指针法：快指针每次移动两步、慢指针每次移动一步
        如果链表有环，则快慢指针一定会在某一时刻指向同一节点
        */
        ListNode fast = head, slow = head;
        while (fast != null && fast.next != null) {
            fast = fast.next.next;
            slow = slow.next;
            if (fast == slow) return true;
        }
        return false;
    }
}
```

### 2.2. 环形链表Ⅱ（hot100, 2）

**题目 $142$ 环形链表Ⅱ**：给定一个链表的头节点 `head`，返回链表开始入环的第一个节点。如果链表无环，则返回`null`。

```java
// 时间复杂度 O(n)；空间复杂度 O(1)
// n - 链表长度
public class Solution {
    public ListNode detectCycle(ListNode head) {
        // 快慢指针法：注意移动长度的数学推导
        ListNode fast = head, slow = head, tmp = head;
        while (fast != null && fast.next != null) {
            fast = fast.next.next;
            slow = slow.next;
            if (fast == slow) {  // 确定快慢指针相遇位置
                while (tmp != slow) {
                    slow = slow.next;
                    tmp = tmp.next;
                }
                return slow;  // 确定环的入口
            }
        }
        return null;
    }
}
```

## 3. 合并链表系列

### 3.1. 合并两个有序链表（hot100, 1）

**题目 $21$ 合并两个有序链表**：将两个升序链表合并为一个新的升序链表并返回。新链表是通过拼接给定的两个链表的所有节点组成。 

```markdown
# 注意点：
- 虚拟头节点的使用。
```

```java
// 时间复杂度 O(n + m)；空间复杂度 O(1)
// n - list1.length; m - list2.length
class Solution {
    public ListNode mergeTwoLists(ListNode list1, ListNode list2) {
        // 设置虚拟头节点：方便操作
        ListNode dummy = new ListNode(-1);

        // 指针：指向完成合并排序操作的最后一个节点
        ListNode pre = dummy;
        while (list1 != null && list2 != null) {
            if (list1.val <= list2.val) {
                pre.next = list1;
                list1 = list1.next;
            } else {
                pre.next = list2;
                list2 = list2.next;
            }
            pre = pre.next;  // 移动 pre 指针
        }

        // 当有一个链表遍历完之后，将另一个链表的剩余节点直接合并
        if (list1 != null) pre.next = list1;
        else pre.next = list2;

        return dummy.next;  // 返回虚拟头节点的下一个节点
    }
}
```

### 3.2. 合并 k 个升序链表（hot100, 2）

**题目 $23$ 合并 k 个升序链表**：给你一个链表数组，每个链表都已经按升序排列。请你将所有链表合并到一个升序链表中，返回合并后的链表。

```markdown
# 注意点：
- 本题在上一题的基础上，要进行递归合并操作，以减少两两合并的次数。
```

```java
// 时间复杂度 O(nlogk)；空间复杂度 O(logk)
// n - 所有链表的节点个数；k - lists.length
class Solution {
    public ListNode mergeKLists(ListNode[] lists) {
        return traversal(lists, 0, lists.length - 1);
    }

    // 递归分左右区间进行合并
    public ListNode traversal(ListNode[] lists, int left, int right) {
        // 递归结束条件
        if (left > right) return null;
        if (left == right) return lists[left];
        // 单层递归逻辑
        int middle = (left + right) / 2;
        // 特别注意：mid 中点必须要包含在左区间，否则会无限递归
        return mergeList(traversal(lists, left, middle), traversal(lists, middle + 1, right));
    }

    // 21 合并两个有序链表
    public ListNode mergeList(ListNode head1, ListNode head2) {
        ListNode dummy = new ListNode();
        ListNode p = dummy;
        while (head1 != null && head2 != null) {
            if (head1.val >= head2.val) {
                p.next = head2;
                head2 = head2.next;
            } else {
                p.next = head1;
                head1 = head1.next;
            }
            p = p.next;
        }
        if (head1 == null) p.next = head2;
        if (head2 == null) p.next = head1;
        return dummy.next;
    }
}
```

### 3.3. 排序链表（hot100, 3）

**题目 $148$ 排序链表**：给你链表的头结点`head`，请将其按升序排列并返回排序后的链表。

```markdown
# 注意点：本题难度较大，需要熟悉“归并排序”、“链表中间节点”、“合并两个有序链表”等题目。
```

```java
// 时间复杂度 O(nlogn)；空间复杂度 O(logn)——递归栈
// n - 链表长度
class Solution {
    public ListNode sortList(ListNode head) {
        // 递归结束条件
        if (head == null || head.next == null) return head;

        // 寻找链表的左中间节点
        ListNode midNode = findMiddle(head);
        
        // 左 - 右递归
        ListNode rightNode = sortList(midNode.next);
        midNode.next = null;  // 断开左右链表
        ListNode leftNode = sortList(head);
        
        // 合并两个有序链表
        ListNode dummyHead = new ListNode();
        ListNode pre = dummyHead;
        while (leftNode != null && rightNode != null) {
            if (leftNode.val <= rightNode.val) {
                pre.next = leftNode;
                leftNode = leftNode.next;
            } else {
                pre.next = rightNode;
                rightNode = rightNode.next;
            }
            pre = pre.next;
        }
        if (leftNode != null) pre.next = leftNode;
        if (rightNode != null) pre.next = rightNode;
        
        return dummyHead.next;
    }

    // 寻找链表的中间节点（必须是“左中间节点”，否则会陷入死循环）
    public ListNode findMiddle(ListNode head) {
        ListNode slow = head, fast = head.next;
        while (fast != null && fast.next != null) {
            fast = fast.next.next;
            slow = slow.next;
        }
        return slow;
    }
}
```

### 4.2. 删除排序链表中的重复元素

**题目 $83$ 删除排序链表中的重复元素**：给定一个已排序的链表的头`head`，删除所有重复的元素，使每个元素只出现一次。返回已排序的链表。

```markdown
# 注意点：
- 明确快慢指针的含义。
```

```java
// 时间复杂度 O(n)；空间复杂度 O(1)
// n - 链表长度
class Solution {
    public ListNode deleteDuplicates(ListNode head) {
        if (head == null) {
            return null;
        }
        ListNode slow = head; // 慢指针，指向结果链表的尾部
        ListNode fast = head; // 快指针，用于遍历整个链表

        while (fast != null) { // 只要快指针没有走完链表
            // 核心逻辑：当快指针找到了一个和慢指针值不同的节点
            if (fast.val != slow.val) {
                // 1. 将慢指针的 next 指向这个新发现的不同节点
                slow.next = fast;
                // 2. 慢指针也前进一步，占据这个新位置，成为新的尾部
                slow = slow.next;
            }
            // 无论值是否相同，快指针都要继续前进，去寻找下一个节点
            fast = fast.next;
        }
        // 循环结束后的处理
        slow.next = fast; // fast 此时为 null
        return head;
    }
}
```

### 4.3. 删除排序链表中的重复元素Ⅱ（2）

**题目 $82$ 删除排序链表中的重复元素Ⅱ**：给定一个已排序的链表的头`head`，删除原始链表中所有重复数字的节点，只留下不同的数字。返回已排序的链表。

```markdown
# 注意点：
- 虚拟头节点的使用。
- 明确快慢指针的含义。
```

```java
// 时间复杂度 O(n)；空间复杂度 O(1)
// n - 链表长度
class Solution {
    public ListNode deleteDuplicates(ListNode head) {
        ListNode dummyHead = new ListNode();
        dummyHead.next = head;

        ListNode slow = dummyHead;  // 慢指针，指向结果链表的尾部
        ListNode fast = head;  // 快指针，遍历整个链表
        while (fast != null) {
            if (fast.next != null && fast.val == fast.next.val) {
                // 此时，fast 为第一个重复元素
                while (fast.next != null && fast.val == fast.next.val) {
                    fast = fast.next;
                }
                slow.next = fast.next;
                fast = fast.next;
            } else {
                // fast 不是重复序列，则添加到结果列表
                slow = slow.next;
                fast = fast.next;
            }
        }
        return dummyHead.next;
    }
}
```

**题目 $19$ 删除链表的倒数第 n 个节点**：给你一个链表，删除链表的倒数第`n`个结点，并且返回链表的头结点。

```markdown
# 注意点：
- 虚拟头节点使用。
- 明确快慢指针的含义。
```

```java
// 时间复杂度 O(n)；空间复杂度 O(1)
// n - 链表长度
class Solution {
    public ListNode removeNthFromEnd(ListNode head, int n) {
        // 快慢指针法
        // 设置虚拟头节点：由于存在删除头节点的情况
        ListNode dummy = new ListNode(0, head);
        ListNode slow = dummy, fast = dummy;
        // 快指针先移动 n + 1 步
        while (n >= 0) {
            fast = fast.next;
            n--;
        }
        while (fast != null) {
            fast = fast.next;
            slow = slow.next;
        }
        // 此时 slow 指针指向的一定是待删除节点的前一个节点
        slow.next = slow.next.next;
        return dummy.next;
    }
}
```

## 5. 相交链表（hot100, 2）

**题目 $160$ 相交链表**：给你两个单链表的头节点`headA`和`headB`，请你找出并返回两个单链表相交的起始节点。如果两个链表不存在相交节点，返回`null`。

```markdown
# 注意点：
- 双指针对齐。
```

```java
// 时间复杂度 O(n + m)；空间复杂度 O(1)
// n - headA 长度；m - headB 长度
public class Solution {
    public ListNode getIntersectionNode(ListNode headA, ListNode headB) {
        /** 本题的关键：
        两个指针分别遍历两个链表，如何让两个指针同时指向相交节点？
        */
        // 计算两个链表的长度
        int sizeA = 0, sizeB = 0;
        ListNode currentNodeA = headA, currentNodeB = headB;
        while (currentNodeA != null) {
            currentNodeA = currentNodeA.next;
            sizeA++;
        }
        while (currentNodeB != null) {
            currentNodeB = currentNodeB.next;
            sizeB++;
        }
        // 快慢指针：让较长的链表指针先走 |sizeA - sizeB| 步
        currentNodeA = headA;
        currentNodeB = headB;
        while (sizeA > sizeB) {
            currentNodeA = currentNodeA.next;
            sizeA--;
        }
        while (sizeA < sizeB) {
            currentNodeB = currentNodeB.next;
            sizeB--;
        }
        // 双指针同时向后移动
        while (currentNodeA != null) {
            if (currentNodeA == currentNodeB) return currentNodeA;
            currentNodeA = currentNodeA.next;
            currentNodeB = currentNodeB.next;
        }
        return null;
    }
}
```

## 6. 两数相加（hot100, 3）

**题目 $2$ 两数相加**：给你两个非空的链表，表示两个非负的整数。它们每位数字都是按照逆序的方式存储的，并且每个节点只能存储一位数字。请你将两个数相加，并以相同形式返回一个表示和的链表。你可以假设除了数字`0`之外，这两个数都不会以`0`开头。

```markdown
# 注意点：
- 虚拟头节点的使用。
- 在循环条件中考虑进位的特殊情况。
```

```java
// 时间复杂度 O(max(n, m))；空间复杂度 O(max(n, m))
// n - l1 长度；m - l2 长度
class Solution {
    public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
        ListNode dummy = new ListNode(0);
        ListNode pre = dummy;
        int tmp = 0;  // 保存进位制
        // 注意循环的结束条件：考虑进位的情况
        while (l1 != null || l2 != null || tmp != 0) {
            // 求和
            int val1 = (l1 == null) ? 0 : l1.val;
            int val2 = (l2 == null) ? 0 : l2.val;
            int sum = val1 + val2 + tmp;
            // 新节点
            ListNode newNode = new ListNode(sum % 10);
            // 新进位制
            tmp = sum / 10;
            // 移动指针
            pre.next = newNode;
            pre = pre.next;
            if (l1 != null) l1 = l1.next;
            if (l2 != null) l2 = l2.next;
        }
        return dummy.next;
    }
}
```

## 7. 两两交换链表中的节点（hot100）

**题目 $24$ 两两交换链表中的节点**：给你一个链表，两两交换其中相邻的节点，并返回交换后链表的头节点。你必须在不修改节点内部的值的情况下完成本题（即只能进行节点交换）。

```markdown
# 注意点：
- 虚拟头节点使用。
- 本题其实是 25 k 个一组反转链表的特例，但不推荐采用 25 题的方法来解决。
- 特别注意：本题用一个指针来解决较为清晰，尤其是循环结束条件的书写。
```

```java
class Solution {
    public ListNode swapPairs(ListNode head) {
        // 使用虚拟头节点
        ListNode dummy = new ListNode(0, head);
        ListNode cur = dummy;
        while (cur.next != null && cur.next.next != null) {
            ListNode tmp1 = cur.next;
            ListNode tmp2 = cur.next.next.next;
            cur.next = cur.next.next;
            cur.next.next = tmp1;
            cur.next.next.next = tmp2;
            // 注意指针的移动
            cur = cur.next.next;
        }
        return dummy.next;
    }
}
```

## 8. 随机链表的复制（hot100）

**题目 $138$​ 随机链表的复制**：给你一个长度为`n`的链表，每个节点包含一个额外增加的随机指针`random`，该指针可以指向链表中的任何节点或空节点。构造这个链表的深拷贝。深拷贝应该正好由`n`个全新节点组成，其中每个新节点的值都设为其对应的原节点的值。新节点的`next`指针和`random`指针也都应指向复制链表中的新节点，并使原链表和复制链表中的这些指针能够表示相同的链表状态。

```markdown
# 注意点：
- 哈希表的巧妙使用。
```

```java
class Solution {
    public Node copyRandomList(Node head) {
        // 采用哈希表记录 新-老 节点的映射关系
        Map<Node, Node> hm = new HashMap<>();
        Node pre = head;
        while (pre != null) {
            hm.put(pre, new Node(pre.val));
            pre = pre.next;
        }
        // 遍历哈希表，复制节点的指向
        Set<Node> kset = hm.keySet();  // hm.keySet() | hm.values()
        for (Node node : kset) {
            hm.get(node).next = hm.get(node.next);
            hm.get(node).random = hm.get(node.random);
        }
        return hm.get(head);
    }
}
```

## 9. LRU 缓存（hot100, 1）

**题目 $146$ LRU 缓存**：请你设计并实现一个满足 LRU（最近最少使用）缓存约束的数据结构。实现`LRUCache`类：

- `LRUCache(int capacity)`以正整数作为容量`capacity`初始化 LRU 缓存。
- `int get(int key)`如果关键字`key`存在于缓存中，则返回关键字的值，否则返回`-1`。
- `void put(int key, int value)`如果关键字`key`已经存在，则变更其数据值`value`；如果不存在，则向缓存中插入该组`key-value`。如果插入操作导致关键字数量超过`capacity`，则应该逐出最久未使用的关键字。

函数`get`和`put`必须以`O(1)`的平均时间复杂度运行。

```markdown
# 本题关键在于 O(1) 时间复杂度完成查询和插入、删除、移动等操作，考虑数据结构：
- 哈希表：O(1) 的时间复杂度完成查找。很自然能想到采用 Map 结构存储节点的 key 和对应的指针。
- 双向链表（为什么不采用单向链表）：在插入、删除、移动等操作中，需要获取目标节点的前一个节点，这在单向链表中是无法在 O(1) 时间复杂度内完成的。
```

```java
class LRUCache {

    int capacity;  // 容量
    int size;  // 当前元素个数
    Map<Integer, Node> hm = new HashMap<>();  // 哈希表
    Node dummyHead, dummyTail;  // 虚拟头、尾节点（需定义为成员变量，否则无法访问）

    public class Node {
        private int key;
        private int val;
        private Node next;
        private Node prev;
        public Node() {}
        public Node(int key, int val) {
            this.key = key;
            this.val = val;
        }
    }

    public LRUCache(int capacity) {
        // 容量初始化
        this.capacity = capacity;
        // 双向链表初始化
        dummyHead = new Node();
        dummyTail = new Node();
        dummyHead.next = dummyTail;
        dummyTail.prev = dummyHead;
    }
    
    public int get(int key) {
        if (!hm.containsKey(key)) return -1;
        Node getNode = hm.get(key);
        remove(getNode);
        addTail(getNode);
        return getNode.val;
    }
    
    public void put(int key, int value) {
        if (hm.containsKey(key)) {
            Node getNode = hm.get(key);
            getNode.val = value;
            remove(getNode);
            addTail(getNode);
        } else {
            Node newNode = new Node(key, value);
            hm.put(key, newNode);
            addTail(newNode);
            size++;
            if (size > capacity) {
                Node removeNode = dummyHead.next;  // 注意：用一个指针保存待删除的节点
                remove(removeNode);
                hm.remove(removeNode.key);
                size--;
            }
        }
    }

    // 在双向链表中删除节点
    public void remove(Node node) {
        node.prev.next = node.next;
        node.next.prev = node.prev;
    }

    // 在链表尾部插入元素
    public void addTail(Node node) {
        dummyTail.prev.next = node;
        node.prev = dummyTail.prev;
        dummyTail.prev = node;
        node.next = dummyTail;
    }
}
```

## 1. 链表的中间节点

**题目 $876$**：给你单链表的头结点`head`，请你找出并返回链表的中间结点。如果有两个中间结点，则返回第二个中间结点。

```java
class Solution {
    public ListNode middleNode(ListNode head) {
        ListNode fast = head, slow = head;
        // 注意循环结束条件，防止出现空指针异常
        while (fast != null && fast.next != null) {
            fast = fast.next.next;  // 快指针每次走两步
            slow = slow.next;  // 慢指针每次走一步
        }
        return slow;
    }
}
```
