# 图论

## 1. 基础

### 1.1. 图的分类

按边的方向性分类：

- **无向图（Undirected Graph）**：边没有方向，顶点间关系是双向的。

  特性：节点度为连接边的总数。

- **有向图（Directed Graph，Digraph）**：边带有方向，用箭头表示单向关系。

  特性：每个顶点有入度（指向自己的边数）和出度（指向外部的边数），入度之和等于出度之和。

按边的权重分类：

- **无权图（Unweighted Graph）**：边仅表示连接关系，无附加数值。
- **加权图（Weighted Graph）**：边带有权重（如距离、成本），常用于量化关系。

### 1.2. 连通性

**连通图（Connected Graph）**：在无向图中，若任意两个顶点之间都存在一条路径（直接或间接相连），该图称为连通图。

**连通分量（Connected Component）**：在无向图中，**极大连通子图**称为连通分量。即子图满足：

- 子图内部连通。
- 无法通过添加更多顶点或边保持连通性。

**强连通图（Strongly Connected Graph）**：在有向图中，若任意两个顶点之间均存在**双向路径**，该图称为强连通图。

**强连通分量（Strongly Connected Component, SCC）**：在有向图中，**极大强连通子图**称为强连通分量。即子图满足：

- 子图内部强连通。
- 无法通过添加更多顶点或边保持强连通性。

### 1.3. 图的构造

#### 1.3.1. 邻接矩阵

**邻接矩阵**是一个二维数组（矩阵），用于表示图中顶点之间的连接关系。矩阵的行和列对应图的顶点，元素值表示顶点间的边是否存在，或权重。

- 无权图：`matrix[i][j] = 0` 表示节点`i, j`之间没有边相连；`matrix[i][j] = 1`表示节点`i, j`之间有边相连。
- 加权图：`matrix[i][j] = w`表示节点`i`到节点`j`的边权重为`w`；`matrix[i][j] = null`表示节点`i`到节点`j`的边不存在。

> 邻接矩阵适合存储稠密图，查询速度快；但对于节点数量较多的稀疏图，邻接矩阵会浪费大量的存储空间。

#### 1.3.2. 邻接表

**邻接表**通过**数组和链表**为每个顶点维护其直接邻居列表，仅存储实际存在的边。

>邻接表适合存储稀疏图，只需要存储边，空间利用率高。

## 2. 图的遍历

### 2.1. 深度优先搜索

**深度优先搜索（DFS）**：从起点开始，尽可能深地访问图的节点，直到无法继续深入，然后回溯并探索其他分支。

#### 2.1.1. 所有可达路径

题目来源**卡码网（leetcode $797$ 所有可能的路径）**：给定一个有`n`个节点的有向无环图，节点编号从`1`到`n`。请编写一个函数，找出并返回所有从节点`1`到节点`n`的路径。每条路径应以节点编号的列表形式表示。

输入描述：第一行包含两个整数`N, M`，表示图中拥有`N`个节点，`M`条边。后续`M`行，每行包含两个整数`s, t`，表示图中的`s`节点与`t`节点中有一条路径。

输出描述：输出所有的可达路径，路径中所有节点之间空格隔开，每条路径独占一行，存在多条路径，路径输出的顺序可任意。如果不存在任何一条路径，则输出`-1`。注意输出的序列中，最后一个节点后面没有空格。

```java
// ACM 模式：邻接矩阵实现
import java.util.List;
import java.util.Scanner;
import java.util.ArrayList;

public class Main {
    static List<List<Integer>> res = new ArrayList<>();
    public static void main(String[] args) {
        Scanner myScanner = new Scanner(System.in);
        int n = myScanner.nextInt();  // 节点数量
        int e = myScanner.nextInt();  // 边数量

        // 邻接矩阵（节点编号从 1 开始）
        int[][] graph = new int[n + 1][n + 1];
        for (int i = 0; i < e; i++) {
            int node1 = myScanner.nextInt();
            int node2 = myScanner.nextInt();
            graph[node1][node2] = 1;
        }
        // 初始化路径
        List<Integer> list = new ArrayList<>();
        list.add(1);
        // 求解
        dfs(graph, n, 1, list);
        // 输出
        if (res.isEmpty()) System.out.println(-1);
        for (int i = 0; i < res.size(); i++) {
            List<Integer> tmp = res.get(i);
            StringBuilder sb = new StringBuilder();
            for (int j = 0; j < tmp.size(); j++) {
                sb.append(tmp.get(j));
                if (j != tmp.size() - 1) sb.append(' ');
            }
            System.out.println(sb);
        }
    }

    public static void dfs(int[][] graph, int n, int cur, List<Integer> list) {
        // 递归结束条件
        if (cur == n) {
            res.add(new ArrayList<>(list));
            return;
        }

        for (int j = 0; j <= n; j++) {
            if (graph[cur][j] == 0) continue;
            // 递归
            list.add(j);
            dfs(graph, n, j, list);
            // 回溯
            list.remove(list.size() - 1);
        }
    }
}
```

```java
class Solution {
    private int[][] dirs = new int[][]{{1, 0}, {-1, 0}, {0, 1}, {0, -1}};
    public int numIslands(char[][] grid) {
        int res = 0;
        for (int i = 0; i < grid.length; i++) {
            for (int j = 0; j < grid[0].length; j++) {
                if (grid[i][j] == '1') {
                    dfs(grid, i, j);
                    res++;
                }
            }
        }
        return res;
    }

    public void dfs(char[][] grid, int i, int j) {
        for (int[] dir : dirs) {
            int newI = i + dir[0];
            int newJ = j + dir[1];
            if (newI < 0 || newI >= grid.length || newJ < 0 || newJ >= grid[0].length) continue;
            if (grid[newI][newJ] == '0') continue;
            grid[newI][newJ] = '0';
            dfs(grid, newI, newJ);
            // 注意：这里不能够添加回溯
        }
    }
}
```
