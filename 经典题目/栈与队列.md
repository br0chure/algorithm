# 栈与队列

## 1. 数据结构基础

Java 中，栈有两种实现方式：

- `Stack`类：该类为`List`接口实现类`Vector`的子类。由于该类底层采用向量实现，在单线程环境下效率不高，因此不推荐使用。
- `Deque`接口实现类：该接口为**双端队列**接口，是`Queue`接口的子接口，其实现类既可以作为栈，也可以作为队列来使用。
  - `ArrayDeque`类：基于动态数组存储，内存连续，无额外指针开销。
  - `LinkedList`类：基于双向链表存储，每个元素有前驱和后驱指针，内存占用更高。

> 在使用**栈、普通队列、双端队列**时，`ArrayDeque`在性能、内存占用和缓存效率上全面优于`LinkedList`，推荐使用。
>
> `ArrayDeque`作为**栈**数据结构的常用 API 如下：
>
> | 操作             | 复杂度 | 解释                                             |
> | ---------------- | ------ | ------------------------------------------------ |
> | `E peek()`       | $O(1)$ | 查看栈顶元素，但不移除。如果栈为空，则返回`null` |
> | `E pop()`        | $O(1)$ | 移除并返回栈顶元素。如果栈为空，则**抛出异常**   |
> | `void push(E e)` | $O(1)$ | 将元素压入栈顶。默认自动扩容                     |
>
> `ArrayDeque`作为**普通队列**数据结构的常用 API 如下：
>
> | 操作                 | 复杂度 | 解释                                               |
> | -------------------- | ------ | -------------------------------------------------- |
> | `E peek()`           | $O(1)$ | 返回队列头部元素，不移除。如果队列为空，返回`null` |
> | `E poll()`           | $O(1)$ | 移除并返回队列头部元素。如果队列为空，返回`null`   |
> | `boolean offer(E e)` | $O(1)$ | 将元素添加到队列尾部。默认自动扩容，返回`true`     |
>
> `ArrayDeque`作为**双端队列**数据结构的常用 API 如下：
>
> | 操作                      | 复杂度 | 解释                                               |
> | ------------------------- | ------ | -------------------------------------------------- |
> | `E peekFirst()`           | $O(1)$ | 查询队列头部元素。如果队列为空，则返回`null`       |
> | `E peekLast()`            | $O(1)$ | 查询队列尾部元素。如果队列为空，则返回`null`       |
> | `E pollFirst()`           | $O(1)$ | 移除并返回队列头部元素。如果队列为空，则返回`null` |
> | `E pollLast()`            | $O(1)$ | 移除并返回队列尾部元素。如果队列为空，则返回`null` |
> | `boolean offerFirst(E e)` | $O(1)$ | 插入元素到队列头部。默认自动扩容，返回`true`       |
> | `boolean offerLast(E e)`  | $O(1)$ | 插入元素到队列尾部。默认自动扩容，返回`true`       |

Java 中，队列通常有两种使用场景：

- 普通队列：优先使用`ArrayDeque`类；备选使用`LinkedList`类。
- 优先级队列：使用`PriorityQueue`类（`Queue`接口的实现类），基于**小顶堆**实现，即值最小的元素优先被弹出。

> **堆（Heap）**：是一种**完全二叉树**结构，即除最后一层外，其他层节点全满，且最后一层节点左对齐。具体可以分为大顶堆和小顶堆：
>
> - 大顶堆——单调递减队列：父节点的值 $\geq$ 子节点的值。
> - 小顶堆——单调递增队列：父节点的值 $\leq$ 子节点的值。
>
> 堆的常见操作与时间复杂度（以 Java 中的`PriorityQueue`类的 API 进行介绍）如下：
>
> | 操作                 | 复杂度       | 解释                                                     |
> | -------------------- | ------------ | -------------------------------------------------------- |
> | `E peek()`           | $O(1)$       | 查询队列头部元素（即查询堆顶元素）。队列为空，返回`null` |
> | `E poll()`           | $O(\log{n})$ | 移除并返回队列头部元素。队列为空，返回`null`             |
> | `boolean offer(E e)` | $O(\log{n})$ | 插入元素到队列尾部。自动扩容，返回`true`                 |

### 1.1. 用栈实现队列（3）

**题目 $232$ 用栈实现队列**：请你仅使用两个栈实现先入先出队列。队列应当支持一般队列支持的所有操作`push, pop, peek, empty`。

```markdown
# 注意点：
- 两个栈：一个负责入元素，一个负责出元素。
- 复用 pop() 方法。
```

```java
class MyQueue {
    Deque<Integer> instack, outstack;
    public MyQueue() {
        this.instack = new ArrayDeque<>();
        this.outstack = new ArrayDeque<>();
    }
    
    public void push(int x) {
        instack.push(x);
    }
    
    public int pop() {
        if (!outstack.isEmpty()) return outstack.pop();
        // 出栈为空，则从入栈中取数据
        while (!instack.isEmpty()) {
            outstack.push(instack.pop());
        }
        return outstack.pop();
    }
    
    public int peek() {
        // 复用 pop() 方法：先弹出元素，然后再将元素压入出栈
        int target = this.pop();
        outstack.push(target);
        return target;
    }
    
    public boolean empty() {
        return instack.isEmpty() && outstack.isEmpty();
    }
}
```

### 1.2. 用队列实现栈

**题目 $225$ 用队列实现栈**：请你仅使用一个队列实现一个后入先出的栈，并支持普通栈的全部四种操作`push, top, pop, empty`。

```markdown
# 注意点：
- 复用 pop() 方法
```

```java
class MyStack {
    Deque<Integer> queue;
    public MyStack() {
        this.queue = new ArrayDeque<>();
    }
    
    public void push(int x) {
        queue.offer(x);
    }
    
    public int pop() {
        // 记录当前队列大小
        int size = queue.size();
        while (size > 1) {
            queue.offer(queue.poll());
            size--;
        }
        return queue.poll();
    }
    
    public int top() {
        // 复用 pop() 方法：先弹出元素，再将元素添加到队列尾部
        int target = this.pop();
        queue.offer(target);
        return target;
    }
    
    public boolean empty() {
        return queue.isEmpty();
    }
}
```

#### 2.1.1. 有效的括号（hot100, 1）

**题目 $20$ 有效的括号**：给定一个只包括`'(', ')', '{', '}', '[', ']'`的字符串`s`，判断字符串是否有效。

```java
// 时间复杂度 O(n)；空间复杂度 O(n)
// n - 字符串长度
class Solution {
    public boolean isValid(String s) {
        Deque<Character> stack = new ArrayDeque<>();
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (c == '(') stack.push(')');
            else if (c == '[') stack.push(']');
            else if (c == '{') stack.push('}');
            else {
                // 情况一：如果右括号多了，返回 false
                if (stack.isEmpty()) return false;
                char tmp = stack.pop();
                // 情况二：如果左右括号不匹配，返回 false
                if (tmp != c) return false;
            }
        }
        // 情况三：判断是否有多余的左括号
        return stack.isEmpty();
    }
}
```

#### 2.1.2. 删除字符串中的所有相邻重复项

**题目 $1047$ 删除字符串中的所有相邻重复项**：给出由小写字母组成的字符串`s`，重复项删除操作会选择两个相邻且相同的字母，并删除它们。在`s`上反复执行重复项删除操作，直到无法继续删除。在完成所有重复项删除操作后返回最终的字符串。

```java
class Solution {
    public String removeDuplicates(String s) {
        Deque<Character> stack = new ArrayDeque<>();
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (stack.isEmpty() || c != stack.peek()) {
                stack.push(c);
            } else stack.pop();
        }
        // 取出栈中剩余的元素
        StringBuilder sb = new StringBuilder();  // 高效拼接
        while (!stack.isEmpty()) {
            sb.append(stack.pop());
        }
        return sb.reverse().toString();
    }
}
```

#### 2.1.3. 逆波兰表达式求值

**题目 $150$ 逆波兰表达式求值**：给你一个字符串数组`tokens`，表示一个根据逆波兰表示法表示的算术表达式。请你计算该表达式。返回一个表示表达式值的整数。逆波兰表达式是一种后缀表达式，即运算符写在后面。

```java
class Solution {
    public int evalRPN(String[] tokens) {
        Deque<Integer> stack = new ArrayDeque<>();
        for (String s : tokens) {
            if (s.equals("+")) {
                int n1 = stack.pop();
                int n2 = stack.pop();
                stack.push(n2 + n1);
            } else if (s.equals("-")) {
                int n1 = stack.pop();
                int n2 = stack.pop();
                stack.push(n2 - n1);
            } else if (s.equals("*")) {
                int n1 = stack.pop();
                int n2 = stack.pop();
                stack.push(n2 * n1);
            } else if (s.equals("/")) {
                int n1 = stack.pop();
                int n2 = stack.pop();
                stack.push(n2 / n1);
            } else {
                stack.push(Integer.parseInt(s));
            }
        }
        return stack.pop();
    }
}
```

#### 2.1.4. 字符串解码（hot100）

**题目 $394$ 字符串解码**：给定一个编码的字符串，返回它解码后的字符串。编码规则为`k[encoded_string]`，表示其中方括号内部的`encoded_string`正好重复`k`次。注意`k`保证为正整数。你可以认为输入字符串总是有效的；输入字符串中没有额外的空格，且输入的方括号总是符合格式要求的。此外，你可以认为原始数据不包含数字，所有的数字只表示重复的次数`k`，例如不会出现像`3a`或`2[4]`的输入。

```markdown
# 注意点：
- 本题不难，但是要注意的细节很多，需要很熟练。
```

```java
// 时间复杂度 O(M)；空间复杂度 O(M)
// M - 最终结果字符串的长度
class Solution {
    public String decodeString(String s) {
        Deque<Character> stack = new ArrayDeque<>();
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            // 除了 ']' 均压入栈
            if (c != ']') stack.push(c);
            else {
                // 1. 获取字符
                StringBuilder sb = new StringBuilder();
                while (stack.peek() != '[') {
                    sb.append(stack.pop());
                }
                sb.reverse();  // 反转
                stack.pop();  // 去除 '['

                // 2. 获取数字（注意非空判断）
                StringBuilder numStr = new StringBuilder();
                while (!stack.isEmpty() && Character.isDigit(stack.peek())) {
                    numStr.append(stack.pop());
                }
                int num = Integer.parseInt(numStr.reverse().toString());

                // 3. 根据倍数，将字符重新压入栈
                for (int j = 0; j < num; j++) {
                    for (int k = 0; k < sb.length(); k++) {
                        stack.push(sb.charAt(k));
                    }
                }
            }
        }

        // 取出栈中所有元素
        StringBuilder res = new StringBuilder();
        while (!stack.isEmpty()) {
            res.append(stack.pop());
        }
        return res.reverse().toString();
    }
}
```

#### 2.1.5. 最长有效括号（hot100, 3）

**题目 $32$ 最长有效括号**：给你一个只包含`(`和`)`的字符串，找出最长有效（格式正确且连续）括号子串的长度。

```markdown
# 注意点：本题较难，简化思路很重要
- 栈：存储 '(' 的下标，用于匹配括号。
- 数组：记录匹配成功的位置。
```

```java
// 时间复杂度 O(n)；空间复杂度 O(n)
// n - 字符串长度
class Solution {
    public int longestValidParentheses(String s) {
        // 栈：存储 '(' 的下标，用于匹配括号
        // 数组：用于记录匹配成功的位置
        Deque<Integer> stack = new ArrayDeque<>();
        int[] res = new int[s.length()];

        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (c == '(') stack.push(i);
            else {
                if (!stack.isEmpty()) {
                    int tmpIdx = stack.pop();
                    // 匹配成功赋值为 1
                    res[tmpIdx] = 1;
                    res[i] = 1;
                }
            }
        }

        // 判断数组中连续 1 的最大长度
        int maxLen = 0;
        int tmp = 0;
        for (int i = 0; i < res.length; i++) {
            if (res[i] == 1) {
                tmp++;
                maxLen = Math.max(maxLen, tmp);
            }
            else tmp = 0;
        }
        return maxLen;
    }
}
```

### 2.2. 单调栈

> 单调栈（Monotonic Stack）是一种特殊的栈结构，其元素按照单调递增或递减的顺序排列。它常用于解决**寻找下一个更大/更小元素**、**区间极值**或**特定几何问题**，能将时间复杂度优化到 $O(n)$。
>
> - 单调递增（严格来说是“非递减”）栈（从栈顶到栈底）：用于寻找下一个更大元素；前一个更大元素。
> - 单调递减（严格来说是“非递增”）栈（从栈顶到栈底）：用于寻找下一个更小元素；前一个更小元素。

#### 2.2.1. 每日温度（hot100）

**题目 $739$ 每日温度**：给定一个整数数组`temperatures`，表示每天的温度，返回一个数组`answer`，其中`answer[i]`是指对于第`i`天，下一个更高温度出现在几天后。如果气温在这之后都不会升高，请用`0`来代替。

```markdown
# 注意点：
- 非严格单调递增栈。
- 由于最后求“几天后”，因此栈中存放的是元素的下标。
```

```java
// 时间复杂度 O(n)；空间复杂度 O(n)
// n - 数组长度
class Solution {
    public int[] dailyTemperatures(int[] temperatures) {
        // 单调栈：非严格递增；栈中存放下标
        // 存放的元素为：已经遍历过，但还没有找到大于它的第一个元素
        Deque<Integer> stack = new ArrayDeque<>();
        int[] res = new int[temperatures.length];

        // 逻辑：比较当前元素和栈顶元素的大小
        for (int i = 0; i < temperatures.length; i++) {
            if (stack.isEmpty() || temperatures[i] <= temperatures[stack.peek()]) {
                stack.push(i);
                continue;
            }
            while (!stack.isEmpty() && temperatures[i] > temperatures[stack.peek()]) {
                int tmpIdx = stack.pop();
                res[tmpIdx] = i - tmpIdx;
            }
            stack.push(i);
        }
        return res;
    }
}
```

#### 2.2.2. 下一个更大元素Ⅰ

**题目 $496$ 下一个更大元素Ⅰ**：`nums1`中数字`x`的下一个更大元素是指`x`在`nums2`中对应位置右侧的第一个比`x`大的元素。给你两个没有重复元素的数组`nums1`和`nums2`，其中`nums1`是`nums2`的子集。对于每个`0 <= i < nums1.length`，找出满足`nums1[i] == nums2[j]`的下标`j`，并且在`nums2`确定`nums2[j]`的下一个更大元素。如果不存在下一个更大元素，那么本次查询的答案是`-1`。返回一个长度为`nums1.length`的数组`ans`作为答案，满足`ans[i]`是如上所述的下一个更大元素。

```markdown
# 注意点：
- 非严格单调递增栈。
- 由于哈希表中 key 为元素值，因此栈中存放的是元素值。
```

```java
class Solution {
    public int[] nextGreaterElement(int[] nums1, int[] nums2) {
        // <nums2[i], 第一个大于 nums2[i] 的数>
        Map<Integer, Integer> hash = new HashMap<>();
        // 单调递增栈
        Deque<Integer> stack = new ArrayDeque<>();

        for (int i = 0; i < nums2.length; i++) {
            if (stack.isEmpty() || nums2[i] <= stack.peek()) {
                stack.push(nums2[i]);
                continue;
            }
            while (!stack.isEmpty() && nums2[i] > stack.peek()) {
                int tmp = stack.pop();
                hash.put(tmp, nums2[i]);
            }
            stack.push(nums2[i]);
        }

        int[] res = new int[nums1.length];
        for (int i = 0; i < nums1.length; i++) {
            if (hash.containsKey(nums1[i])) {
                res[i] = hash.get(nums1[i]);
            } else {
                res[i] = -1;
            }
        }
        return res;
    }
}
```

#### 2.2.3. 下一个更大元素Ⅱ

**题目 $503$ 下一个更大元素Ⅱ**：给定一个循环数组`nums`，即`nums[nums.length - 1]`的下一个元素是`nums[0]`，返回`nums`中每个元素的下一个更大元素。数字`x`的下一个更大的元素是按数组遍历顺序，这个数字之后的第一个比它更大的数，这意味着你应该循环地搜索它的下一个更大的数。如果不存在，则输出`-1`。

```markdown
# 注意点：
- 非严格单调递增栈；存放元素下标。
- 处理循环数组：虚拟扩容 + 取模。
```

```java
class Solution {
    public int[] nextGreaterElements(int[] nums) {
        // 单调栈：非严格递增；存放元素下标
        // 存放的元素（下标）为：已经遍历，但还没有找到大于它的第一个元素
        Deque<Integer> stack = new ArrayDeque<>();
        int[] res = new int[nums.length];
        Arrays.fill(res, -1);

        // 循环数组的解决方式：虚拟扩容 + 取模
        for (int i = 0; i < nums.length * 2; i++) {
            int mod = i % nums.length;
            if (stack.isEmpty() || nums[mod] <= nums[stack.peek()]) {
                stack.push(mod);
                continue;
            }
            while (!stack.isEmpty() && nums[mod] > nums[stack.peek()]) {
                int tmpIdx = stack.pop();
                res[tmpIdx] = nums[mod];
            }
            stack.push(mod);
        }
        return res;
    }
}
```

#### 2.2.4. 接雨水（hot100, 2）

**题目 $42$ 接雨水**：给定`n`个非负整数表示每个宽度为`1`的柱子的高度图，计算按此排列的柱子，下雨之后能接多少雨水。

```markdown
# 注意点：
- 非严格单调递增栈；栈中存放元素下标。
- “横向”求接雨水面积。
- 三个元素构成了接雨水的容器：
	- 底：栈顶元素。
	- 右侧柱子：当前元素（> 栈顶元素）。
	- 左侧柱子：栈顶的下一个元素（>= 栈顶元素）。
```

```java
// 时间复杂度 O(n)；空间复杂度 O(n)
// n - 数组长度
class Solution {
    public int trap(int[] height) {
        // 单调栈：非严格递增。存放下标
        // 存放的元素（下标）是：已经遍历过，但还没有找到下一个更大元素
        Deque<Integer> stack = new ArrayDeque<>();
        int count = 0;

        for (int i = 0; i < height.length; i++) {
            if (stack.isEmpty() || height[i] <= height[stack.peek()]) {
                stack.push(i);
                continue;
            }
            while (!stack.isEmpty() && height[i] > height[stack.peek()]) {
                int bottomIdx = stack.pop();
                if (!stack.isEmpty()) {  // 存在左侧柱子
                    int leftIdx = stack.peek();
                    // 高度
                    int h = Math.min(height[i], height[leftIdx]) - height[bottomIdx];
                    // 宽度
                    int w = i - leftIdx - 1;
                    count += h * w;
                }
            }
            stack.push(i);
        }
        return count;
    }
}
```

#### 2.2.5. 柱状图中最大的矩形（hot100）

**题目 $84$​ 柱状图中最大的矩形**：给定`n`个非负整数，用来表示柱状图中各个柱子的高度。每个柱子彼此相邻，且宽度为`1`。求在该柱状图中，能够勾勒出来的矩形的最大面积。

```markdown
# 注意点：
- 非严格单调递减栈；存放元素的下标。
- “横向”求最大矩形。
```

```java
// 时间复杂度 O(n)；空间复杂度 O(n)
// n - 数组长度
class Solution {
    public int largestRectangleArea(int[] heights) {
        // 单调栈：非严格递减；存放元素下标
        // 存放的元素（下标）：遍历过，但还没有找到下一个小于其的元素
        Deque<Integer> stack = new ArrayDeque<>();
        int maxArea = 0;

        // 在原数组头部和尾部分别添加 0，以防止无法找到更小元素的特殊情况
        int[] newHeights = new int[heights.length + 2];
        for (int i = 1; i <= heights.length; i++) {
            newHeights[i] = heights[i - 1];
        }
        heights = newHeights;

        for (int i = 0; i < heights.length; i++) {
            if (stack.isEmpty() || heights[i] >= heights[stack.peek()]) {
                stack.push(i);
                continue;
            }
            while (!stack.isEmpty() && heights[i] < heights[stack.peek()]) {
                int baseIdx = stack.pop();
                // 当前元素存在左侧小于其的元素
                if (!stack.isEmpty()) {
                    int leftIdx = stack.peek();
                    maxArea = Math.max(maxArea, (i - leftIdx - 1) * heights[baseIdx]);
                }
            }
            stack.push(i);
        }
        return maxArea;
    }
}
```

#### 2.3.1. 最小栈（hot100）

**题目 $155$ 最小栈**：设计一个支持`push, pop, top`操作，并能在常数时间内检索到最小元素的栈。

```markdown
# 注意点：
- 由于栈先进后出的性质，栈中的每一个元素代表其包括其以下所有元素的最新状态。
- 辅助栈：存放最小值。
```

```java
class MinStack {

    Deque<Integer> stack;
    Deque<Integer> minStack;

    public MinStack() {
        this.stack = new ArrayDeque<>();
        this.minStack = new ArrayDeque<>();
    }
    
    public void push(int val) {
        stack.push(val);
        // 当前值 val 为最小值：如果 minStack 为空，或当前最小值大于 val
        if (minStack.isEmpty() || minStack.peek() > val) {
            minStack.push(val);
        } else {
            minStack.push(minStack.peek());
        }
    }
    
    public void pop() {
        stack.pop();
        minStack.pop();
    }
    
    public int top() {
        return stack.peek();
    }
    
    public int getMin() {
        return minStack.peek();
    }
}
```

## 3. 队列

普通队列的应用场景主要在树、图中的**广度优先遍历（BFS）**，这里不做过多的介绍。

### 3.1. 单调队列

> 单调队列是一种特殊的**双端队列**，它维护队列元素的**单调性**，以便快速查询区间最值，常用于**滑动窗口最值问题**。
>
> 以单调递减队列（维护滑动窗口最大值）为例，其操作的主要性质如下：
>
> - 入队操作：元素在队列尾部入队。入队时，将队列尾部**小于**入队元素的所有元素从**尾部移除**。
> - 出队操作：元素从队列头部移出。出队时，判断出队元素是否是当前维护的最大值：如果是，则移除；如果不是，则不进行任何操作。
> - 获取最值操作：获取队列头部元素。

由于 Java 没有内置的单调队列实现类，因此，在使用到单调队列时需要自己实现。示例代码如下：

```java
// 单调队列：非严格单调递减
class MaxDeque {

    Deque<Integer> deque;

    public MaxDeque() {
        this.deque = new ArrayDeque<>();
    }

    // 入队操作
    public void offer(int val) {
        // 注意：条件是 >，而不是 >=
        while (!deque.isEmpty() && val > deque.peekLast()) {
            deque.pollLast();
        }
        deque.offerLast(val);
    }

    // 出队操作
    public void poll(int val) {
        if (!deque.isEmpty() && val == deque.peekFirst()) {
            deque.pollFirst();
        }
    }

    // 获取最值
    public int getMax() {
        return deque.peekFirst();
    }
}

// 单调队列：非严格单调递增
class MinDeque {

    Deque<Integer> deque;

    public MinDeque() {
        this.deque = new ArrayDeque<>();
    }

    // 入队操作
    public void offer(int val) {
        while (!deque.isEmpty() && val < deque.peekLast()) {
            deque.pollLast();
        }
        deque.offerLast(val);
    }

    // 出队操作
    public void poll(int val) {
        if (!deque.isEmpty() && val == deque.peekFirst()) {
            deque.pollFirst();
        }
    }

    // 获取最值
    public int getMin() {
        return deque.peekFirst();
    }
}
```

#### 3.1.1. 滑动窗口最大值（hot100, 3）

**题目 $239$ 滑动窗口最大值**：给你一个整数数组`nums`，有一个大小为`k`的滑动窗口从数组的最左侧移动到数组的最右侧。你只可以看到在滑动窗口内的`k`个数字。滑动窗口每次只向右移动一位。返回滑动窗口中的最大值。

```markdown
# 注意点：
- 单调递减队列，维护滑动窗口最大值。
```

```java
// 时间复杂度 O(n)；空间复杂度 O(n)
// n - 数组长度
// 主函数
class Solution {
    public int[] maxSlidingWindow(int[] nums, int k) {
        MaxDeque maxDeque = new MaxDeque();
        int[] res = new int[nums.length - k + 1];
        // 先将前 k 个元素入队
        for (int i = 0; i < k; i++) {
            maxDeque.offer(nums[i]);
        }
        res[0] = maxDeque.getMax();
        // 再遍历剩余的元素
        for (int i = k; i < nums.length; i++) {
            // 移除 & 添加元素（顺序可以调换）
            maxDeque.poll(nums[i - k]);
            maxDeque.offer(nums[i]);
            // 收集结果
            res[i - k + 1] = maxDeque.getMax();
        }
        return res;
    }
}
```

#### 3.1.2. 绝对差不超过限制的最长连续子数组

**题目 $1438$ 绝对差不超过限制的最长连续子数组**：给你一个整数数组`nums`，和一个表示限制的整数`limit`，请你返回最长连续子数组的长度，该子数组中的任意两个元素之间的绝对差必须小于或者等于`limit`。如果不存在满足条件的子数组，则返回`0`。

```markdown
# 注意点：
- 使用两个单调队列，分别维护滑动窗口内的最大值和最小值。
```

```java
// 主函数
class Solution {
    public int longestSubarray(int[] nums, int limit) {
        MaxDeque maxDeque = new MaxDeque();
        MinDeque minDeque = new MinDeque();
        int maxLen = 0;
        int left = 0;  // 滑动窗口左边界
        for (int right = 0; right < nums.length; right++) {
            maxDeque.offer(nums[right]);
            minDeque.offer(nums[right]);
            // 不满足条件，则左边界移动
            while (maxDeque.getMax() - minDeque.getMin() > limit) {
                maxDeque.poll(nums[left]);
                minDeque.poll(nums[left]);
                left++;
            }
            maxLen = Math.max(maxLen, right - left + 1);
        }
        return maxLen;
    }
}
```

### 3.2. 优先级队列

#### 3.2.1. 最后一块石头的重量

**题目 $1064$ 最后一块石头的重量**：有一堆石头，每块石头的重量都是正整数。每一回合，从中选出两块最重的石头，然后将它们一起粉碎。假设石头的重量分别为`x,y`，且`x <= y`。那么粉碎的可能结果如下：

- 如果`x == y`，那么两块石头都会被完全粉碎；
- 如果`x != y`，那么重量为`x`的石头将会完全粉碎，而重量为`y`的石头新重量为`y-x`。

最后，最多只会剩下一块石头。返回此石头的重量。如果没有石头剩下，就返回`0`。

```markdown
# 注意点：
- 单调递减优先级队列（大顶堆）。
```

```java
// 时间复杂度 O(nlogn)；空间复杂度 O(n)
// n - 数组长度
class Solution {
    public int lastStoneWeight(int[] stones) {
        // 堆的应用（大顶堆）
        Queue<Integer> heap = new PriorityQueue<>((o1, o2) -> o2 - o1);
        for (int i = 0; i < stones.length; i++) {
            heap.offer(stones[i]);
        }

        while (heap.size() > 1) {
            int s1 = heap.poll();
            int s2 = heap.poll();
            if (s1 - s2 != 0) {
                heap.offer(s1 - s2);
            }
        }
        return (heap.size() == 0) ? 0 : heap.poll();
    }
}
```

#### 3.2.2. 数组中的第 k 个最大元素（hot100, 1）

**题目 $215$  数组中的第 k 个最大元素**：给定整数数组`nums`和整数`k`，请返回数组中第`k`个最大的元素。请注意，你需要找的是数组排序后的第`k`个最大的元素，而不是第`k`个不同的元素。你必须设计并实现时间复杂度为`O(n)`的算法解决此问题。

```markdown
# 注意点：
- 单调递增优先级队列（小顶堆）。
```

```java
// 时间复杂度 O(nlogk)；空间复杂度 O(k)
// n - 数组长度；k - 题目给出
class Solution {
    public int findKthLargest(int[] nums, int k) {
        // 优先级队列：小顶堆，单调递增
        Queue<Integer> queue = new PriorityQueue<>();

        for (int i = 0; i < nums.length; i++) {
            queue.offer(nums[i]);
            if (queue.size() > k) queue.poll();
        }

        // 返回优先级队列中队列头部的元素
        return queue.peek();
    }
}
```

#### 3.2.3. 最小 k 个数

**面试题 17.14 最小 k 个数**：设计一个算法，找出数组中最小的`k`个数。以任意顺序返回这`k`个数均可。

```markdown
# 注意点：
- 单调递减优先级队列（大顶堆）。
```

```java
// 时间复杂度 O(nlogk)；空间复杂度 O(k)
// n - 数组长度；k - 题目给出
class Solution {
    public int[] smallestK(int[] arr, int k) {
        // 优先级队列——大顶堆
        Queue<Integer> queue = new PriorityQueue<>((o1, o2) -> o2 - o1);
        for (int i = 0; i < arr.length; i++) {
            queue.offer(arr[i]);
            if (queue.size() > k) {
                queue.poll();
            }
        }

        // 从小到大输出
        int[] res = new int[k];
        for (int i = res.length - 1; i >= 0; i--) {
            res[i] = queue.poll();
        }
        return res;
    }
}
```

#### 3.2.4. 前 k 个高频元素（hot100）

**题目 $347$ 前 k 个高频元素**：给你一个整数数组`nums`和一个整数`k`，请你返回其中出现频率前`k`高的元素。你可以按任意顺序返回答案。

```markdown
# 注意点：
- 单调递增优先级队列（小顶堆）。
- 优先级队列中存放 [元素值，出现频率]。
```

```java
// 时间复杂度 O(nlogk)；空间复杂度 O(k)
// n - 数组长度；k - 题目给出
class Solution {
    public int[] topKFrequent(int[] nums, int k) {
        // 优先级队列：小顶堆，队列单调递增
        Queue<int[]> priorityQueue = new PriorityQueue<>((o1, o2) -> (o1[1] - o2[1]));
        int[] res = new int[k];

        // 哈希表：统计每个元素出现的次数
        Map<Integer, Integer> hm = new HashMap<>();
        for (int i = 0; i < nums.length; i++) {
            if (hm.containsKey(nums[i])) {
                hm.put(nums[i], hm.get(nums[i]) + 1);
            } else {
                hm.put(nums[i], 1);
            }
        }

        Set<Integer> set = hm.keySet();
        for (Integer num : set) {
            // 将 [元素值，出现次数] 数组依次加入优先级队列
            priorityQueue.offer(new int[]{num, hm.get(num)});
            if (priorityQueue.size() > k) {
                priorityQueue.poll();
            }
        }

        // 优先级队列中最后剩余 k 个出现次数最大的数组
        int i = 0;
        while (!priorityQueue.isEmpty()) {
            res[i] = priorityQueue.poll()[0];
            i++;
        }
        return res;
    }
}
```

#### 3.2.5. 数据流的中位数（hot100）

**题目 $295$ 数据流的中位数**：中位数是有序整数列表中的中间值。如果列表的大小是偶数，则没有中间值，中位数是两个中间值的平均值。

```markdown
# 注意点：
- 大顶堆：存储小于等于中位数的值。
- 小顶堆：存储大于中位数的值。
```

```java
class MedianFinder {
    Queue<Integer> minHeap;
    Queue<Integer> maxHeap;
    public MedianFinder() {
        // 奇数：大顶堆堆顶元素
        // 偶数：大顶堆和小顶堆堆顶元素平均值
        // 保存大于中位数的元素 4，5
        this.minHeap = new PriorityQueue<>();
        // 保存小于等于中位数的元素 3，2，1
        this.maxHeap = new PriorityQueue<>((o1, o2) -> o2 - o1);
    }
    
    public void addNum(int num) {
        // 存放元素
        if (maxHeap.isEmpty() || num <= maxHeap.peek()) {  // 初始情况
            maxHeap.offer(num);
            // 当大顶堆元素数量比小顶堆多两个时，调整
            if (maxHeap.size() - minHeap.size() > 1) {
                minHeap.offer(maxHeap.poll());
            }
        } else {
            minHeap.offer(num);
            // 当小顶堆中元素数量超过大顶堆时，调整
            if (minHeap.size() > maxHeap.size()) {
                maxHeap.offer(minHeap.poll());
            }
        }
    }
    
    public double findMedian() {
        // 偶数情况
        int size = minHeap.size() + maxHeap.size();
        if (size % 2 == 0) return (minHeap.peek() + maxHeap.peek()) / 2.0;
        else return maxHeap.peek();
    }
}
```
