# 模拟

**模拟算法（Simulation Algorithm）**是一种按照问题的实际过程，逐步模拟其运行状态的算法。它的核心思想是通过代码模拟现实中的操作或规则，通常不依赖于特定的数学公式，而是按照逻辑推演一步步执行。

## 1. 字符串

### 1.1. 字符串转换整数（3）

**题目 $8$​ 字符串转换整数**：请你来实现一个`myAtoi(string s)`函数，使其能将字符串转换成一个`32`位有符号整数。函数`myAtoi(string s)`的算法如下：

1. 空格：读入字符串并丢弃无用的前导空格。
2. 符号：检查下一个字符（假设还未到字符末尾）为`'-'`还是`'+'`。如果两者都不存在，则假定结果为正。
3. 转换：通过跳过前置零来读取该整数，直到遇到非数字字符或到达字符串的结尾。如果没有读取数字，则结果为`0`。
4. 舍入：如果整数数超过`32`位有符号整数范围`[−2^31, 2^31−1]`，需要截断这个整数，使其保持在范围内。

返回整数作为最终结果。

```markdown
# 注意点：本题细节较多，需要熟练。
```

```java
// 时间复杂度 O(n)；空间复杂度 O(1)
// n - 字符串长度
class Solution {
    public int myAtoi(String s) {
        long res = 0;
        // 1. 去除前导空格
        int p = 0;
        while (p < s.length() && s.charAt(p) == ' ') p++;
        if (p == s.length()) return 0;

        // 2. 记录符号
        int sign = 1;
        if (s.charAt(p) == '-') {
            sign = -1;
            p++;
        } else if (s.charAt(p) == '+') p++;

        // 3. 读入连续的数字
        while (p < s.length() && Character.isDigit(s.charAt(p))) {
            res = res * 10 + sign * (s.charAt(p) - '0');  // 带符号运算
            // 4. 溢出判断
            if (res > 0 && res >= Integer.MAX_VALUE) return Integer.MAX_VALUE;
            else if (res < 0 && res <= Integer.MIN_VALUE) return Integer.MIN_VALUE;
            p++;
        }
        return (int) res;
    }
}
```

### 1.2. 字符串相乘（3）

**题目 $43$ 字符串相乘**：给定两个以字符串形式表示的非负整数`num1`和`num2`，返回`num1`和`num2`的乘积，它们的乘积也表示为字符串形式。注意：不能使用任何内置的`BigInteger`库或直接将输入转换为整数。

```markdown
# 注意点：本题细节较多，需要熟练。
- 竖式乘法的规律。
- 对于最高位 0 的处理。
```

```java
// 时间复杂度 O(n * m)；空间复杂度 O(n + m)
// n - num1.length(); m - num2.length()
class Solution {
    public String multiply(String num1, String num2) {
        // 特殊情况
        if (num1.equals("0") || num2.equals("0")) {
            return "0";
        }

        int[] array = new int[num1.length() + num2.length()];
        // 索引 i 和 j 的乘积
        // 累加到数组 num1.length() - 1 - i + num2.length() - 1 - j 索引上
        for (int i = 0; i < num1.length(); i++) {
            for (int j = 0; j < num2.length(); j++) {
                int n1 = num1.charAt(i) - '0';
                int n2 = num2.charAt(j) - '0';
                int idx = num1.length() - 1 - i + num2.length() - 1 - j;
                array[idx] += n1 * n2;
            }
        }
        
        // 数组下标 0 代表最低位
        StringBuilder sb = new StringBuilder();
        int jinwei = 0;
        for (int i = 0; i < array.length; i++) {
            int tmp = array[i] + jinwei;
            // 最高位为 0 单独处理
            if (i == array.length - 1 && tmp == 0) continue;
            sb.append(tmp % 10);
            jinwei = tmp / 10;
        }
        return sb.reverse().toString();
    }
}
```

### 2.1. 轮转数组（hot100）

**题目 $189$ 轮转数组**：给定一个整数数组`nums`，将数组中的元素向右轮转`k`个位置，其中`k`是非负数。

```markdown
# 注意点：最简单的思路，根据下标的特点，重新构建数组。
```

```java
// 时间复杂度 O(n)；空间复杂度 O(n)
// n - 数组长度
class Solution {
    public void rotate(int[] nums, int k) {
        int[] newArray = new int[nums.length];
        // 将原数组下标为 i 的元素存放至新数组下标为 (i + k) % nums.length 的位置
        for (int i = 0; i < nums.length; i++) {
            newArray[(i + k) % nums.length] = nums[i];
        }
        // 更新原数组
        for (int i = 0; i < nums.length; i++) {
            nums[i] = newArray[i];
        }
    }
}
```

```markdown
# 进阶要求：在 O(1) 空间复杂度下求解。
- 反转数组：注意反转的顺序。
```

```java
// 时间复杂度 O(n)；空间复杂度 O(1)
// n - 数组长度
class Solution {
    public void rotate(int[] nums, int k) {
        // k 可能大于数组长度
        if (k > nums.length) k = k % nums.length;
        reverse(nums, 0, nums.length - 1);  // 反转整个数组
        reverse(nums, 0, k - 1);  // 反转 [0, k - 1]
        reverse(nums, k, nums.length - 1);  // 反转 [k, nums.length - 1]
    }

    public void reverse(int[] nums, int left, int right) {
        while (left < right) {
            int tmp = nums[left];
            nums[left] = nums[right];
            nums[right] = tmp;
            left++;
            right--;
        }
    }
}
```

### 2.2. 除自身以外数组的乘积（hot100）

**题目 $238$​ 除自身以外数组的乘积**：给你一个整数数组`nums`，返回数组`answer`，其中`answer[i]`等于`nums`中除`nums[i]`之外其余各元素的乘积 。题目数据保证数组`nums`之中任意元素的全部前缀元素和后缀的乘积都在`32`位整数范围内。要求：不能使用除法，且算法的时间复杂度为`O(n)`，只能额外新建`answer`数组。

```markdown
# 注意点：
- 前缀乘积 & 后缀乘积。
```

```java
// 时间复杂度 O(n)；空间复杂度 O(n)
// n - 数组长度
class Solution {
    public int[] productExceptSelf(int[] nums) {
        // 前缀乘积数组
        int[] pre = new int[nums.length];
        pre[0] = 1;
        for (int i = 1; i < nums.length; i++) {
            pre[i] = pre[i - 1] * nums[i - 1];
        }
        // 后缀乘积数组
        int[] post = new int[nums.length];
        post[nums.length - 1] = 1;
        for (int i = nums.length - 2; i >= 0; i--) {
            post[i] = post[i + 1] * nums[i + 1];
        }
        // answer
        int[] answer = new int[nums.length];
        for (int i = 0; i < answer.length; i++) {
            answer[i] = pre[i] * post[i];
        }
        return answer;
    }
}
```

### 2.3. 多数元素（hot100）

**题目 $169$ 多数元素**：给定一个大小为`n`的数组`nums`，返回其中的多数元素。多数元素是指在数组中出现次数大`⌊ n/2 ⌋`的元素。你可以假设数组是非空的，并且给定的数组总是存在多数元素。

```markdown
# 注意点：摩尔投票法。
# leetcode 题解参考：“同归于尽消杀法” 
- 第一个士兵，直接插上自己阵营的旗帜占领这块高地，此时 candidate 就是这个阵营的人，现存兵力 count = 1。
- 如果新来的士兵和前一个士兵是同一阵营，则集合起来占领高地，candidate 依然是当前这个士兵所属阵营，现存兵力 count++。
- 如果新来到的士兵不是同一阵营，则前方阵营派一个士兵和它同归于尽。 此时前方阵营兵力 count--。
- 当下一个士兵到来，发现前方阵营已经没有兵力 count = 0，新士兵就成了 candidate，现存兵力 count++。
各路军阀一直以这种以一敌一同归于尽的方式厮杀下去，直到少数阵营都死光，那么最后剩下的几个必然属于多数阵营，candidate 就是多数阵营。
```

```java
// 时间复杂度 O(n)；空间复杂度 O(1)
// n - 数组长度
class Solution {
    public int majorityElement(int[] nums) {
        int candidate = 0;
        int count = 0;
        for (int i = 0; i < nums.length; i++) {
            if (count == 0) {
                candidate = nums[i];
            }
            if (candidate == nums[i]) count++;
            else count--;
        }
        return candidate;
    }
}
```

### 2.4. 颜色分类（hot100）

**题目 $75$ 颜色分类**：给定一个包含红色、白色和蓝色、共`n`个元素的数组`nums`，原地对它们进行排序，使得相同颜色的元素相邻，并按照红色、白色、蓝色顺序排列。我们使用整数`0, 1, 2`分别表示红色、白色和蓝色。必须在不使用库内置的排序函数的情况下解决这个问题。

```markdown
# 注意点：
- 三指针：i 用于交换 0, j 用于遍历数组，k 用于交换 1
- 每一种情况下指针的移动。
```

```java
// 时间复杂度 O(n)；空间复杂度 O(1)
// n - 数组长度
class Solution {
    public void sortColors(int[] nums) {
        int i = 0, k = nums.length - 1;  // i 用于交换 0，k 用于交换 2
        int j = 0;  // j 用于遍历数组
        while (j <= k) {  // 注意循环的结束条件
            if (nums[j] == 0) {
                nums[j] = nums[i];  // nums[i] 不可能是 2
                nums[i] = 0;
                i++;
                j++;
            } else if (nums[j] == 1) {
                j++;
            } else {
                nums[j] = nums[k];
                nums[k] = 2;
                k--;
            }
        }
    }
}
```

### 2.5. 下一个排列（hot100, 3）

**题目 $31$ 下一个排列**：整数数组的一个排列就是将其所有成员以序列或线性顺序排列。

- 例如`arr = [1,2,3]` ，以下这些都可以视作`arr`的排列`[1,2,3], [1,3,2], [3,1,2], [2,3,1]`。

整数数组的下一个排列是指其整数的下一个字典序更大的排列。更正式地，如果数组的所有排列根据其字典顺序从小到大排列在一个容器中，那么数组的下一个排列就是在这个有序容器中排在它后面的那个排列。如果不存在下一个更大的排列，那么这个数组必须重排为字典序最小的排列（即元素按升序排列）。

- 例如`arr = [1,2,3]`的下一个排列是`[1,3,2]`；类似地，`arr = [2,3,1]`的下一个排列是`[3,1,2]`；而`arr = [3,2,1]`的下一个排列是`[1,2,3]`，因为`[3,2,1]`不存在一个字典序更大的排列。

给你一个整数数组`nums`，找出`nums`的下一个排列。必须原地修改，只允许使用额外常数空间。

```markdown
# 注意点：本题的思路比较难想，需要熟练。
```

```java
// 时间复杂度 O(n)；空间复杂度 O(1)
// n - 数组长度
class Solution {
    public void nextPermutation(int[] nums) {
        // 从后往前，找到第一个峰值的位置 peak
        int peak = nums.length - 1;
        while (peak > 0 && nums[peak - 1] >= nums[peak]) peak--;

        // 如果 peak = 0，则直接反转整个数组
        if (peak == 0) {
            reverseArray(nums, 0, nums.length - 1);
        } else {
            // 如果 peak != 0，则寻找需要交换的元素位置
            int target = nums.length - 1;
            while (nums[target] <= nums[peak - 1]) target--;
            
            // 交换元素 nums[peak - 1], nums[target]
            int tmp = nums[target];
            nums[target] = nums[peak - 1];
            nums[peak - 1] = tmp;
            // 反转 [peak, nums.length - 1] 区间
            reverseArray(nums, peak, nums.length - 1);
        }
    }

    public void reverseArray(int[] nums, int left, int right) {
        while (left < right) {
            int tmp = nums[left];
            nums[left] = nums[right];
            nums[right] = tmp;
            left++;
            right--;
        }
    }
}
```

### 2.6. 寻找重复数（hot100）

**题目 $287$ 寻找重复数**：给定一个包含`n + 1`个整数的数组`nums`，其数字都在`[1, n]`范围内（包括`1`和`n`），可知至少存在一个重复的整数。假设`nums`只有一个重复的整数，返回这个重复的数。你设计的解决方案必须不修改数组`nums`且只用常量级`O(1)`的额外空间。

```markdown
# 注意点：
- 本题和 环形链表Ⅱ 的思路完全一致。
- 数组转换为链表：
	下标 i 的节点(value = nums[i])，其 next 节点为下标 nums[i] 的节点(value = nums[nums[i]])
	对于数组 [1, 3, 4, 2, 2]，其链表为 1 -> 3 -> 2 -> 4 -> 2 ...
```

```java
class Solution {
    public int findDuplicate(int[] nums) {
        // 由于数组长度为 n+1，因此每一个元素值都可以对应一个下标
        // 将数组转化为链表 num[0] -> nums[nums[0]] -> nums[nums[nums[0]]] -> ...
        // 问题转化为：寻找环形链表的入口
        int slow = nums[0];
        int fast = nums[0];

        // 寻找快慢指针相遇的位置
        do {
            slow = nums[slow];
            fast = nums[nums[fast]];
        } while (slow != fast);
        
        // 寻找环的入口
        int tmp = nums[0];
        while (slow != tmp) {
            tmp = nums[tmp];
            slow = nums[slow];
        }
        return tmp;
    }
}
```

## 3. 矩阵

### 3.1. 螺旋矩阵系列

#### 3.1.1. 螺旋矩阵（hot100, 2）

**题目 $54$ 螺旋矩阵**：给你一个`m`行`n`列的矩阵`matrix`，请按照顺时针螺旋顺序，返回矩阵中的所有元素。

```markdown
# 注意点：
- 逐层遍历：采用四个指针记录上下左右的边界位置。
- while 循环的条件是 && 而不是 ||
```

```java
// 时间复杂度 O(nm)；空间复杂度 O(nm)
// n - 行数；m - 列数
class Solution {
    public List<Integer> spiralOrder(int[][] matrix) {
        List<Integer> res = new ArrayList<>();  // 结果数组
        // 四个指针：上下左右的边界位置
        int left = 0, right = matrix[0].length - 1;
        int top = 0, bottom = matrix.length - 1;

        while (left <= right && top <= bottom) {  // 同时满足条件才有元素可搜索
            // 第一行
            for (int j = left; j <= right; j++) res.add(matrix[top][j]);
            top++;
            // 最后一列
            for (int i = top; i <= bottom; i++) res.add(matrix[i][right]);
            right--;
            // 最后一行
            if (top <= bottom) {
                for (int j = right; j >= left; j--) res.add(matrix[bottom][j]);
                bottom--;
            }
            // 第一列
            if (left <= right) {
                for (int i = bottom; i >= top; i--) res.add(matrix[i][left]);
                left++;
            }
        }
        return res;
    }
}
```

#### 3.1.2. 螺旋矩阵Ⅱ

**题目 $59$ 螺旋矩阵Ⅱ**：给你一个正整数`n`，生成一个包含`1`到`n^2`所有元素，且元素按顺时针顺序螺旋排列的`n x n`正方形矩阵`matrix`。

```java
// 时间复杂度 O(n^2)；空间复杂度 O(n^2)
// n - 正整数
class Solution {
    public int[][] generateMatrix(int n) {
        int[][] matrix = new int[n][n];
        // 四个指针：上下左右的边界位置
        int left = 0, right = n - 1;
        int top = 0, bottom = n - 1;

        int num = 1;
        while (left <= right) {
            // 第一行
            for (int j = left; j <= right; j++) matrix[top][j] = num++;
            top++;
            // 最后一列
            for (int i = top; i <= bottom; i++) matrix[i][right] = num++;
            right--;
            // 最后一行
            if (top <= bottom) {
                for (int j = right; j >= left; j--) matrix[bottom][j] = num++;
                bottom--;
            }
            // 第一列
            if (left <= right) {
                for (int i = bottom; i >= top; i--) matrix[i][left] = num++;
                left++;
            }
        }
        return matrix;
    }
}
```

### 3.2. 旋转图像（hot100）

**题目 $48$ 旋转图像**：给定一个`n × n`的二维矩阵`matrix`表示一个图像。请你将图像顺时针旋转`90`度。你必须在原地旋转图像，这意味着你需要直接修改输入的二维矩阵。请不要使用另一个矩阵来旋转图像。

```markdown
# 注意点：
- 本题有一个误区：不要按行来旋转图像。每次旋转一个元素即可。
```

```java
// 时间复杂度 O(n^2)；空间复杂度 O(1)
// n - 矩阵阶数
class Solution {
    public void rotate(int[][] matrix) {
        // 四个指针：上下左右的边界位置
        int left = 0, right = matrix[0].length - 1;
        int top = 0, bottom = matrix.length - 1;

        while (left < right) {
            // 注意：i 为 [left, right) 之间的相对值，且不能取到 right 边界
            for (int i = 0; i < right - left; i++) {
                int tmp = matrix[top][left + i];
                matrix[top][left + i] = matrix[bottom - i][left];
                matrix[bottom - i][left] = matrix[bottom][right - i];
                matrix[bottom][right - i] = matrix[top + i][right];
                matrix[top + i][right] = tmp;
            }
            left++; right--;
            top++; bottom--;
        }
    }
}
```

### 3.3. 矩阵置零（hot100）

**题目 $73$ 矩阵置零**：给定一个`m x n`的矩阵，如果一个元素为`0`，则将其所在行和列的所有元素都设为`0`。

```markdown
# 注意点：直观的思路。
- 用两个标记数组记录出现 0 的行和列。
```

```java
// 时间复杂度 O(nm)；空间复杂度 O(n + m)
// n - 行数；m - 列数
class Solution {
    public void setZeroes(int[][] matrix) {
        // 两个标记数组
        boolean[] rowFlags = new boolean[matrix.length];
        boolean[] colFlags = new boolean[matrix[0].length];
        for (int i = 0; i < matrix.length; i++) {
            for (int j = 0; j < matrix[0].length; j++) {
                if (matrix[i][j] == 0) {
                    rowFlags[i] = true;
                    colFlags[j] = true;
                }
            }
        }
        // 更新矩阵：置零
        for (int i = 0; i < matrix.length; i++) {
            for (int j = 0; j < matrix[0].length; j++) {
                if (rowFlags[i] || colFlags[j]) matrix[i][j] = 0; 
            }
        }
    }
}
```

```markdown
# 进阶要求：在 O(1) 空间复杂度下求解。
- 采用矩阵的第一行和第一列作为标记数组。
- 单独用两个标记变量来记录第一行和第一列是否出现 0.
```

```java
// 时间复杂度 O(nm)；空间复杂度 O(1)
// n - 行数；m - 列数
class Solution {
    public void setZeroes(int[][] matrix) {
        // 两个标记变量：记录第一行、第一列是否有 0
        boolean rowFlag = false, colFlag = false;
        for (int i = 0; i < matrix.length; i++) {
            if (matrix[i][0] == 0) colFlag = true;
        }
        for (int j = 0; j < matrix[0].length; j++) {
            if (matrix[0][j] == 0) rowFlag = true;
        }
        // 采用第一行、第一列作为标记数组
        for (int i = 1; i < matrix.length; i++) {
            for (int j = 1; j < matrix[0].length; j++) {
                if (matrix[i][j] == 0) {
                    matrix[i][0] = 0;
                    matrix[0][j] = 0;
                }
            }
        }
        // 遍历矩阵：置零
        for (int i = 1; i < matrix.length; i++) {
            for (int j = 1; j < matrix[0].length; j++) {
                if (matrix[i][0] == 0 || matrix[0][j] == 0) {
                    matrix[i][j] = 0;
                }
            }
        }
        // 最后处理第一行、第一列
        if (rowFlag) {
            for (int j = 0; j < matrix[0].length; j++) matrix[0][j] = 0;
        }
        if (colFlag) {
            for (int i = 0; i < matrix.length; i++) matrix[i][0] = 0;
        }
    }
}
```

### 3.4. 搜索二维矩阵Ⅱ（hot100）

**题目 $240$ 搜索二维矩阵Ⅱ**：编写一个高效的算法来搜索`m x n`矩阵`matrix`中的一个目标值`target`。该矩阵具有以下特性：每行的元素从左到右升序排列；每列的元素从上到下升序排列。

```markdown
# 注意点：
- Z 字形搜索：如果当前位置元素小于 target，舍弃当前行；反之，舍弃当前列。
```

```java
// 时间复杂度 O(m + n)；空间复杂度 O(1)
// m - 行数；n - 列数
class Solution {
    public boolean searchMatrix(int[][] matrix, int target) {
        // 从矩阵右上角开始 Z 字形查找
        int top = 0, right = matrix[0].length - 1;

        while (top <= matrix.length - 1 && right >= 0) {
            if (matrix[top][right] == target) return true;
            else if (matrix[top][right] > target) right--;
            else if (matrix[top][right] < target) top++;
        }

        // 退出循环说明没有找到目标值
        return false;
    }
}
```

## 4. 位运算

### 4.1. 只出现一次的数字（hot100）

**题目 $136$ 只出现一次的数字**：给你一个非空整数数组`nums`，除了某个元素只出现一次以外，其余每个元素均出现两次。找出那个只出现了一次的元素。

> 异或`^`：常见的位运算，对两个二进制位进行比较，相同为 $0$，不同为 $1$。其核心运算性质如下：
>
> - 交换律：`a ^ b = b ^ a`。
> - 结合律：`(a ^ b) ^ c = a ^ (b ^ c)`。
> - 自反性：`a ^ a = 0, a ^ 0 = a`。

```markdown
# 注意点：
- 数组中所有元素的异或结果就等于只出现一次的数字。
```

```java
// 时间复杂度 O(n)；空间复杂度 O(1)
// n - 数组长度
class Solution {
    public int singleNumber(int[] nums) {
        int res = 0;
        for (int i = 0; i < nums.length; i++) {
            res = res ^ nums[i];
        }
        return res;
    }
}
```

### 4.2. 只出现一次的数字Ⅱ

**题目 $137$ 只出现一次的数字Ⅱ**：给你一个整数数组`nums`，除某个元素仅出现一次外，其余每个元素都恰出现三次 。请你找出并返回那个只出现了一次的元素。

```markdown
# 注意点：
- 二进制运算：(num >> i) & 1。提取整数第 i 位的值。
- 二进制运算：res | (1 << i)。将 res 的第 i 位置 1.
- 判断每一位中 1 出现的次数，如果为 3 的倍数，则目标元素该位为 0；反之，目标元素该位为 1.
```

```java
// 时间复杂度 O(n)；空间复杂度 O(1)
// n - 数组长度
class Solution {
    public int singleNumber(int[] nums) {
        int res = 0;
        for (int i = 0; i < 32; i++) {
            // 统计第 i 位 1 的数量
            int total = 0;
            for (int j = 0; j < nums.length; j++) {
                total += (nums[j] >> i) & 1;
            }
            // 如果第 i 位 1 的数量不是 3 的倍数，则目标元素该位为 1
            if (total % 3 != 0) {
                res = res | (1 << i);
            }
        }
        return res;
    }
}
```
