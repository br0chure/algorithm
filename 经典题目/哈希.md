## 1. 字母异位词系列

### 1.1. 有效的字母异位词

**题目 $242$ 有效的字母异位词**：给定两个字符串`s`和`t` ，编写一个函数来判断`t`是否是`s`的字母异位词。字母异位词是通过重新排列不同单词或短语的字母而形成的单词或短语，并使用所有原字母一次。字符串均由小写英文字符构成。

```markdown
# 注意点：
- 采用 数组 作为哈希结构。
```

```java
// 时间复杂度 O(n)；空间复杂度 O(1)
// n - 字符串长度
class Solution {
    public boolean isAnagram(String s, String t) {
        if (s.length() != t.length()) return false;
        // 采用 数组 作为哈希结构
        int[] hash = new int[26];

        for (int i = 0; i < s.length(); i++) {
            hash[s.charAt(i) - 'a']++;
            hash[t.charAt(i) - 'a']--;
        }
        for (int i = 0; i < hash.length; i++) {
            if (hash[i] != 0) return false;
        }
        return true;
    }
}
```

### 1.2. 赎金信

**题目 $383$ 赎金信**：给你两个字符串`ransomNote`和`magazine`，判断`ransomNote`能不能由`magazine`里面的字符构成。如果可以，返回`true`；否则返回`false`。`magazine`中的每个字符只能在`ransomNote`中使用一次。字符串均由小写英文字符构成。

```markdown
# 注意点：
- 采用 数组 作为哈希结构。
```

```java
// 时间复杂度 O(n + m)；空间复杂度 O(1)
// n - ransomNote.length(); m - magazine.length()
class Solution {
    public boolean canConstruct(String ransomNote, String magazine) {
        if (magazine.length() < ransomNote.length()) return false;
        // 采用 数组 作为哈希
        int[] hash = new int[26];

        for (int i = 0; i < ransomNote.length(); i++) {
            hash[ransomNote.charAt(i) - 'a']++;
        }
        for (int i = 0; i < magazine.length(); i++) {
            hash[magazine.charAt(i) - 'a']--;
        }

        for (int i = 0; i < hash.length; i++) {
            if (hash[i] > 0) return false;
        }
        return true;
    }
}
```

### 1.3. 字母异位词分组（hot100）

**题目 $19$ 字母异位词分组**：给你一个字符串数组，请你将字母异位词组合在一起。可以按任意顺序返回结果列表。`strs[i]`仅包含小写字母。

```markdown
# 注意点：暴力求解需要两层循环 + 判断是否是字母异位词；哈希解法只需要一层循环 + 判断是否是字母异位词
- 采用 数组 作为哈希结构：存储每个单词中字符出现次数。
- 采用 Map 作为哈希结构：存储字母异位词。
```

```java
// 时间复杂度 O(n * m)；空间复杂度 O(n * m)
// n - 字符串数组长度; m - 字符串平均长度
class Solution {
    public List<List<String>> groupAnagrams(String[] strs) {
        // 采用 Map 作为哈希结构：存储字母异位词
        Map<String, List<String>> hm = new HashMap<>();

        for (String str : strs) {
            // 采用 数组 作为哈希结构：存储每个单词中字符出现次数
            int[] hash = new int[26];
            for (int i = 0; i < str.length(); i++) {
                hash[str.charAt(i) - 'a']++;
            }
            // 构造 Map 的键：a1e1t1
            StringBuilder sb = new StringBuilder();
            for (int i = 0; i < hash.length; i++) {
                if (hash[i] != 0) {
                    sb.append((char) ('a' + i));  // 注意类型转换
                    sb.append(hash[i]);
                }
            }

            String key = sb.toString();
            if (hm.containsKey(key)) hm.get(key).add(str);
            else {
                List<String> list = new ArrayList<>();
                list.add(str);
                hm.put(key, list);
            }
        }
        
        // 遍历 Map，生成结果
        for (String key : hm.keySet()) {
            res.add(hm.get(key));
        }
        return res;
    }
}
```

### 1.4. 找到字符串中所有字母异位词（hot100）

**题目 $438$ 找到字符串中所有字母异位词**：给定两个字符串`s`和`p`，找到`s`中所有`p`的异位词的子串，返回这些子串的起始索引。不考虑答案输出的顺序。`s`和`p`仅包含小写字母。

```markdown
# 注意点：
- 双指针 + 哈希（数组）。
```

```java
// 时间复杂度 O(n)；空间复杂度 O(n)
// n - s.length()
class Solution {
    public List<Integer> findAnagrams(String s, String p) {
        List<Integer> res = new ArrayList<>();
        if (s.length() < p.length()) return res;

        // 采用 array 作为哈希结构
        int[] hash = new int[26];
        // 第一个滑动窗口
        for (int i = 0; i < p.length(); i++) {
            hash[p.charAt(i) - 'a']++;
            hash[s.charAt(i) - 'a']--;
        }
        if (allCover(hash)) res.add(0);

        for (int i = p.length(); i < s.length(); i++) {
            hash[s.charAt(i) - 'a']--;
            hash[s.charAt(i - p.length()) - 'a']++;
            if (allCover(hash)) res.add(i - p.length() + 1);
        }
        return res;
    }

    public boolean allCover(int[] nums) {
        for (int i = 0; i < nums.length; i++) {
            if (nums[i] != 0) return false;
        }
        return true;
    }
}
```

## 2. 数组交集系列

### 2.1. 两个数组的交集

**题目 $349$ 两个数组的交集**：给定两个数组`nums1`和`nums2`，返回它们的交集。输出结果中的每个元素一定是唯一的。我们可以不考虑输出结果的顺序。

```markdown
# 注意点：
- 采用 Set 作为哈希结构。
```

```java
// 时间复杂度 O(n1 + n2)；空间复杂度 O(min(n1, n2))
// n1 - nums1.lengh; n2 - nums2.length
class Solution {
    public int[] intersection(int[] nums1, int[] nums2) {
        // 采用 Set 作为哈希结构
        Set<Integer> set1 = new HashSet<>();  // 存储 nums1 中的不重复元素
        Set<Integer> set2 = new HashSet<>();  // 存储交集元素

        for (int i = 0; i < nums1.length; i++) {
            set1.add(nums1[i]);
        }
        for (int i = 0; i < nums2.length; i++) {
            if (set1.contains(nums2[i])) set2.add(nums2[i]);
        }

        int[] res = new int[set2.size()];
        int idx = 0;
        for (Integer num : set2) {
            res[idx++] = num;
        }
        return res;
    }
}
```

### 2.2. 两个数组的交集Ⅱ

**题目 $350$ 两个数组的交集Ⅱ**：给你两个整数数组`nums1`和`nums2`，请你以数组形式返回两数组的交集。返回结果中每个元素出现的次数，应与元素在两个数组中都出现的次数一致（如果出现次数不一致，则考虑取较小值）。可以不考虑输出结果的顺序。

```markdown
# 注意点：
- 采用 Map 作为哈希结构。
```

```java
// 时间复杂度 O(n1 + n2)；空间复杂度 O(n1)
// n1 - nums1.lengh; n2 - nums2.length
class Solution {
    public int[] intersect(int[] nums1, int[] nums2) {
        // 采用 Map 作为哈希结构
        Map<Integer, Integer> hm = new HashMap<>();
        List<Integer> list = new ArrayList<>();

        for (int i = 0; i < nums1.length; i++) {
            if (hm.containsKey(nums1[i])) hm.put(nums1[i], hm.get(nums1[i]) + 1);
            else hm.put(nums1[i], 1);
        }
        for (int i = 0; i < nums2.length; i++) {
            if (hm.containsKey(nums2[i]) && hm.get(nums2[i]) > 0) {
                hm.put(nums2[i], hm.get(nums2[i]) - 1);
                list.add(nums2[i]);
            }
        }

        // 将 List 转换为 int[] 返回
        int[] res = new int[list.size()];
        for (int i = 0; i < list.size(); i++) res[i] = list.get(i);
        return res;
    }
}
```

## 3. 最长连续序列（hot100）

**题目 $128$ 最长连续序列**：给定一个未排序的整数数组`nums`，找出数字连续的最长序列（不要求序列元素在原数组中连续）的长度。请你设计并实现时间复杂度为`O(n)`的算法解决此问题。

```markdown
# 注意点：
- 采用 Set 作为哈希结构：元素去重，防止超时。
- 计算以当前元素开头的最长序列：防止重复计算，超时。
```

```java
// 时间复杂度 O(n)；空间复杂度 O(n)
// n - 数组长度
class Solution {
    public int longestConsecutive(int[] nums) {
        // 采用 Set 作为哈希结构
        Set<Integer> set = new HashSet<>();
        // 先采用 Set 进行去重，数组中可能存在重复元素，防止超时
        for (int i = 0; i < nums.length; i++) {
            set.add(nums[i]);
        }

        int maxLen = 0;
        for (Integer num : set) {
            // 计算以当前元素开头的最长连续序列
            if (!set.contains(num - 1)) {
                int tmp = num + 1;
                int len = 1;
                while (set.contains(tmp)) {
                    len++;
                    tmp++;
                }
                maxLen = Math.max(maxLen, len);
            }
        }
        return maxLen;
    }
}
```

## 4. 和为 k 的子数组（hot100）

**题目 $560$ 和为 k 的子数组**：给你一个整数数组`nums`和一个整数`k`，请你统计并返回该数组中和为`k`的子数组的个数。子数组是数组中元素的连续非空序列。

```markdown
# 注意点：
- 采用 Map 作为哈希结构 <前缀和，出现次数>。
- 虚拟前缀和。
- 必须先“累加和为 k 的子数组个数”再“保存前缀和”，否则当 k = 0 时会发生错误统计。
```

```java
// 时间复杂度 O(n)；空间复杂度 O(n)
// n - 数组长度
class Solution {
    public int subarraySum(int[] nums, int k) {
        // 采用 Map 作为哈希结构
        // 存储到当前遍历元素为止 前缀和:出现次数
        Map<Integer, Integer> hm = new HashMap<>();

        // 注意：初始化
        hm.put(0, 1);

        int count = 0;
        int sum = 0;
        for (int i = 0; i < nums.length; i++) {
            sum += nums[i];
            // 累加和为 k 的子数组个数
            if (hm.containsKey(sum - k)) count += hm.get(sum - k);
            // 保存前缀和
            if (hm.containsKey(sum)) hm.put(sum, hm.get(sum) + 1);
            else hm.put(sum, 1);
        }
        return count;
    }
}
```

## 5. 快乐数

**题目 $202$ 快乐数**：编写一个算法来判断一个数`n`是不是快乐数。快乐数定义为：

- 对于一个正整数，每一次将该数替换为它每个位置上的数字的平方和。
- 然后重复这个过程直到这个数变为`1`，也可能是无限循环但始终变不到`1`。
- 如果这个过程结果为`1`，那么这个数就是快乐数。

如果`n`是快乐数就返回`true`；不是，则返回`false`。

```markdown
# 注意点：
- 采用 Set 作为哈希结构。
```

```java
// 时间复杂度 O(log n)；空间复杂度 O(log n)
// n - 数值
class Solution {
    public boolean isHappy(int n) {
        // 采用 Set 作为哈希结构：存储出现过的数
        Set<Integer> set = new HashSet<>();

        while (n != 1) {
            int sum = 0;
            while (n != 0) {
                sum += (n % 10) * (n % 10);
                n = n / 10;
            }
            if (set.contains(sum)) return false;
            else set.add(sum);
            n = sum;
        }
        return true;
    }
}
```

## 6. 两数之和（hot100, 1）

**题目 $1$ 两数之和**：给定一个整数数组`nums`和一个整数目标值`target`，请你在该数组中找出和为目标值 `target`的那两个整数，并返回它们的数组下标。你可以假设每种输入只会对应一个答案，并且你不能使用两次相同的元素。你可以按任意顺序返回答案。

```markdown
# 注意点：
- 采用 Map 作为哈希结构。
```

```java
// 时间复杂度 O(n)；空间复杂度 O(n)
// n - 数组长度
class Solution {
    public int[] twoSum(int[] nums, int target) {
        // 采用 Map 作为哈希结构
        Map<Integer, Integer> hm = new HashMap<>();

        int[] res = new int[2];
        for (int i = 0; i < nums.length; i++) {
            if (hm.containsKey(nums[i])) {
                res[0] = i;
                res[1] = hm.get(nums[i]);
                break;
            } else {
                hm.put(target - nums[i], i);
            }
        }
        return res;
    }
}
```

## 7. 四数相加Ⅱ

**题目 $454$ 四数相加Ⅱ**：给你四个整数数组`nums1, nums2, nums3, nums4`，数组长度都是`n`，请你计算有多少个元组`(i, j, k, l)`能满足：`0 <= i, j, k, l < n, nums1[i] + nums2[j] + nums3[k] + nums4[l] == 0`。

```markdown
# 注意点：
- 采用 Map 作为哈希结构。
- 分组遍历，降低时间复杂度。
```

```java
// 时间复杂度 O(n^2)；空间复杂度 O(n^2)
// n - 数组长度
class Solution {
    public int fourSumCount(int[] nums1, int[] nums2, int[] nums3, int[] nums4) {
        // 采用 Map 作为哈希结构
        Map<Integer, Integer> hm = new HashMap<>();

        // 双重循环遍历 nums1, nums2
        for (int i = 0; i < nums1.length; i++) {
            for (int j = 0; j < nums2.length; j++) {
                int sum = - nums1[i] - nums2[j];
                if (hm.containsKey(sum)) hm.put(sum, hm.get(sum) + 1);
                else hm.put(sum, 1);
            }
        }
        
        // 双重循环遍历 nums3, nums4
        int res = 0;
        for (int i = 0; i < nums3.length; i++) {
            for (int j = 0; j < nums4.length; j++) {
                if (hm.containsKey(nums3[i] + nums4[j])) {
                    res += hm.get(nums3[i] + nums4[j]);
                }
            }
        }
        return res;
    }
}
```

## 8. 缺失的第一个正数（hot100, 3）

**题目 $41$​ 缺失的第一个整数**：给你一个未排序的整数数组`nums`，请你找出其中没有出现的最小的正整数。请你实现时间复杂度为`O(n)`并且只使用常数级别额外空间的解决方案。

```markdown
# 注意点：本题在空间复杂度要求下很困难。
- 原地哈希：将输入数组作为哈希结构。由于长度为 n 的数组只能存放 [1, n + 1] 之间的正数。因此，元素 i + 1 的正确位置是下标 i。
- 遍历数组，如果遇到 [1, n + 1] 之间的元素，则将其与正确位置上的元素交换。
```

```java
// 时间复杂度 O(n)；空间复杂度 O(1)
// n - 数组长度
class Solution {
    public int firstMissingPositive(int[] nums) {
        // 原地哈希：将元素 i + 1 放在正确位置，即下标为 i 的位置
        // 0 <= i <= nums.length - 1
        int n = nums.length;
        for (int i = 0; i < n; i++) {
            // nums[i] != nums[nums[i] - 1] 条件判断了两种情况：
            // 1. 当前位置上已经是正确的数值
            // 2. 当前位置上不是正确的数值，且交换的两个数相同
            while (nums[i] >= 1 && nums[i] <= n && nums[i] != nums[nums[i] - 1]) {
                // 注意：交换的顺序不能调换
                int tmp = nums[nums[i] - 1];
                nums[nums[i] - 1] = nums[i];
                nums[i] = tmp;
            }
        }
        // 遍历数组，查找第一个不正确的位置
        for (int i = 0; i < n; i++) {
            if (nums[i] != i + 1) return i + 1;
        }
        return n + 1;
    }
}
```
