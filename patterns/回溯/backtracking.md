# backtracking · 回溯

集中沉淀回溯的通用模板与心法。搭配 [tree_path](../二叉树/tree_path.md)（二叉树里的 DFS + 回溯）一起看——回溯就是它的推广。

## Pattern 概念

在一个"选择序列"上穷举所有可能：每步从候选里选一个 → 递归到下一步 → 试完回退换下一个。
典型场景：**组合 / 子集 / 排列 / 棋盘（N 皇后、数独）/ 字符串切分**。

抽象成树：**宽度** = 每步候选个数，**深度** = 选择步数。

## 通用模板

骨架永远是 **选择 → 递归 → 撤销**，三步成对。差别只在两处：**在哪收集** 和 **候选怎么定**。

### 在哪收集（决定题目形态）

**A. 满了才收集**——只要特定大小的解（排列、组合）

```go
var backtrack func(int)
backtrack = func(start int) {
    if len(path) == 目标 {        // 进度尺到点
        收集（深拷贝）
        return                    // 满了别再深入（组合里这是必须的剪枝）
    }
    for i := start; ... {
        做选择; backtrack(...); 撤销选择
    }
}
```

**B. 每个节点都收集**——所有中间状态都算解（子集）

```go
var backtrack func(int)
backtrack = func(start int) {
    收集（深拷贝）                 // 一进来就收，根节点把空集也收进来
    for i := start; i < n; i++ {
        做选择; backtrack(i+1); 撤销选择
    }
    // 不必写 base case：i 到末尾 for 自然不跑、自然返回
}
```

> **收集写 for 外还是 for 里？** 上面两式都写在 for **外**（站在当前节点收自己）。等价写法是放进 for 里、`选` 之后（站在父节点，选完一个孩子就收）——收的是同一批状态，只差**根节点**：for 里收法收不到空集，要的话得额外补。组合/排列放 base case（for 外）最省事，因为能顺手 `return` 剪枝。

### 候选怎么定（决定去重）

| | 手段 | 适用 |
|--|--|--|
| **排列** | `used[]` 标记，每层选所有没用过的 | 结果**计顺序**（`[1,2]≠[2,1]`），要回头选 |
| **组合 / 子集** | `start` 指针，只往后选 | 结果**不计顺序**（`[1,2]=[2,1]`），强制升序去重 |
| **逐层独立** | `index` 逐层，每层遍历本层自己的候选 | 每层候选不同（如电话号码），位置被锁死 → **无需 start / 去重** |

判断尺：前两类看结果计不计顺序；**第三类候选每层都不同（位置固定），天生不重复**——要不要 `start` 取决于"是否同一候选集 + 计不计顺序"，**不取决于 for 从不从 0 开始**。

> `start` 传什么 = "下一层还能不能再选 `j` 自己"：传 `j+1` → 每个数只用一次（0077）；传 `j` → 同一个数可重复选（0039）。排列不传起点，靠 `used` 决定谁还能选。

## 心法

### #1 递归 = 层数不定的 for

排列 `[1,2,3]` 要 3 层 for、`[1,2,3,4]` 要 4 层——层数随输入变，没法写"变量层 for"。**递归就是层数不定的 for**：每深一层 = 多套一层，自己套到候选耗尽。这是回溯用递归、而非迭代嵌套的根本原因。

### #2 二叉树递归是回溯的特例

- 二叉树：每节点选择**固定两个**（左 / 右）→ 写死 `dfs(Left)`、`dfs(Right)`。
- 一般回溯：每步选择是**一组** → 换成 `for { 选; backtrack; 撤销 }`。

同一骨架，二叉树只是"每层定宽为 2"的回溯。**会二叉树 DFS = 已经会回溯**。

### #3 终止靠 for 边界，base case 是"额外职责"

递归能停，本质是**候选耗尽时 for 不再产生新调用**（组合 `i` 涨到 `n`、排列 `used` 全满），**不是**靠 base case 那个 `if`。

base case 的 `if` 其实是叠加上去的两件事：① 判断"该收集了" ② 用 `return` 剪掉无用深入。推论：

- **子集**每节点都收集、无需判断时机 → 连 base case 都能省。
- **组合**满了之后 for 还有候选（`i` 没到 `n`）→ `return` 是必须的剪枝；漏写不会错，但白跑一大片。
- **排列**满了 `used` 全满、for 全 `continue` → `return` 可有可无（顺手写上保持一致）。

### #4 收集解必须深拷贝

`path` 是共享底层数组的切片，直接存进结果会被后续回溯改乱。`make([]int, len(path)) + copy`，或 `append([]int{}, path...)`。注意 `copy` 看 `len` 不看 `cap`。（同 tree_path 的坑）

### #5 同层去重（输入含重复元素时）

前提都是先**排序**（相同值相邻）。核心都是 **同层跳、跨层留**，但"怎么判同层"取决于你用 `start` 还是 `used`：

**组合 / 子集（用 `start`）**：`if j > i && nums[j]==nums[j-1] { continue }`
- `j > i` 锁同层：`i` 是本层起点，`j > i` 说明本层前面刚选过相同值（跳）；`j == i`（本层第一个）的相同值来自上层（跨层，留），否则 `[1,1]` 会被误杀。

**排列（用 `used`）**：`if i > 0 && nums[i]==nums[i-1] && !used[i-1] { continue }`
- 看前一个相同值的状态：前一个「用了」（`used[i-1]==true`）在 path 里、是上层选的（跨层，留）；「没用」（`used[i-1]==false`）是本层刚试完撤销的（同层，跳）。

> **口诀：前一个「用了」是跨层（留），「没用」是同层（跳）。**
> 本质统一：同层（同一次 for 的兄弟）去重、跨层（父 → 子递归）保留——组合靠 `j>i` 判、排列靠 `!used[i-1]` 判，判的是同一件事。

### #6 切分型：把「选一段」当「选一个元素」

分割字符串 = 子集的「选一段」版，骨架和子集一模一样：

```go
backtrack = func(start int) {
    if start == len(s) {          // 整串切完 → 收集
        收集 path; return
    }
    for j := start; j < len(s); j++ {
        sub := s[start : j+1]     // 当前段 [start, j]
        if 段不合法 { continue }   // 回文分割: !isPalindrome；IP: 非法段
        path = append(path, sub); backtrack(j+1); 撤销
    }
}
```

- `start` 段头、`j` 段尾、`s[start:j+1]` 这一段、`backtrack(j+1)` 切剩下的。
- 和子集**唯一实质区别**：base case `start==len(s)`——必须整串切完才算一个答案（子集是每节点都收）。
- 段合法性在 for 里过滤；**天生不用去重**（按位置切、顺序锁死）。

### #7 网格 DFS：四方向 + visited + 每格起点

二维网格搜索（单词搜索、岛屿）：

- 每个格子都可能是起点 → **双重 for 遍历起点**。
- `dfs(r,c,...)`：先判 **越界 / 不匹配 / 已访问** → return；再判成功。
- **四方向**递归 `(r±1,c)`、`(r,c±1)`；**visited 标记进、撤销出**。

> visited 两种：`used` 矩阵（清晰，O(mn)）vs 原地改标记（省空间 O(1)，临时动输入）。

## 常见变体（随刷题补全）

| 变体 | 关键手段 | 代表题 |
|---|---|---|
| 排列 | `used[]`（可回头选） | 0046 ✅ |
| 组合 | `start`，满了才收集 | 0077 ✅ |
| 子集 | `start`，每节点都收集 | 0078 ✅ |
| 同层去重 | 排序 + `j>i`(组合) / `!used[i-1]`(排列) | 0040 / 0090 / 0047 ✅ |
| 元素可重复选 | 递归传 `i` 而非 `i+1` | 0039 ✅ |
| 逐层独立候选 | `index` 逐层，无需 start | 0017 ✅ |
| 切分型 | 选一段 `s[start:j+1]`，切到底才收 | 0131 / 0093 ✅ |
| 约束生成 | 每位填候选 + 剪枝（括号 open/close） | 0022 ✅ |
| 网格 DFS | 四方向 + visited，每格当起点 | 0079 ✅（0051 待刷）|
