# 斐波那契型（线性递推）

DP 最入门的一类：`dp[i]` 由前面固定的一两个状态直接相加得到，**没有"选择"分支**。通用方法论见 [dp_intro](dp_intro.md)。

## 特征

`dp[i] = dp[i-1] + dp[i-2]`（或类似的、只依赖最近几个状态的固定递推）。

## Go 模板（O(1) 滚动变量）

`dp[i]` 只用到前两个值，不必开整个数组，两个变量往前滚：

```go
func fib(n int) int {
    if n < 2 {
        return n
    }
    prev, curr := 0, 1
    for i := 2; i <= n; i++ {
        prev, curr = curr, prev+curr // 往前滚一格
    }
    return curr
}
```

## 心法

- **状态最简单**：这类题起手五步的 ③（要记住什么）答案就是"前一两个状态"，无需选择、无需多维。
- **滚动变量**：只依赖最近几个状态 → 空间 O(n) → O(1)，一维 DP 最常见的空间优化。
- **base case 是唯一要小心的地方**（不同题起点不同）。
