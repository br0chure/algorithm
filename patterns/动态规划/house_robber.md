# 打家劫舍型（选或不选 + 相邻互斥）

一批元素排成**线 / 环 / 树**，每个"选或不选"、**相邻的不能同时选**，求最优。通用方法论见 [dp_intro](dp_intro.md)。

## 核心（起手五步）

- **① 选择**：当前元素偷 or 不偷
- **② 约束**：偷了它 → 相邻的不能偷
- **③ 状态**：`dp[i]` = 到 i 为止能偷的最大值（偷没偷 i 是 max 的副产品，不锁定）
- **④ 转移**：`dp[i] = max(不偷 = dp[i-1], 偷 = dp[i-2] + nums[i])`
- **⑤ 顺序**：线性从小到大 / 树后序

口诀：**偷 → 跳一格接 `dp[i-2]`；不偷 → 原地接 `dp[i-1]`。** 决策被 `max` 吸收，一维就够。

## 三种变体（质不同）

| 变体 | 关键转化 | 状态 |
|---|---|---|
| **线性** [0198](../../problems/动态规划/0198%20打家劫舍.md) | 直接递推 | 一维，可 O(1) 滚动 |
| **环形** [0213](../../problems/动态规划/0213%20打家劫舍%20II.md) | **断环成链**：首尾不能同时偷 → 去首、去尾各跑一次线性，取 max | 复用线性 |
| **树形** [0337](../../problems/动态规划/0337%20打家劫舍%20III.md) | 后序 DFS，每节点返回**一对** `(不偷, 偷)` | 二维状态机（甩不掉）|

## 心法

- **一维够 vs 必须状态机**：线性 / 环形里"偷 / 不偷"决策能被 `max` 吸收（`dp[i-1]` 天然编码了"不偷"分支）→ 一维够；树形里"偷父"要精确用到"孩子不偷"的值、没有线性结构可借力 → **每节点必须显式返回一对**。这是"何时给状态加一维"的活教材。
- **环形**：环比线只多首尾一条边；**任意一条边当接缝都对**（最优方案每条边都至少空一端），选首尾只因 `nums[1:]` / `nums[:n-1]` 是现成切片、最省事。
- **树形**：dp 表 = 递归返回值，别用数组；**局部变量接住、每节点只算一次**，否则重复调用 3ⁿ 爆炸。
