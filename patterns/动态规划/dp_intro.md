## 一、什么时候用 DP：重叠子问题

两个信号同时满足，基本就是 DP：

1. **问的是最优 / 计数 / 可行**：最大、最小、多少种、能不能。
2. **子问题重叠**：拆成小问题时，**同一个小问题会被反复用到**。

判断"重叠"不用画递归树数节点，问一句就够：

> **"我拆出来的小问题，会被重复用到吗？"**

- 会 → 得把算过的**记账**存下来，这就是 DP。
- 不会（每个小问题只服务一个上层，像二叉树遍历每个节点只有一个父亲）→ 普通递归就够，不叫 DP。

## 二、DP 起手五步：拿到题怎么想

状态定义是 DP 最难、最容易卡"不知从哪下手"的一步。按这五步逼问自己，状态会自己浮出来：

| 步 | 追问 |
|---|---|
| **① 选择** | 当前这一步，我在做什么"选 / 不选 / 选哪个"的决定？ |
| **② 约束** | 做完这个决定，它限制、影响了谁？ |
| **③ 状态** | **为了让"下一个决定"做得对，我必须记住什么？** ← 命门 |
| **④ 转移** | 按 ① 的选择分情况，用子问题的状态拼出当前 |
| **⑤ 起点 & 顺序** | 最小的子问题填什么？按什么顺序算，才能保证用到的都已算好？ |

灵魂是 **③**，它有一句万能追问：

> **"轮到我做决定时，我需要知道'子问题'的什么信息才够？那个信息，就是状态。"**

③ 不仅定义状态，还**决定状态几维**：

- 打家劫舍（树形）：要决定父亲偷不偷，得知道孩子"偷 / 不偷"两种值 → 每节点记**一对**。
- 背包：要决定这个物品选不选，得知道"还剩多少容量" → 多一维 `dp[i][j]`。
- 买卖股票：要决定今天买不买，得知道"手里有没有票" → 多一维 `dp[i][0/1]`。

> 五步对"逐步做选择"类（爬楼梯 / 打家劫舍 / 背包 / 股票 / 子序列 / 编辑距离）最顺手；少数"按区间划分"的题，① 放宽成"枚举最后一步 / 最后一个分割点"，骨架仍成立。

## 三、内核 vs 外壳

**内核**（每题不变，缺一不可）：**状态定义 · 转移方程 · 记账**。状态定义是灵魂（见第二节 ③）。

**外壳**（随题而变，别当死模板）：

| 维度 | 可能形态 |
|---|---|
| 写法 | for 递推 / 记忆化递归 |
| 维数 | 一维 `dp[i]` / 二维 `dp[i][j]` / 更高 |
| 存储 | 数组（状态有整数下标时）/ **递归返回值 + 局部变量接住**（树、无下标时）|

> "记账"和"存储"是一回事：填过的格子（或接住的返回值）不再重算，就是记账。

## 四、两个方向：其实你都写过了

同一个转移方程，两个方向，你都亲手写过：

- **自底向上（bottom-up）= for 递推**：爬楼梯 / 打家劫舍，从最小的 `dp[0]`、`dp[1]` **从小往大一个个填**到 `dp[n]`。
- **自顶向下（top-down）= 记忆化递归**：树形打家劫舍，从根 `dfs(root)` 出发**往下递归拆到底、再把结果层层返回来拼**。

区别只在：bottom-up "先把小的全填好、用时直接取"；top-down "要用时现去递归求，求过的记下别重求"。

**什么时候用哪个：**

- 状态有**整数下标顺序**（线性、矩阵）→ **for 递推**最简洁。
- 状态**没有天然顺序**（树、图）→ **递归自顶向下**最自然（没法"从小到大 for 一棵树"）。

> ⚠️ 记忆化递归的坑：`memo` 要建在递归函数**外面**（全程共享一张账本）；建在里面每层 new 一张空的 → 记账失效 → 退回指数。

## 五、遍历顺序 = 服从依赖方向

遍历顺序只有一个使命：**算某个状态时，它依赖的状态都已经算好了**。所以顺序不用背，看转移依赖谁：

- **线性**：`dp[i]` 依赖 `dp[i-1]`（更小）→ 从小到大；若依赖 `dp[i+1]` → 从大到小。
- **树**：父的值依赖孩子的值（父依赖子）→ **后序**（先算完孩子）；若父把信息传给子（子依赖父）→ 前序。

> 转移方程一写出来，依赖方向就写在脸上，⑤ 的顺序自动定死——不用记。

## 六、复杂度直觉：重复 → 指数，记账 → 线性

- **不记账、每次调用分裂出 k 份重复子计算** → 沿一条路径每层 ×k → **指数 kⁿ**（爬楼梯纯递归 ≈1.6ⁿ、树形重复调用 3ⁿ 都是这个病）。
- **记账、每个子问题只算一次** → 总量 = 数状态个数 → **线性**（把节点 / 格子加起来，是加法不是乘方）。

**空间**：

- 递归栈占 O(树高 / 递归深度)。
- **滚动变量**：若 `dp[i]` 只依赖最近几个状态，就不必开整个数组，几个变量往前滚，空间 O(n) → **O(1)**。
